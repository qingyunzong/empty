# virtualarray — 虚拟数组矩形读取

`virtualarray` 把若干“源数组 + 点选择映射”装配成一个虚拟数组，并对宿主
请求的半开矩形做精确读取。它不解析 HDF5 或任何磁盘格式，只消费宿主给出
的映射元数据。

## 设计要点

- 任意精度：所有 shape、selection 参数、坐标与线性下标均为 `*big.Int`，
  超过 `2^53` 乃至 `uint64` 的元数据也保持精确；秩限制为 1 至 8。
- 不展开选择：读取仅遍历“请求矩形”内的点，逐点用
  membership / rank / unrank 算术定位，绝不按 selection 总点数分配索引或
  展开整个源 / 整个选择。
- 映射语义：selection 按坐标字典序（最后一维最快）排序，虚拟点与源点按
  相同序号一一对应；源与虚拟秩、形状可不同，但选中点数必须精确相等。
- 遮蔽与缺源：多条映射命中同一点时列表最后一条优先；其源在可用性快照中
  不可用时输出 fill 且不回退到较早映射；无映射也输出 fill。
- 批量源读取：同一源的相同线性位置只读一次；位置去重后合并相邻位置为
  半开区间 `[Lo, Hi)`，按源一次性回调；回调失败或返回长度不符则整次失败，
  不交付半批。
- 布局：源按宿主声明的 C（最后维最快）或 F（第一维最快）顺序平铺为
  `int64`，回调只看线性元素下标。
- 预算：请求点数超过调用方预算时，在任何分配与源回调之前返回
  `ErrBudgetExceeded`。
- fill 不被当作缺失：源里真的存着 fill 值时，读取成功并标记为有源数据。

## 初始化校验

`New` 完整校验并做防御性拷贝，任何不合法都不会得到可用对象：

- shape 秩 1..8、长度非负；selection 秩必须与对应数组一致。
- 每轴 `stride > 0`、`block > 0`、`stride >= block`、`start >= 0`、
  `count >= 0`；`start <= 维长` 对空 selection 也强制。
- 非空轴的最后一个选中坐标 `start+(count-1)*stride+(block-1)` 必须落在
  shape 内；空 selection 不要求虚构“最后坐标”。
- 虚拟与源 selection 选中点数必须精确相等（含两者皆空）。
- 同名源的 shape 与 C/F 顺序必须一致。

## 读取结果

`ReadRect` 返回 C 顺序的 `Values` 与等长的 `Points` 溯源信息：命中映射
下标、源名、虚拟坐标、源坐标、是否 fill 及 fill 原因（`NoMapping` /
`SourceUnavailable`）。空矩形返回空切片且不触发任何源回调。

## 测试

`reference_test.go` 是仅用于测试的小数组全展开参考实现，主测试将流式实现
与其逐点比对，并覆盖：跨秩 zip、block 内部顺序、C/F 源布局、后映射遮蔽、
缺源不回退、重复源位置只读与相邻合并、读取失败整批不交付、超大空间中的
小请求、`uint64` 边界、预算前置拒绝与初始化校验。

运行：

```sh
go test ./virtualarray/ -race
```
