# exprop

整数表达式优化库（仅使用 Go 标准库）：常量折叠 + 短路简化，并严格保留
可观察的除零错误顺序——未求值的分支不会提前报错。

## 结构

- `expr.go` — AST（`Const` / `Binary` / `Cond`），每个节点带来源位置 `Pos`；`Dump` 输出带位置的 S 表达式。
- `eval.go` — 解释器：左到右求值，`&&`/`||`/`?:` 短路；除零产生带位置的 `*EvalError`；`EvalProgram` 按序求值并记录每个表达式的值或错误。
- `opt.go` — 优化器：
  - 常量折叠：两侧均为常量时折叠；但常量除零**不**折叠，保留节点让错误在运行时的原有顺序位置抛出。
  - 短路简化：`0 && x → 0`、`c≠0 && x → (x != 0)`、`1 || x → 1`、`0 || x → (x != 0)`、常量条件的 `?:` 选支——被丢弃的分支原本就不会被求值，其错误不可观察。
  - 恒等式：`x+0`、`x*1`、`x/1` 等；`x*0 → 0` 仅当 `x` 纯净（`pure`，不可能抛出除零错误）时应用。

## 测试

- 单元测试覆盖折叠、短路、未求值分支不报错、除零错误位置保持、不纯子表达式不被丢弃。
- `ExampleOptimize` 展示优化前后带位置的树形输出。
- `TestRandomProgramsDifferential`：固定种子生成 20000 个随机小程序（1–4 个表达式、深度 ≤ 4），
  逐表达式比较原解释器与优化后树的值及错误（消息 + 位置）序列完全一致。

运行：`go test ./...`
