# trajidx — 轨迹索引 CLI

为日志文件旁路生成行偏移与 SHA-256 摘要的索引（`<file>.idx`），**绝不修改原文件**。
仅使用 Go 标准库。

## 特性

- **流式扫描**：`bufio` 按字节流读取，多字节（UTF-8）日志、末行无换行、超长行均可处理，不把文件整体载入内存。
- **旁路索引**：行偏移/长度、周期性检查点（前缀摘要）、整体摘要写入独立 sidecar 文件。
- **增量索引**：先流式核对已索引前缀的各检查点摘要；前缀可信且文件仅追加时，只扫描新增尾部（末行无换行时自动回退到该 partial 行起点重扫）。
- **首个不可信区间**：发生任意截断或更改时，定位第一个摘要失配的检查点，报告半开区间 `[start, end)` 并从最近可信检查点重建；测试结果与全扫描 `Build` 完全一致。

## 用法

```sh
go build ./cmd/trajidx
trajidx build  app.log        # 全扫描，写 app.log.idx
trajidx update app.log        # 增量更新；如有截断/更改，打印首个不可信区间
trajidx verify app.log        # 重算摘要并核对
trajidx line   app.log 42     # 查询第 42 行（0 起）的偏移与长度
```
