# 指标行的分上下文转义与序列键

指标采集管道收到的一行里，测量名、标签和引号字段对空格、逗号、等号的转义并不通用，行首的井号才是注释。实现可导入的TypeScript模块，供采集管道调用。构造参数指定ns、us、ms或s，缺省时间使用注入的整数纳秒时钟，换到目标精度时向零截断。LF分行，行尾CR LF里的CR丢弃；行内其他CR失败。未遇到LF不出点，Finish时仍有残余则失败。首字节为#的行整行忽略。空行忽略。测量名非空，其中的空格、逗号和反斜杠必须写成反斜杠加原字符，别的反斜杠失败。标签紧接测量名，每个标签以逗号开始，键和值都非空；键和值里的空格、逗号、等号、反斜杠必须转义。标签与字段之间、字段与时间戳之间都恰好一个空格。至少一个字段，字段之间用逗号。字段键的转义与标签键相同。字段值只能是下列之一：以i结尾且落在int64范围的十进制整数；以u结尾且落在0至18446744073709551615的十进制；true、false、t、f、T、F之一；双引号字符串；或不带i、u后缀的十进制浮点。整数和u整数禁止前导零，允许单独的0，也允许负的i整数；负号后紧跟0、空的i或空的u都失败。字符串只把\\和\"还原成反斜杠和双引号，不闭合、出现换行或其他反斜杠都失败，内容必须是严格UTF-8。浮点接受可选符号、数字、可选小数部分和可选e或E指数，按有理数做binary64最近偶数舍入，结果必须有限；字面+0与-0保留符号。同一点内标签键或字段键重复则该行失败。返回字段保持原顺序，另给按标签键UTF-8字节序排序后的序列键；排序不改原始标签列表。时间戳若存在，是可选单个负号加无前导零十进制，负号后不能紧跟0，数值按所选精度解释并必须落在int64。坏行之前已经完成的点保留，组件停止。测试独立做转义和标签排序，覆盖测量名中的空格、标签中的等号、引号内逗号、重复键、精度向零截断、正负零、只有行首井号才是注释，以及行被切块。期望点不得调用被测模块生成。
