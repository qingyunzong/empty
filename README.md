# 日志条目的二进制字段长度

日志采集若把二进制字段的长度读进下一条，空行就不再是条目边界。实现可导入的Go组件，供日志采集调用。条目由字段组成，条目之间用一个空行分隔，最后一条后面可以没有空行。含等号的行是文本字段：等号前是键，等号后到换行前是值，值必须是严格UTF-8，值可以是空串。不含等号且非空的行是二进制字段的键，下一组字节是小端uint64长度和正好这么多原始字节，原始字节后面不额外要求换行。键由1至64个ASCII字母、数字或下划线组成。同一条目允许重复键并保留顺序，没有任何字段的条目失败。长度大于宿主maxField时，8字节一旦齐备就拒绝，不按声明分配。LF是唯一换行，单独的CR失败。Push可以切在长度或正文中间；Finish时最后一个条目未结束则失败。失败停止组件，已交付条目保留。测试独立计算长度，覆盖二进制正文吞入下一条、重复键、结尾没有空行、空文本值、非法UTF-8和切块位置。期望条目不得由被测组件生成。
