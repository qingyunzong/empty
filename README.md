# 采集去重的内容定义分块

归档写入器调用Go流式分块包，对文件字节生成内容定义块。参数为1<=min<=max、正窗口宽度w、模数m>1及0<=r<m；滚动摘要为最近至多w字节按从旧到新计算h=(h*257+byte)模m，遇到块边界不清空窗口。当前块长度至少min且h等于r时切块，长度达到max强制切块；显式结束时交付非空残块，空文件零块。每块返回全文件起点、原始字节与SHA256。运算须对任意uint64模数准确，不能靠溢出后的取模；内存只保留窗口与当前块。回调暂停表示该块已接收，本块剩余输入由消费位置返回，恢复不重发。以每次重算窗口的参考实现验证所有切块位置、极大模数、强制边界和输入逐字节分割。
