# seatbank

给同一排座位分配不超过 10 个团体：

- 每个团体必须占据**连续**的座位，不得拆团；
- 团体之间可以隔着任意空座（可跨过空座）；
- 封锁座位（`#`）不可用；
- 目标一：未安置人数最少；目标二：在此前提下，所有已安置人员到指定列的
  绝对距离之和最小。

## 算法

主算法是子集 DP：`dp[i][mask]` 表示只使用前 `i` 个座位、恰好安置 `mask`
中团体时的最优二元目标（安置人数大者优先，其次总距离小者优）。每个座位可以
留空，也可以作为一个未安置团体的起点。复杂度 `O(N · 2^G · G)`（G ≤ 10）。

`SolveBrute` 是参考实现：对“子集 × 排列 × 起始位置”做全排列式枚举，
`TestMatchesBrute` 在短排（≤9 座、≤4 团）上随机生成 2000 个用例交叉核验。

## 输入格式（stdin）

```
N T G            座位数、目标列（1 起）、团体数（≤10）
rowstring        长度为 N：'.' 可用，'#' 封锁
s1 s2 ... sG     各团体人数
```

## 运行

```sh
printf '10 4 3\n..##......\n3 2 4\n' | go run .
```

输出未安置人数、总距离、布局串（A、B… 为团体，. 为空座，# 为封锁）
以及每个团体占据的列区间。
