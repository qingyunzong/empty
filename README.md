# stats — 按用户维护最近 n 个事件中位数的统计库

仅使用 Go 标准库。

## 核心语义

- **窗口与中位数**：每个属主（用户或别名组）的事件按 `(业务时间 Time, ID)`
  升序排序，取末尾（最近）n 个作为统计窗口；窗口分数的中位数为统计结果，
  偶数个取中间两项的平均分数。
- **Upsert**：按（用户, ID）归属的上报/更正。同用户同 ID 为原地更正；
  不同用户可各自持有同 ID 事件（归并时再去重）。
- **Correct**：按事件 ID 的全局更正，可移动所属用户；同 ID 多属主时从
  字典序最小的属主处移动，其余副本不受影响。
- **变动快照**：每个变更操作返回本次状态发生变化的属主快照（按 Owner
  排序），并追加到只增不减的历史快照流 `History()`。
- **归并 Merge**：成员事件并入别名组并按 (Time, ID) 重组顺序；同 ID
  只保留成员列表中最先出现的一份参与统计，其余副本（重复或冲突）隔离
  到隔离区（`Quarantine` 可查）。归并后按任一成员别名查询均得到组快照。
- **拆分 Split**：规范副本与隔离副本都归还各自来源用户（事件当前 User
  即来源；若归并期间更正改写了来源导致冲突，以规范副本为准），组存续
  期间输出的历史快照保持不丢。
- **索引**：归属索引（事件 ID → 属主集合）与序统计索引（每实体有序事件
  表 + 窗口分数多重集）在同一持锁临界区内原子更新；Store 并发安全。

## 测试

- `stats_test.go`：窗口滚动、奇偶中位数、同时间 ID 决胜、更正移动用户、
  归并去重/冲突隔离/拆分恢复/历史保持、参数校验、并发（配合 `-race`）。
- `differential_test.go`：随机操作历史（上报/更正/归并/拆分/恢复/非法
  操作）逐步与全量排序参考模型对照变动快照、全量状态、隔离区与历史
  快照流；同种子重放验证确定性。

## 实测结果（go1.27.1 linux/amd64）

```
$ go test ./...
ok  	stats	1.086s
$ go test -race ./...
ok  	stats	9.186s
# 差分测试临时加严到 600 个随机种子同样通过（13.33s）
```
