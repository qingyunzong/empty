# skyline

维护一组带高度矩形的水平天际线（C++20）。每个矩形贡献半开区间
`[x1, x2)` 上的一段高度；同一 id 的删除只移除该矩形自身的贡献。

## 语义约定

- **半开区间**：矩形覆盖 `[x1, x2)`，相邻区间在端点处不重叠。
- **空矩形**：`height <= 0` 或 `x1 >= x2` 的矩形定义为空，不产生任何贡献
  （`add` 空矩形等价于移除该 id 的旧贡献）。
- **负坐标**：坐标与 id 均为有符号 64 位整数，负值合法。
- **同 id 重加**：`add` 相同 id 会替换其之前的贡献。
- **来源保留**：同高度重叠的矩形不会丢失来源——每段记录达到该段最高
  高度的全部矩形 id（`Segment::sources`，升序去重）。

## API 概览（`skyline::Skyline`）

- `add(id, x1, x2, height)` / `remove(id)`：增量维护，删除只移除该 id 的贡献。
- `snapshot()`：详细快照，输出高度变化点；相邻且高度与来源集合都相同的
  段被合并；无覆盖区域不输出。
- `skyline()`：纯高度视图，相邻同高段合并（忽略来源差异）。
- `applyBatch(additions, removals)`：批次增删（先删后加），返回旧快照、
  新快照与差量。
- `Skyline::diff(before, after)`：对任意两份快照（支持外部保存的旧快照）
  求逐段差量。**高度不变但来源集合变化同样会产生 `Change` 通知**
  （`heightChanged() == false`、`sourcesChanged() == true`）。

## 构建与测试

```sh
cmake -S . -B build
cmake --build build
cd build && ctest --output-on-failure
```

测试包含两部分模型核验：

1. **端点分段全扫描模型**：收集所有矩形端点，对每个基本区间暴力扫描
   全部矩形求最高高度及全部来源 id，与库的增量实现逐步对拍
   （4000 步随机增删/批次操作，含负坐标、零高度、退化区间、同 id 替换）。
2. **逐端点差量模型**：对批次前后的矩形集合逐基本区间独立扫描，
   验证 `applyBatch` 输出的每条 `Change` 覆盖区间、旧/新高度与旧/新
   来源集合完全一致，且未变化的区间不出现在差量中。
