# rsp — 响应文件参数展开库

Go 标准库实现的命令行参数展开库（模块 `example.com/rsp`，包 `rsp`）。

## 功能

- **响应文件递归展开**：`@file` 参数被替换为文件内容分词后的 token 序列，
  文件内可继续嵌套 `@file`（`Expand`）。
- **引号与转义**：单引号原样保留；双引号内保留空白且 `\` 转义下一字符；
  引号外 `\` 转义下一字符；未闭合引号报错并带文件与偏移。
- **相对包含路径**：响应文件内的 `@ref` 相对包含它的文件所在目录解析
  （`FS.Resolve`）。
- **循环检测**：按规范路径（`FS.Canonical`，OSFS 下为绝对路径 + 符号链接
  解析）检测包含环，`CycleError.Chain` 按顺序报告完整包含链，如
  `response file cycle: /a.rsp -> /b.rsp -> /a.rsp`。菱形包含（两个文件
  同时包含同一文件）不是环，会正常展开两次。
- **`--` 终止选项**：先完整展开为扁平 token 序列，再在第一个 `--` 处切分
  （`Parse` → `Args{Options, Positional, Terminated}`）。因此响应文件内的
  `--` 对展开后的整个序列生效，`--` 之后的 `@file` 仍会被展开。
- **来源区间**：每个 token 携带 `Source{File, Start, End}`，File 为规范
  路径（命令行直接给出的 token 为空），Start/End 为文件内字节偏移，
  区间覆盖原始文本（含引号）。
- **文件系统抽象**：`FS` 接口 + `OSFS`（真实文件系统）与 `MapFS`
  （内存虚拟文件表，用于测试）。

## 测试结果

`go test ./...`（Go 1.27.1，linux/amd64，2026-10-06）实际输出：

```
ok  	example.com/rsp/rsp	0.053s
```

11 个测试全部通过：递归展开、引号与转义、未闭合引号、相对包含路径、
规范路径循环链、`--` 作用于整个展开序列、无 `--`、来源区间偏移、
菱形包含、真实文件系统（OSFS）、字面 `@` 与缺失文件。
