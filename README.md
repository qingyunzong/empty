# resample

固定间隔的有理数重采样库，仅使用 Go 标准库（`math/big`）。

## 语义

- 输入为有理数时间/数值的采样点（`Sample{T, V *big.Rat}`），时间必须非负且全局严格递增。
- 输出为锚定原点的等间隔网格点：原点 `t = 0` 是显式网格点，输出时间恒为 `step` 的非负整数倍。
- 网格值由分段线性插值得到，全程 `big.Rat` 精确运算，无浮点误差。
- 缺失段不插值：`Break` 分隔的间隙内的网格点不产生输出。
- 尾部不外推：最后一个采样点之后（没有右端点）的网格点不产生输出，`End` 结束信号只关闭流，不补点。

## API

- `New(step)`：创建流式重采样器。
- `Write([]Sample)`：写入一批采样点，返回新确定的网格点。
- `Break()`：结束当前连续段，之后直到下一点为缺失段。
- `End()`：结束信号，关闭重采样器。
- `Resample(step, runs)`：整序列一次性处理，`runs` 为按缺失段分隔的连续段。
