# graphlib — 版本化二分图分析库

仅使用 Go 标准库。

## 功能

- **边增删与撤销**：`AddEdge` / `RemoveEdge` / `Undo`，每次成功变更（含撤销）递增版本号。
- **稳定 ID**：顶点用字符串 ID 标识；孤立点（`AddVertex` 或删边后残留）永久保留；重复边插入（含反向）为幂等无操作，不增版本、不占撤销日志。
- **每版分析**：`Analyze()` 返回当前版本的最大匹配（Hopcroft–Karp）与同大小的最小顶点覆盖（Kőnig 构造），结果按版本缓存；非二分边与自环被拒绝（Kőnig 定理保证二分图上 |最大匹配| = |最小顶点覆盖|）。
- **独立验证器**（`verify` 包）：校验匹配合法性（边存在、端点不共享）、覆盖合法性（每条边至少一个端点在覆盖中）、两者大小相等；对 ≤24 个顶点的小图枚举全部子集核对最小覆盖大小——结合大小相等即反证匹配最大。

## 结构

- `graph/graph.go` — 版本化图、增删边、撤销、二分性校验
- `graph/matching.go` — Hopcroft–Karp 最大匹配 + Kőnig 最小顶点覆盖
- `verify/verify.go` — 独立验证器与暴力枚举核对
- `graph/graph_test.go`、`verify/verify_test.go` — 单元测试、随机操作序列逐版本验证、撤销一致性、验证器阴性用例
