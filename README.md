# 查询结果行的空值长度

查询采集若把长度为-1的空值读成4字节占位，下一列的长度就会落到数据中间。实现可导入的Go组件，供查询采集调用，不连接数据库。消息以1字节类型开始，随后是大端int32长度，该长度包含这4字节、不包含类型字节，且必须不小于4。只接受D、C、E、Z、d、c。D的正文是大端int16列数，随后每列一个大端int32长度；长度-1表示空值且后面没有数据，长度大于等于0时紧跟这么多原始字节。列数必须和实际列一致，不能剩下半列。C和E的正文是严格UTF-8，以0x00结束，中间不能有0x00；E在这个结束字节之后不能再有字节。Z的正文只能是I、T或E之一。d的正文是原始字节，长度可以对应空正文。c的长度必须恰好为4。长度大于宿主maxMessage时，4字节一旦齐备就拒绝，不按声明分配。流可从任意字节继续。Push可停在长度或列数据中间；Finish时消息未完成则失败。失败停止组件，已交付消息保留。测试独立计算长度，覆盖空值-1、列数不符、Z的非法状态、c多出字节、E中间的0x00，以及长度字段被切开。期望行不得调用被测组件生成。
