# 报文字段的体长与末字段校验

报文采集若把起始字段算进体长，校验范围又漏掉体长字段，两个数字会同时对不上。实现可导入的Go组件，供报文采集调用，不建立会话。字段之间和每个字段结尾都是0x01。字段是无前导零的十进制标签、等号和值，值可以是空串但不能含0x01。一条报文必须以标签8开始，值只能是FIX.4.2或FIX.4.4，接着必须是标签9，值是体长。体长从标签9的结尾0x01之后算起，直到标签10前面的那个0x01，包含这段里的全部字节。标签10必须是最后一个字段，值是恰好3位十进制，范围000至255，允许前导零。校验是标签10之前所有字节的无符号和模256，不含标签10自身。标签35必须是体长之后的第一个字段，值非空。除8、9、10、35外，标签可以重复并保留顺序。体长大于宿主maxBody时，在标签9的值完整后拒绝，不按声明分配。Push可停在字段中间；Finish时报文未完成则失败。失败停止组件，已交付报文保留。测试独立计数，覆盖体长含起始字段、校验漏掉标签9、标签10不是最后、35不在体长后和0x01被切开。期望报文不得调用被测组件生成。
