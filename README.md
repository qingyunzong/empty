# 分组溢写后的排序稳定性

日志聚合宿主调用可导入Go外存分组包，输入行有字符串组键、任意精度整数值及递增原序号。只允许缓存至多B行，B为正，超出时通过注入的临时段接口溢写；结果按组键字节序输出sum及组内原序号列表，序号列表允许流式回调。取消或任何段读写失败须关闭并释放全部临时段，不能先发布未经完整读回校验的组。用最多两行缓存夹具和内存全排序参考测试跨段同组、错误及资源回收。

## extgroup 外存分组包

`extgroup` 提供可导入的外存分组能力（`example.org/dataeng/q0167/extgroup`）：

- 输入行 `Row{Key string, Value *big.Int, Seq uint64}`，`Seq` 为递增原序号。
- 内存最多缓存 `Config.B` 行（`B > 0`），缓存满时通过注入的
  `SegmentFactory` 溢写为有序临时段。
- `Finish` 对所有临时段做 k 路归并，按组键字节序输出每组的 `sum` 与
  原序号列表；序号通过 `EmitSeq` 回调流式读取，末尾返回 `io.EOF`。
- 组仅在该组全部行成功读回后才发布；取消或任何段读写失败都会关闭并
  释放全部临时段，聚合器随后返回 `ErrFinished` 拒绝复用。

测试使用最多两行的内存段夹具，并以内存全排序为参考实现，覆盖跨段同组、
任意精度求和、错误注入、取消与资源回收：

```sh
go test ./...
go test -race ./...
```
