# 副本库存模拟: 版本向量 + 冲突集合 + 读修复

TypeScript 实现的副本键值库存模拟, 语义对齐 Dynamo 风格的可最终一致存储:

- **版本向量**: 每个值携带版本向量 (`src/versionVector.ts`), 支持 `increment` / `merge` / `compare` (支配、被支配、并发、等价)。
- **并发冲突集合**: 并发版本全部保留在冲突集合中, 不做时钟覆盖 (LWW); 仅当被更新的版本因果支配时才裁剪 (`src/versionedValue.ts` 的 `normalizeSet` / `mergeSets`)。
- **读修复**: 读路径强制 `r >= 2`, 合并各副本集合后把结果回写给缺版本的副本, 并返回修复证据 (`src/cluster.ts` 的 `read`)。
- **撤回不复活**: 删除产生带版本向量的墓碑, 墓碑支配被撤回的旧版本; 随机分区 + 集合合并 (反熵 `syncAll`) 下旧版本不会复活 (`test/randomized.test.ts`)。
- **支配关系证据**: `src/evidence.ts` 输出每个 key 的版本分布与两两支配/并发关系; `npm run demo` 直接打印。

## 运行

```bash
npm test     # tsc 编译 + node --test 全部测试
npm run demo # 打印三个场景: 并发冲突 / 读修复 / 随机分区撤回核验
```

无第三方依赖, 需要 Node.js 与全局 `tsc`。

## 不变量 (由测试核验)

- 任意副本的冲突集合内不存在互相支配的版本 (局部归一化)。
- 愈合 + 反熵后所有副本集合一致 (收敛)。
- 被删除时副本可见的版本 (已撤回集合) 在终态任何副本中均不作为存活值出现 (不复活)。
- 相同随机种子产生相同终态 (确定性)。
