直播转码管线需要可嵌入的 C++20 H.264 Annex B 访问单元组装器，字节块可在起始码、NAL 头和 RBSP 防竞争字节中任意切开。组件识别三字节与四字节起始码，保留每个 NAL 的原始字节范围，去除 emulation_prevention_three_byte 后只解析形成画面边界所需的 SPS、PPS、AUD 与 slice header；参数集按 id 和世代保存，切片引用当时有效的参数集。按 H.264 的 first_mb_in_slice、frame_num、field_pic_flag、bottom_field_flag、nal_ref_idc、POC 相关字段及 IDR 标识判断新 picture，同一 picture 的多 slice 必须归入一个访问单元，SEI/参数集按出现位置归属，AUD 可显式定界但不能掩盖冲突切片。缺参数集、截断 Exp-Golomb、禁止位、非法防竞争序列或互相矛盾的首切片使当前访问单元失败，之后只在下一个可靠起始码恢复；Flush 区分完整末 NAL 与截断头。用独立编码夹具覆盖多 slice 帧、场图、POC 回绕、参数集更新、无 AUD 流、起始码跨块和损坏后恢复，并把组装结果与一次性解析参考逐切块对照。
