# 采样记录的长度不含标头

采样采集把标头的8字节也算进样本长度时，下一条记录的企业号会落到上一条里面。实现可导入的Go组件，供采样采集调用，不接收网络。分组以大端uint32版本开始，版本必须为5。随后大端uint32地址类型只能是1或2，分别跟着4或16字节地址。再是大端uint32子代理、序号、运行毫秒和样本个数。每个样本是大端uint32类型、大端uint32样本长度和数据。类型的高20位是企业号，低12位是格式，企业号必须为0，格式只能是1或2。样本长度不含类型和长度这8字节，必须等于数据字节数。格式1的数据依次是大端uint32序号、源标识、采样率、样本池、丢弃数、输入接口、输出接口和记录个数，然后是记录。格式2的数据依次是大端uint32序号、源标识和记录个数，然后是记录。源标识的高8位原样返回，低24位是索引。记录同样是大端uint32类型、大端uint32长度和原始值，长度不含这8字节。记录个数必须和实际记录数一致，样本长度必须正好覆盖这些字段和记录。样本个数必须和实际样本数一致，分组不能有剩余字节。样本长度大于宿主maxSample时在这4字节可读后拒绝，不按声明分配。Push可停在样本中间；Finish时分组未完成则失败。失败停止组件，已交付分组保留。测试独立组包，覆盖样本长度含进8字节标头、格式1的记录个数不符、企业号非0和分组被切开。期望样本不得调用被测组件生成。
