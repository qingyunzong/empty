# transferplan

调拨规划库（仅使用 Go 标准库）。在不超过 8 个节点、10 条运输边、
单点库存/需求不超过 20 的网络上，求满足全部需求的最低成本调拨方案。

## 模型

- 每条有向边有整数容量 `Cap`、单位成本 `Cost`、固定整数损耗 `Loss`。
- 边启用（流量 f > 0）时损耗先扣：源点发出 f 单位，终点收到 f - Loss
  单位（因此要求 f >= Loss），其余货物守恒。
- 每点有初始库存 `Supply` 与期末需求 `Demand`，允许中转。

## 求解与对照

- `Solve`：精确算法。固定损耗等价于固定费用（启用边 e 额外支付
  `Loss*Cost`），枚举启用边子集（至多 2^10），每个子集化为一次
  最小费用流，取全局最优。
- `Enumerate`：逐边流量枚举（暴力）参考实现，用于对照验证。
- `Verify`：校验方案的可行性（容量、损耗、需求、成本一致）。

## 测试

```sh
go test ./...
```

覆盖：确定性手算用例、参数校验、1000 组随机实例上 `Solve` 与
`Enumerate` 的成本一致性对照、以及 8 点 10 边库存 20 的上限规模用例
（该规模下逐边枚举为 21^10，不可行，仅运行 `Solve`）。
