# 十六进制浮点采集值的舍入

地震资料接入服务要将历史设备的32位十六进制浮点样本转成IEEE binary32；普通浮点乘法会在边界二次舍入。实现供样本解码管线导入的Go转换包。输入四字节大端字，最高位为符号，中间7位为指数e，低24位为整数尾数m，精确值为(-1)^sign*(m/2^24)*16^(e-64)；m=0时忽略指数但保留符号得到正负零，非零m允许未规范化。输出IEEE binary32原始位型，使用round-to-nearest ties-to-even，一次完成舍入，含次正规数、舍入到最小正规数、最大有限数及溢出无穷；输出是否精确、是否下溢及是否溢出，下溢定义为舍入前绝对值小于最小正规数且转换不精确。还要提供反向转换：给binary32位型，在满足下述规范化要求的全部可表示十六进制字中选择数值最接近者，平局取偶数尾数，再取指数最小者，符号按输入保留；NaN与无穷不能反向转换，返回错误。反向非零输出应规范化为m最高四位非零，但若指数0仍不足则允许非规范尾数；符号零统一指数0尾数0。实现不能通过float64中间值或字符串格式化推断舍入。测试以任意精度有理数对照正反向误差，覆盖每类指数交界、半ULP平局、正负零、多个等值非规范字及两种格式的最大范围差异；说明精确性和上下溢标志如何验算。
