# 抓取文档的生成编号还原

爬虫取得的正文不含伪元素编号，导致嵌套章节的真实标号丢失。给采集宿主开发TypeScript生成文本提取包，输入已解析树、全局唯一节点ID和宿主算好的样式指令，不解析CSS、不排版；仅实现以下显式计数作用域契约，不宣称完整浏览器兼容。初始实例的来源统一记为$initial，输入是一组根节点并按同样兄弟层处理；初始每个已声明名称有根实例及任意精度有符号整数值，未知名称拒绝。处理一组兄弟前为这一层建立空的局部实例表；节点reset某名称时，若这一层已创建该名称则替换当前局部实例，否则在该名实例栈上压入新实例，作用于当前节点及后续兄弟、其后代。每节点依次应用reset、set、increment，再取before内容、递归孩子、取after内容；set与increment只作用最内实例，未局部reset则改到继承实例，其修改在离开孩子层后仍保留；退出一组兄弟只弹出该层创建的实例，不能把外层计数值恢复成进入时数值。每类指令是有序列表，同类同名重复拒绝，三类间同名允许。内容token仅含原样literal、counter(name,style)和counters(name,sep,style)，后者由外到内格式化整栈并连接；style为decimal或lower-alpha，decimal含负号，alpha对正数按1=a、26=z、27=aa的无零进位制，非正数回退十进制。节点skipSubtree时其指令、内容和子树全不执行；只suppressText时仍执行指令并遍历孩子，仅自身before/after不产出，不能把二者混淆。输出拼接文本及每段生成文本的节点、before/after、token序号、所读实例创建节点与当前精确值，字面量段也保留来源；即使skipSubtree也先做全输入结构与指令合法性验证；树有环、多父、重复ID、坏指令或超出宿主输出字节预算时整次失败。提供嵌入采集例和测试，用独立的实例对象解释器核对兄弟reset替换、孩子增量影响后续兄弟、嵌套同名栈、隐藏文本仍计数、巨大负数与alpha进位，不借助浏览器的自动编号得到答案。
