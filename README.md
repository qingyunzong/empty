# 嵌套列表的重复级别与定义级别

列式接入宿主调用可导入的Go嵌套级别包，行类型为可空list<可空list<可空int64>>，输入token含重复级r、定义级d及可选值。d=0外list为null、1外list空、2某外元素为null、3该内list空、4内元素null、5有值，仅d=5携值；r=0开新行，1开同一行下一外元素，2续同一内list。r=1要求前后token的d均至少2，r=2要求前后d均至少4，首token必须r=0；r仅0到2、d仅0到5；参数给非负行数且须一致，结束输入时才确认最后一行。实现双向转换，保留每个叶值token位置，不把null与空混同。用树生成编码再解码及独立逐token状态机核验非法续接、空流与跨批输入，每个输入批次原子校验，错误不发布该批次完成的行且状态回滚，前批未完成行暂存。
