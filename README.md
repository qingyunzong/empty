# 指数直方图跨精度与零桶闭包合并

遥测采集器接收不同精度的指数直方图，需要在不知道原始样本的情况下合并，不能假设桶内均匀分布。开发供采集管线调用的Go包；输入是同一度量的非负整数计数直方图，不处理时间窗、报表或告警。scale为[-8,8]整数，边界B(s,i)=2^(i*2^(-s))，正负两组分别按绝对值分桶，索引i代表(B(s,i),B(s,i+1)]；实际负数的方向由调用方解释，禁止交换负数组的索引顺序。输入每组是int32 offset与uint64 counts数组，offset加有效数组下标须仍在int32范围，超界拒绝；空数组规范offset=0；zeroCount统计绝对值不大于zeroThreshold的样本，threshold为0或符号表达式2^(n/2^k)，n有符号int64、k在0..16，数值可超出float64范围，比较必须精确，禁止实际求幂或取浮点对数。所有输入还给uint64 count，须等于两组及zeroCount之和，溢出拒绝；零计数桶可跨越threshold，但每个非零普通桶的下边界须大于等于threshold，否则输入无效，threshold=0时所有普通桶均可用。不要把原始样本映射问题或sum/min/max加入本题。宿主合并一次输入一组直方图及每侧最大稠密跨度M，M在2..4096；返回最高可行公共scale、公共threshold、规范两组稠密桶及count，零数组只裁两端，内部零桶必须保留。候选scale从所有输入scale的最小值向下试到-8；从s降到t时旧索引i精确落入floor(i/2^(s-t))，负索引必须数学向下取整，计数相加检查溢出。每个候选从原始输入重新计算，不能使用上个失败候选已经吞入零桶的结果。先降尺度并分别相加，再令T为所有原始threshold的最大值；若任一正或负侧非零桶满足lower<T<upper，则把T提高到这些跨界桶upper的最大值，反复直到没有跨界桶。然后把upper<=T的所有桶计数移入zeroCount；upper==T必须吸收，lower==T不得吸收，不允许拆分一个桶。T=0不吸收普通桶。threshold结果规范为0，或把n/2^k约分到n为奇数或k=0的表达式。闭包后每侧非零索引的max-min+1均<=M才可行；全零侧跨度0。不存在可行scale时返回容量不足及在-8的所需两侧跨度，不返回部分成功；非法输入、计数溢出和容量不足须区分，调用方已有直方图不得被修改。允许选择更低scale解决跨度，不能随意扩大零桶来满足M，也不能先取某一侧单独最优再拼合。合并空输入返回scale=8、threshold=0、空桶和count=0。给嵌入调用例及独立小规模展开参考实现，核对有理指数边界比较、负索引-1/-2的降尺度、负侧普通桶吸收、跨界阈值提升、非零桶恰在零阈值两侧、内部大空洞、不同scale及threshold的输入置换、计数溢出和最低scale仍超容量；对固定候选scale验证一次合并与分组后在同一scale合并一致，不能把自适应选择scale后的结果声称总与任意分组顺序相同。
