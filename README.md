# 采集文本的多级校勘键与变量权重

跨来源文本合并不能用宿主区域设置排序，否则同一数据快照在两台机器产生不同顺序。给导入宿主开发TypeScript可导入的确定性校勘包，宿主提供已规范化Unicode标量序列，不负责Unicode规范化，也不得调用Intl.Collator或系统locale。规则是非空标量序列到零个或多个校勘元素CE的映射，重复规则键拒绝；CE有primary在0..0x1fffff、secondary和tertiary在0..65535、variable布尔值，variable=true要求primary>0。扫描时在当前标量位置选择最长完整规则，等长不可能有两个；找不到规则则消费一个标量，产生primary=0x200000+码点、secondary=tertiary=0、variable=false的后备CE。规则匹配跨输入块，不能因当前块末恰好匹配短规则就提前交付，真实结束才排除更长规则；扩展CE次序保留，空扩展合法，未知字符不能直接忽略。输出四级权重流。non-ignorable模式各CE的非零primary/secondary/tertiary分别追加相应级，第四级为空。shifted模式下variable CE只向第四级追加自己的primary，且开启变量抑制状态；抑制期间后续primary=0的CE整项忽略，包括它的secondary/tertiary，遇非variable且primary>0的CE才关闭抑制，此CE正常进入前三等级并向第四级追加0x400000；非抑制状态下primary=0的CE保留自己的非零secondary/tertiary，不向第四级加标记。前三等级均只省去零权重，不把primary为0的普通重音误删；shifted中的抑制可跨块也可跨一条规则的扩展CE，不能按源字符重新初始化。选项backwardSecondary=true时在完整文本结束后把第二级全部权重倒序，其他级不反转；这是本题明确定义的规则，不要求完整UCA或任何语言地区兼容。宿主调用Key(strength=1..4)得到前strength级串联，每权重以4字节无符号大端编码，每级追加4个零字节为终止，不能把忽略的0权重实际写进键；键按无符号字节字典序比较须与逐级权重比较完全一致，低强度相等不再按原文或低级权重偷偷决胜。增量对象只在Finish成功后允许取Key；另提供接受两个完整标量序列的Compare及稳定排序调用例，同键项保持宿主原次序，不将无关的规范等价主张写入结果。支持增量Push标量块与Finish，保留当前规则最大长度所需前沿，不重扫已确定的标量前缀；可以保存已生成的权重以便反转第二级，不能保留全部源标量来等EOF再匹配。非法标量、重复Finish或完成后Push明确报错；宿主限制规则最长标量数及总生成CE数，在扩展时检查预算。返回每个保留权重的来源原标量半开区间及扩展CE序号，抑制权重不伪造来源，第二级反转须连来源一起移动。用独立一次性最长规则参考核对每个标量切块、短规则为长规则前缀、多个字符收缩成一个CE、一个字符扩为多个CE、variable后跨块零primary重音、全可忽略文本、补充平面码点和四种强度；穷举小规则字母表短文本，核对Compare符号与键字节比较、相等关系及稳定排序。
