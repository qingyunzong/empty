# 分段采集通道的索引继承与原始块解交错

实验设备接入宿主已解析TDMS式段头和元数据，需Go可导入的原始通道读取包，恢复跨段省略的索引与通道顺序，不做文件管理或波形显示。每段有唯一递增段号、大小端标志、newList标志、有序通道更新及原始字节；通道身份是宿主给的非空UTF8路径，不解析路径文本。每更新含路径及三选一索引：new给类型i16/i32/f64bits/timestamp与每chunk正样本数n；reuse沿用该路径最近一次new的完整索引；none表示本段该通道无原始数据但不删除最近new缓存。类型宽度分别2/4/8/16，f64bits只返回IEEE位型不经十进制转换，timestamp是先uint64亚秒分量再int64秒，两分量都按本段端序，精确秒值为seconds+fraction/2^64。本段每个活动通道的固定端序均须等于本段端序标志；首次new固定该路径的类型及端序，后续new可以改n但不得改类型或端序；缓存未见new即reuse须拒绝，不把另一个路径的索引借来用。newList=true时本段活动顺序恰为更新列表中索引非none的路径顺序，省略的路径不参与本段；false时继承上段活动顺序，已有路径保持位置，none将其从本段活动顺序移除，new/reuse使未活动路径按更新顺序追加；同段重复路径拒绝。若更新列表为空且newList=false，活动顺序与索引全部继承；若true则活动为空。声明raw布局为contiguous或interleaved，contiguous每个chunk按活动顺序先存一个通道全部n样本再下一个通道；interleaved要求所有活动通道n相同，按样本序号轮流存各通道一个值，不要求各通道类型宽度相同。原始区是完整chunk的连续重复，须长度为单chunk字节数的整数倍，不允许短尾；活动为空只允许空原始区，原始区空时仍可提交元数据。每段全部校验通过才提交缓存、活动顺序与通道样本，坏raw、错误复用或类型冲突整段不生效，修正后可以原段号重试，不能产生重复样本；已提交段号再次输入一律拒绝。为每路径累积稳定的逻辑样本号，暂停出现在通道未活动的段不会补零，新n不会把旧样本重分块。提供按路径和逻辑半开样本号区间的读取句柄，返回值和原段/chunk/物理字节来源，索引可按chunk保存，不为全部样本各建一项；宿主提供不可变ReaderAt及原始区长度，不能全文件读入才能读一个样本。设置单段通道数、chunk数及元数据缓存预算，声明超限或寻址乘法溢出在读取前拒绝。用独立构造字节测试无元数据连续段、顺序改变、none后reuse重入、不同宽度交错、两种端序的负timestamp、改变n、空raw提交以及失败段重试，附真实接入宿主调用示例。只实现题面语义，不要求TDMS容器头、字符串通道或DAQmx。
