# maintsched — 检修库停机调度

为 ≤10 台设备选择整数停机区间，最小化总停机损失，并输出占用曲线。

## 模型约定

- 时域为整数时刻 `0..T-1`，`T = len(loss)`。
- 设备 `i` 停机占用**半开区间** `[s, s+dur)`，即占用时刻 `s .. s+dur-1`。
- 允许窗 `[start, end)` 为半开：起点 `s` 须满足 `start <= s` 且 `s+dur <= end`。
- 任意时刻同时停机的设备数 `<= k`。
- 总损失 = `Σ_t loss[t] * occ(t)`，`occ(t)` 为时刻 `t` 的停机台数（重叠按台数累计）。

## 用法

从 stdin 读 JSON，向 stdout 写 JSON：

```sh
echo '{"k":2,"loss":[4,2,1,3,5,2],"devices":[{"dur":2,"start":0,"end":4},{"dur":3,"start":1,"end":6},{"dur":1,"start":2,"end":5}]}' | go run .
```

输出字段：`cost`（最小损失）、`starts`（各设备起点）、`intervals`（半开区间）、
`occupancy`（占用曲线）。无可行解时 `ok=false` 且退出码为 2。

## 算法

- `Solve`：按时刻推进的 DP，状态为 `(started 位掩码, 各设备剩余占用时长)`，
  每时刻枚举可启动设备的子集（受 K 约束），回溯恢复调度方案。
- `Brute`：穷举所有起点组合，用于短时域核验。

## 测试

```sh
go test ./...
```

含半开边界用例（窗口右端、占用结束时刻）与 500 组短时域随机实例的
DP ↔ 穷举交叉核验（可行性、最优值、K 约束、占用曲线成本一致性）。
