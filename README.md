# 采集连接的流式属性帧与推送解复用

采集器把多条请求放到同一RESP连接，服务端穿插推送，且属性帧不占响应位置；按顶层值个数给请求配对会错把推送当作查询结果。为Node.js22采集宿主开发TypeScript可导入的字节解析与解复用包，离线喂入字节，不连接Redis、不做界面。只支持这里明确的RESP3子集：每个行头以CRLF结束；+和-后到CRLF前是simple字符串或simple错误的原始字节，内部不允许孤立CR或LF；:后为可选负号加无前导零十进制整数，范围int64，0合法且拒绝-0；_后必须立即CRLF表示null。$n后跟恰n个任意字节及CRLF为blob；$?启动流式blob，其后重复;n行头、n字节和CRLF，n>0，;0后只带行头CRLF即结束，不再有数据CRLF。*n为定长数组，%n为定长map的n个键值对，键和值均可为任意支持的值；*?和%?为流式数组/map，以.加CRLF结束，map结束必须恰成对；.和;不能在其他上下文出现。map按有序键值对保留重复键，不转JS对象也不以字符串化键去重。所有长度和计数只能无符号无前导零十进制，0合法，先用BigInt检查预算后再转安全索引，不接受负长或RESP2特殊null。|n是包含n对的属性前缀，键和值按同样值语法解析；整个属性块不是一个值、不消耗父容器名额，紧随的下一个实际值才携带它。允许连续属性块，按出现顺序串接pair而不覆盖重复键；属性可在任意容器的元素或键值前出现，其内容自身也可带属性，EOF留下未附着属性必须报截断，不能当成一条响应。>n为顶层推送，其载荷是n个值，n>=1，禁止嵌套推送；属性前缀若紧接推送则归该推送，不留给后一个普通响应。其余类型及流式属性/流式推送均unsupported。PushBytes接受任意Uint8Array片段，Next返回一条完整顶层普通值或push及其属性与物理半开范围，结构或计数错误为永久失败态；此前完整消息不撤回，当前半帧不交付，Finish区分干净边界与所有半行、半blob、未闭容器和孤立属性。blob值保留分块来源但逻辑内容等于各chunk拼接，不包含块头；可组装当前消息，不能保存所有已交付连接字节。宿主配置头行字节数、嵌套深度、当前消息节点数、属性pair数及叶字节总量上限，属性中的键值也计预算；每实际值计一个节点，数组/map/push自身也计一个，属性块自身不计节点但其全部键值计入。顶层值深度1，容器子值及属性键值在当前深度加1，附着的实际值仍用当前深度，连续属性块不自动增加深度；声明定长超限读载荷前拒绝，流式逐块累计检查，不把无限?当免限。另有Register(ticket)、Cancel(ticket)和Consume接口；普通顶层值按登记次序匹配一个ticket，即使值为错误或null也消耗一项；push独立交给宿主不消耗。Cancel不删除已发请求的位置，而留墓碑，后续该位置普通响应标为discarded并携带ticket，不得移给下个请求；同ticket不准再次登记，取消已完成或未知ticket报错且不改队列。无等待ticket的普通值返回unsolicited，不伪造票号。只有完整消息解析后才更新票据队列，遇到半帧错误不能提前完成ticket。交付真实采集宿主调用例及独立一次性树参考，核对全部切块点的类型树、属性归属、推送序列与票据结果；覆盖map键为数组或blob、连续属性和嵌套属性、流式map奇数项结束、属性后立即结束标记非法、blob内含CRLF和伪>、多chunk跨行头、两请求之间push、取消首请求后普通错误到达、无票据响应及预算恰足/差1。只承诺此子集，不宣称所有RESP3类型或线上服务兼容。
