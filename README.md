# inventory/reservation

事件溯源的库存预留库（仅 Go 标准库）。

## 语义约定

- **跨批次预留**：一次预留可横跨多个货位批次；任一批次不足则整体失败，不做部分扣减。
- **事件序决胜**：所有状态迁移进入带严格递增 `Seq` 的只追加日志，到期/确认/撤销冲突按事件顺序裁决。
- **过期含截止**：`t >= ExpireAt` 即视为过期；截止时刻的确认会触发惰性过期并返回 `ErrExpired`。
- **确认原子转移**：确认一次性把该预留全部批次的占用转为转出（`Reserved -> Confirmed`）。
- **请求ID绑定参数**：同一请求 ID 以相同参数重试幂等返回原结果（含失败结果）；参数不同返回 `ErrRequestConflict`。
- **重新领取有新代**：每次成功预留获得严格递增的 `Generation`，过期/撤销后重新领取代次更大。
- **重放守恒**：`Replay` 逐事件重放并在每个事件后校验逐批守恒 `Initial == Available + Reserved + Confirmed`；`Snapshot` 可与实时状态对照。
