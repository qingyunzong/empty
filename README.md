# 购物车拆单优化器

将至多 **14 件商品**拆分为多个订单，使**总实付最低**；实付并列时**订单数最少**。
输出拆分方案与**券证书**，并用**小件数暴力枚举分区**做全量对照。

纯 TypeScript + Node.js 内置库（`node:test` / `node:assert`），零运行时依赖。

## 计价模型（金额单位：分，全程整数）

- **满减**：每单 `floor(小计 / step) * off`，封顶 `cap` —— 逐单向下取整
- **运费**：折后金额 `>= freeAbove` 免运费，否则收 `fee`
- **券**：小计满 `minSpend` 可抵 `value`；每单限用一张，**每张券全局限用一次**；券不使商品应付为负
- **单订单实付** = `max(0, 小计 - 满减 - 券) + 运费`

## 算法

- **主求解器**（`src/solver.ts`）：子集 DP。状态 `dp[商品掩码][券掩码] = (实付, 订单数)`，
  转移枚举包含最低位商品的子集作为一个订单并选一张未用的券（或不用），
  按 `(实付, 订单数)` 字典序取最优。复杂度 `O(3^n · (c+1))`，`n ≤ 14`。
- **暴力对照**（`src/brute.ts`）：限制增长串枚举全部集合划分 × 券的单射分配，
  用于 `n ≤ 8` 时与 DP 结果逐一比对（含 Bell 数规模校验）。
- **券证书与独立核验**（`src/certificate.ts`）：记录每张券去向（哪个订单/未使用、
  门槛是否满足），并独立重算：划分合法性（每件商品恰好一次）、逐单金额、
  券全局限用一次、证书与方案一致。

## 使用

```bash
npm test    # 编译 + 运行全部测试
npm start   # 编译 + 运行 14 件商品演示（打印拆分方案与券证书）
```

## 目录

```
src/types.ts        领域类型（商品/规则/券/订单/证书）
src/pricing.ts      单订单计价（满减向下取整、运费、券）
src/solver.ts       子集 DP 求解器（实付最低 → 订单最少）
src/brute.ts        暴力枚举分区对照（小件数）
src/certificate.ts  券证书独立核验
src/sample.ts       14 件商品演示数据
src/main.ts         演示入口（打印拆分与券证书）
test/               node:test 测试
```
