# 倾斜连接的共享桶拆分

数据平台需要在运行等值连接前，把重键的笛卡尔积分给固定数量的工作槽。规划器通过可导入的Go包请求拆分计划，并用路由接口发送实际记录，请实现该包及测试。输入左右两侧每个键的非负整数行数、工作槽数P与每槽允许处理的行对上限B，整数均不超过10^12，键按UTF-8字节排序。对每个两侧均非零的键选择正整数r、s，r不大于左行数、s不大于右行数，r*s不超过P；左右记录分别按稳定行号模r、模s分桶，每个左桶复制到s个格子，每个右桶复制到r个格子。一个格子的最坏行对数是ceil(L/r)*ceil(R/s)，不得超过B；格子不能与其他键共享槽。跨键总格子数不超过P，目标首先最小化总传输行数sum(L*s+R*r)，其次最小化总格子数，最后按键序比较(r,s)序列取字典序最小。无可行方案返回结构化原因，不输出部分计划。P为1至128，B为正整数，键不超过64，同一侧键重复视为输入错误；行号范围为0至该侧行数减1，两侧不同时出现的键视另一侧为0；键两侧均非零才分配槽。键不超过64，必须以精确整数运算给出全局最优计划，不能逐键贪心。提供根据计划路由左右行号的接口，并验证每一对同键记录恰好在一个格子相遇。测试用小实例枚举对照全局目标、重键倾斜、乘法越界、大整数上取整、空侧及预算恰好可行的边界。
