# tanksim

多水箱模拟库（仅 Go 标准库）。水箱间以**精确有理流速**（`math/big.Rat`）
进出，阈值触发切换阀门，空/满边界限制流量。

## 语义

- **精确分数**：所有时间、液位、流量均为 `*big.Rat`，事件驱动推进，
  无任何浮点误差。
- **阈值触发**：`CondRising`/`CondFalling` 为边沿触发（严格跨越阈值；
  初始已满足的条件在 t=0 结算）；`CondValveOpen`/`CondValveClosed`
  为状态触发，可在同一 tick 内级联。
- **同 tick 结算**：每次结算迭代先收集全部满足条件的触发器，再统一
  应用所有阀门切换（按声明顺序应用）。
- **边界限流**：空水箱净流出、满水箱净流入时，按缺口比例精确缩减
  相关阀门流量，迭代至不动点（守恒）。
- **零时间循环**：结算在同一时刻重复出现相同阀门配置即判定死循环，
  返回 `*ZeroTimeLoopError`，携带时间、逐迭代触发序列与阀门状态等
  证据（`Trace`）。
- **快照重放**：`Snapshot()` 可 JSON 序列化，`Restore` 后继续运行与
  一次性运行产生完全一致的事件序列与终态。
- **微步进对照**：`Step(dt)` 提供定步长积分器，步长缩小时收敛到事件
  驱动结果（测试中以 dt=1/1000 对照，误差在容差内）。
