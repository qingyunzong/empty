# conveyor — 环形传送带模拟库

离散时间（tick）传送带模拟：多条环形传送带通过容量有限的转接口互联，
包裹按目标口取出，支持故障暂停、快照恢复与包裹位置核验。

## 单带模型

- 每条带是 N 个槽位的环，每槽容量为 1，槽 0 为投件口。
- 每 tick 顺序：**移动 → 投件 → 取件**（多带系统在移动后插入**转移**阶段）。
- 移动：所有包裹同时前进一格，末槽绕回槽 0。
- 投件：投件口空闲时从注入队列取一个包裹放入；堵塞时在队列中排队（FIFO）。
- 取件：到达目标口（`Dest == (所属带, 槽位)`）的包裹离开系统，进入输出流。
- 故障：任一槽位标记故障则**全带暂停**（不移动、不投件、不取件、不参与转移），
  故障清除后恢复。

## 多带与转接口

- `TransferLink{From, To, Capacity}` 连接两条带的端口；`Capacity` 是转接口
  待决缓冲容量（0 表示无缓冲，被堵包裹留在带上循环）。
- 包裹到达转接口源槽且其目标带不是当前带时被分流：目标槽空则直接转移，
  否则进入待决缓冲，缓冲满则留在带上继续循环。
- 每 tick 每个转接口最多转移一个包裹；候选在转移前一次性收集，
  因此**同一包裹同 tick 不会重复转移**（跨多条带需多个 tick）。
- 多个转接口竞争同一目标槽时，**包裹 ID 小者优先**，败者进入待决缓冲。
- 单带故障只暂停本带，其他带照常运行；与故障带相连的转移暂时挂起。

## 快照与核验

- `Snapshot()` / `Restore()`：深拷贝保存/恢复全部状态——各带槽位、注入队列、
  故障标记、跨带待决缓冲、输出流与 tick 计数；形状不匹配时 `Restore` 报错且不改动系统。
- `Locations()`：返回每个包裹 ID 的唯一位置（带槽 / 队列 / 转接缓冲 / 输出），
  若同一包裹出现在两处则报错，用于守恒性与唯一性核验。

## 测试

```sh
go test ./...
```

测试要点：

- `TestReferenceModel`：独立的列表参考模型逐 tick 对比真实实现（含绕回、故障、随机投件）。
- `TestWrapAround`：显式验证末槽 → 槽 0 的绕回。
- `TestConservationSingleBelt` / `TestPackageUniqueLocation`：随机场景下逐 tick
  校验包裹守恒（注入数 == 带上 + 队列 + 待决 + 输出）与位置唯一。
- `TestTransferTieBreakByPackageID` / `TestNoDoubleTransferSameTick`：ID 决胜与同 tick 不重复转移。
- `TestSnapshotRestore`：快照后继续模拟与恢复后重放结果完全一致（含跨带待决）。
