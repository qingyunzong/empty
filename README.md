# 采集对象的共享虚表与缺省字段

`dataeng` 是一个只读的、可被 Go 宿主导入的 FlatBuffers 子集读取包。模式由宿主以
已编译的 `Table`/`Field` 定义提供，全程不调用 `flatc`，也不要求与完整 FlatBuffers
兼容。

## 支持的子集

- 标量：`u8`、`i32`、`i64`，全部按小端解码，按自身宽度做绝对对齐。
- 引用：`string`、表引用，以及 `vector<u8>`、`vector<i32>`、`vector<i64>`、
  `vector<table>`。
- 不支持 struct、union、嵌套 vector；表类型可以递归（含自引用环）。
- 缓冲开头是一个 `uint32` 相对偏移，指向 4 对齐的根 table。

## 校验语义

`Open` 在返回句柄前，会从根出发验证所有模式已知、可达的对象；未知虚表槽只做
区间检查，不猜测类型、不校验字段宽度。

- 每个 table 首 `int32` 是带符号距离 `d`，虚表起点 = table 起点 - `d`，`d` 可负，
  因此虚表可以位于对象之后。
- 虚表依次是 `uint16` 自身长度、`uint16` 对象长度、各字段 `uint16` 对象内偏移；
  虚表长度至少 4 且为偶数，对象长度至少 4，两个范围都必须在缓冲内。
- 字段槽号由模式固定。槽在虚表外或偏移为 0 即缺失：标量返回模式缺省值并标记
  `Defaulted`，引用标记为 null。
- 所有非零虚表槽起点必须落在 `[4, 对象长度)` 内；字段非零偏移至少 4，值宽不得
  超出对象长度。
- 引用位置存 `uint32` 正偏移，目标按 32 位算术 `引用位置 + 偏移` 计算（后向引用
  在 32 位回绕是合法的），目标必须 4 对齐且在缓冲内；存储 0 不表示 null，直接
  拒绝；null 只能通过省略字段表达。
- string 目标先 `uint32` 字节长，再是严格 UTF-8 正文和一个 NUL 终止字节，正文
  允许嵌入 NUL。
- vector 目标先 `uint32` 元素数，元素区连续排列；`i64` 元素区需 8 对齐；
  `vector<table>` 的每项以该条目自身位置为偏移基准。
- table、虚表、string、vector 都可以被多处共享，不使用全局区间互斥。按
  “对象位置 + 模式类型”缓存验证结果；同一位置被当作不同表类型或不同 vector
  元素类型时拒绝。原始缓冲在验证和读取期间都不会被修改。

## 限额

`Limits` 限制独立 table 数、按独立对象累加的 vector 元素总数和 string 字节总数；
重复引用只计一次。超过限额时，在该对象进入缓存（即“分配”）之前拒绝，缓冲不会
被部分记账污染。`<= 0` 表示不限制该资源。

## 读取

- `Open(root, buf, limits)` 返回 `*Handle`；宿主保证借用缓冲在句柄存活期内不可变。
- `Handle.Root`、`Handle.Get(steps...)` 与 `Value.Get(steps...)` 按字段名和 vector
  下标导航。
- 每个 `Value` 带有 `Present`、`IsNull`、`Defaulted`、`Path`，以及实际字节范围：
  内联标量用 `Range`；引用类值的 `Range` 是偏移字本身，`RefRange` 是被引用对象。
- 标量用 `U8/I32/I64`，字符串用 `StringValue`，vector 用 `VectorLen/Element` 或
  `U8Elements/I32Elements/I64Elements`。这些切片访问器返回拷贝，包不会把可修改的
  底层切片交还给宿主。

## 示例与测试

- `cmd/collectorhost` 是采集宿主调用例：手工逐字节构造消息、设置限额、按路径
  读取并打印缺省来源和字节范围，运行：`go run ./cmd/collectorhost`。
- 测试用独立字节构造覆盖：旧短虚表、虚表位于对象之后、多对象共享虚表、共享
  string、缺失与显式 0 的区别、非零空引用、超长 vector，以及对齐、共享类型冲突、
  未知槽、嵌入 NUL、vector<table>、递归环和只读拷贝等边界：`go test ./...`。
