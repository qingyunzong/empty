# 可合并分位摘要的秩误差证据

遥测查询宿主需要可导入的Go分位摘要，每层样本权重为2的层号次幂，容量K为大于等于2的偶数；新int64观测进入第0层。某层超过K时排序，取最前偶数个样本配对，调用方注入的二选一位决定每对保留较小或较大者并提升一层，至多一个余样留原层，逐层直到合规；每次同层压缩使用同一个选择位，压缩序号全局递增并与层号传给注入器；本次累计秩误差界加2的层号次幂。摘要只保留各层样本、总输入数、误差界和压缩序号，不能保留全部原流；合并同K摘要拼合各层并压缩，误差界先相加，不能承诺不同合并树样本完全相同。查询<=x的估计秩为各保留样本权重和，输出截在[0,N]的估计加减误差区间，须包含真实秩。用全量计数核验每个不同值及可表示的前一整数、极值、重复观测和随机分片合并，所有计数使用任意精度整数。
