# subtitle-layer-scheduler

字幕显示调度：输入半开区间 `[start, end)` 与优先级（收益），在最多 `k` 层
（同层互不重叠，端点相接不算重叠）内选出总收益最大的显示集合，并输出层分配证书。

## 规则

- 条目至多 20 条，`k >= 1`；`start < end`，ID 唯一。
- 目标字典序：总收益最大 → 选中条数最少 → 选中 ID 排序列表字典序最小（并列 ID 序）。
- 层分配确定性：按 `(start, end, id)` 时序把每条放入编号最小的可用层。

## 算法

- `src/solve.ts`：按时序的轨道 DP。状态 `(i, 各层空闲时刻升序元组)`，转移为跳过
  或放入任一空闲层；随后按 ID 升序“能选则选”重建出字典序最小的最优集合。
- `src/brute.ts`：核对用暴力枚举。区间图是完美图，子集可 k 层着色当且仅当任意
  时刻重叠深度 `<= k`（扫描线求深度），枚举全部 `2^n` 子集取同一目标序最优。
- `src/model.ts`：半开重叠判定、输入校验、证书校验（分层合法 / 同层不重叠 / 收益一致）。
- `src/cli.ts`：命令行入口，支持 `--correct id=start:end` 更正时码后重算。

## 使用

```sh
npm test                 # 编译并运行全部测试
npm run build            # 仅编译到 dist/
node dist/src/cli.js examples/sample.json
node dist/src/cli.js examples/sample.json --correct s04=4.5:6.5
```

## 备注

- 仅使用 Node.js 内置模块（`node:fs`、`node:test`、`node:assert`），无运行时依赖。
