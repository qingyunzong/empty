# 索引动画帧合成组件

C++20 组件 `dlks::FrameCompositor`，把带局部调色板的已解码索引帧合成到统一画布上。

## 模型

- 构造时给定画布尺寸与背景 RGBA，初始画布整体填充背景色。
- 每帧（`IndexedFrame`）携带局部调色板、索引缓冲、透明索引（负值表示不透明）、
  目标矩形 `Rect` 和处置模式 `DisposalMode`：
  - `none`：显示后保留；
  - `restore_bg`：下一帧绘制前把帧矩形恢复为背景色；
  - `restore_prev`：下一帧绘制前把帧矩形恢复为本帧绘制前的内容，
    因此绘制前先按行保存该矩形区域。
- 绘制时遇到透明索引跳过该像素，底图保持不变；其余索引查局部调色板覆盖。
- 目标矩形越界、索引/调色板尺寸不符、索引或透明索引超出调色板时，
  `append_frame` 整帧拒绝并返回 `false`，已保存帧不受影响。

## 播放与 seek

- `render_next()` 顺序播放：先应用上一帧的待处置，再绘制当前帧。
- `render_frame(i)` 按帧号 seek：从最近的检查点（含键为 -1 的空白画布检查点）
  重建，检查点数量受 `max_checkpoints` 限制，超限时淘汰最旧检查点。
- 检查点只保存“已显示帧”的画布及其待处置状态，绝不保存处置后的画布，
  因此回退 seek 不会把已处置画面误当作显示帧。
- `reset()` 回到空白画布但保留检查点，便于继续 seek。

## 构建与测试

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

测试包含独立的朴素参考合成器，在交叠透明帧与三种处置模式交替的随机序列下，
逐像素比对顺序播放、200 轮随机/回退 seek（检查点上限取 1/2/3/8）与参考结果，
并覆盖透明索引保持底图、两种恢复处置、越界整帧拒绝、reset 后重建等场景。
