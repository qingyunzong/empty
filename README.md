# bcchk — 字节码保护区检查器

对字节码指令流的半开保护区间 `[start, end)` 做校验、求每条指令的有效处理器链，并支持模拟插入指令后的端点重映射。

## 语义

- **半开区间**：`[start, end)` 覆盖指令 `start .. end-1`。
- **优先序**：内层（跨度小）区间优先；跨度相同（同层）时声明序号小者优先。
- **交叉拒绝**：两区间重叠但互不包含（crossing）即报错。
- **重映射**：在 `at` 处插入 `count` 条指令后，`start >= at` 则 `start += count`，`end > at` 则 `end += count`。严格落在区间内部插入时新指令被保护；在边界插入则新指令在区间外。

## 使用

```sh
go run . spec.json
```

```json
{
  "length": 12,
  "ranges": [
    {"start": 0, "end": 10, "handler": "Outer"},
    {"start": 2, "end": 6, "handler": "Mid"}
  ],
  "insert": {"at": 4, "count": 2}
}
```

输出每条指令的处理器链（内层在前，`>` 分隔），插入指令后打印重映射区间并再次输出全链。打印前会将索引表结果与逐区间扫描参考逐项核验，不一致即报错退出。

## 测试

```sh
go test ./...
```

`ranges` 包测试包含：嵌套/并列接受、交叉与退化区间拒绝、链优先序、端点重映射边界，以及两个随机化属性测试（索引表 vs 逐区间扫描参考一致；重映射前后链保持）。
