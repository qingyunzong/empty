# reactive-tx：事务式依赖登记的响应式状态库

TypeScript + Node.js 内置库（`node:test` / `node:assert`），零运行时依赖。

## 核心语义（src/reactive.ts）

- **读取事务结束时一次登记依赖**：`Derived.runTransaction` 在计算期间只把读取收集进
  `pendingDeps`，不触碰任何源的订阅列表；`fn` 成功返回后才由 `commitDeps` 原子地完成
  “退订多余 + 订阅新增”，一次生效。
- **计算抛错不改变旧依赖**：抛错时丢弃 `pendingDeps`，已提交依赖、缓存值原样保留，
  节点保持 dirty，恢复后可基于旧依赖重算。
- **销毁与重算交错不留订阅**：`dispose` 立即退订全部依赖并置标志；通知循环基于快照
  迭代，`_invalidate` 与 `commitDeps` 对已销毁节点直接跳过——即使在自身计算事务中
  销毁，提交阶段也不会登记任何订阅。
- **动态条件切换清理依赖**：`cond ? a : b` 切换分支后，不再读取的源在提交阶段被退订，
  后续写入不再触发重算（测试用求值计数验证）。

## 对照实现（src/variants.ts）

- **全量重算** `FullRecomputeRoot`：不做依赖追踪，任何写入重跑全部 effect。
  对照显示事务式只重算受影响节点（无关 effect 运行次数 1 vs 2）。
- **引用计数** `RefComputed`：边读边订阅（retain/release）。对照显示：
  - 抛错时旧依赖已释放、新依赖只订阅一半（`b` 丢失、`c` 残留），而事务式旧依赖不变；
  - 归零时级联释放上游，对应事务式中 `dispose` 沿链精确退订。
