# 抓取任务的robots策略缓存

网页采集服务需要可导入的Go访问策略组件。调用方提供抓取URL、产品标识、注入时钟、正缓存有效期及获取robots文本的函数；按scheme、主机和端口缓存，取得时刻起到期时刻前有效，恰到期须刷新，同一来源并发刷新共享一次。文本按行解析：连续User-agent行及其后Allow或Disallow行构成一组，规则后再出现User-agent即开始新组；空行和#后注释忽略，其他或缺冒号行忽略。选择产品标识中最长的不区分ASCII大小写组名，同长度组合并；无匹配用星号组。比较URL转义路径和可选查询串的原始字节，不解码百分号；星号匹配任意字节，末尾美元符锚定末尾，非星号规则字节数最长者胜出，平局Allow胜出，空Disallow忽略，无匹配默认允许。获取失败时该次刷新的所有等待者均返回不可判定，失败不缓存，后续请求可重新刷新；等待者取消只结束自身等待，不取消共享获取。测试刷新竞态、组合同长、编码路径和失败恢复。
