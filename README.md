# 实体融合因子的精确消元与容量边界

数据融合管线用相互重叠的候选匹配因子表示不确定性，不能把共享变量的局部置信度直接相乘后当独立后验。为宿主开发Go可导入的有限域因子计算包，输入至多40个有唯一ASCII ID的变量，每变量域为按给定次序排列的1..16个不同字符串；若干非负有理势因子，因子给有序且不重复的变量scope及稀疏赋值表，未列项精确为0，重复赋值、未知变量或域外值拒绝。空scope是标量，因子列表空时乘积为1。查询指定互不重复的保留变量列表Q和部分证据E，Q与E不得交叠；目标为U(q)=对所有既非Q也非E变量的赋值求和，求和项是代入E及q后全部势因子之积，返回按Q给定轴顺序排列的规范稀疏U、Z=sum(U)及U/Z；Z=0返回明确矛盾和零U，不产生NaN或伪造均匀分布。分数全程任意精度最简有理数，不能float64中转；变量未出现在任何因子也属于模型，隐藏的这种变量应贡献域大小，不能悄悄丢失。必须采用变量消元，不能枚举全部40变量的世界。代入证据后从当前因子scope建立无向图，每scope成团，包含所有未被证据固定的孤立变量，证据变量不入图；每轮只在隐藏变量中按新增填充边数最少、其当前邻居域大小之积最小、ID ASCII序最小依次选择。消去v时相乘所有含v因子，再沿v求和，加入所得因子并使其scope成团，保留变量不消去；若没有含v因子，用常数1的一元因子表示它再求和。给出每轮v、涉及因子scope、结合scope、消后scope、填充边及所需结合域单元数的轨迹，必须来自实际执行。宿主给正整数cellBudget，每轮在构造结合表前精确计算结合scope全部域大小之积，超过预算返回needsBudget、该变量、精确requiredCells和已执行消元前缀，不返回概率，也不能把预算不足称为矛盾；即使因子稀疏也按这个公开稠密容量上界检查，零因子不提前跳过该检查。最后剩余因子相乘并补齐Q中未出现的变量轴，同样先按Q域乘积检查预算，超限的variable标为final。单轮可采用稀疏乘法，但不可更改给定消元次序或依数据零值改变预算判定。输入与已返回的轨迹不可被后续查询修改；同一模型更换证据须重新限制原因子，不能沿用已消元的残表。提供融合宿主例及独立全世界枚举参考，在小域核对未规范化U、Z、概率、轴顺序及轨迹选择；覆盖因子scope轴序相反、两个因子共享两个变量、标量0、空因子集、隐藏孤立变量、Q空、证据矛盾、断开的两部分和预算恰足/差1。构造40变量二元链且仅保留末变量，给足每轮结合表但远少于2^40的预算，验证可完成且没有枚举全世界。
