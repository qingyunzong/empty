# quote-invert-cli

从舍入后金额反推整数原价区间的报价 CLI。

每个折扣步骤为正有理数 `p/q`，前向计算为 `y = roundHalfEven(x * p / q)`
（最近偶数舍入 / 银行家舍入）。给定折扣链（1–8 步）与最终舍入金额，
CLI 精确反推出所有满足条件的整数原价，输出互不交叠的闭区间；
原价定义域为 `[0, 10^12]`。全部使用 BigInt 精确运算，无浮点误差。

## 使用

```bash
npm run build          # 编译 TypeScript 到 dist/
npm run quote -- 150 3/4 9/10
# 或编译后直接运行
node dist/src/cli.js 150 3/4 9/10
```

选项：

- `--max N`：原价定义域上界（默认 `1000000000000`）
- `--verify-limit N`：低价域逐值前向核验上限（默认 `1000000`，`0` 跳过）
- `--json`：JSON 输出
- `-h, --help`：帮助

## 测试

```bash
npm test
```

测试内容：最近偶数舍入（含平局取偶）、单步原像与暴力枚举对照、
1–8 步随机链与逐值前向计算全量对照、定义域 `10^12` 截断、
低价域逐值核验、CLI 参数解析与端到端输出。

## 结构

- `src/core.ts`：舍入、单步原像、区间合并、链式反推、低价域核验
- `src/app.ts`：CLI 主逻辑（纯函数，返回退出码与输出文本）
- `src/cli.ts`：可执行入口
- `test/`：node:test 测试
