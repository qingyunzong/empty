# 采集基因型数组的等位索引投影

基因数据接入宿主要在重排、合并或去掉部分等位项后同步变更基因型及其概率数组，请实现可导入Go索引转换包，只处理题面定义的数据表示，不做生物学判定。源有N个等位项，索引0是参考项，目标有M项，调用方给每个源索引映到目标索引或drop的映射；0必须映0，其他项不能映0，目标索引须恰好覆盖0至M-1，允许多个源非零项合并。倍性P为1至16，N/M均为1至64。概率数组按所有长度P的非降源索引元组排列，元组(a1..aP)的零起始位置为sum(i=1..P) C(ai+i-1,i)，C(n,k)在n<k时为0；总长C(N+P-1,P)。实现任意精度rank和unrank，不得转float或先枚举全组合，给无效元组与索引明确错误。对可选完整概率向量，每项是以十进制大整数分子和正分母表示的既约非负有理数，零只能表示为0/1且总和为1；每个源元组映射后含drop则其概率归入丢弃质量，否则重新排序目标索引后累加到目标rank。输出保留质量、丢弃质量及除以保留质量后的目标概率；保留质量为0时返回undefined概率状态，不能给全零概率冒充分布；输入概率字段整体缺失则目标也缺失，但不得编造质量。另转换GT字符串，恰P个索引或点号，以斜杠或竖线连接，原有顺序与分隔符保留，drop项变点号，不能按概率元组的非降规则重排GT。源或目标组合数超过调用方正整数预算时，转换完整向量必须在分配或遍历概率输入前拒绝，但rank/unrank仍支持巨大组合空间；GT索引只接受无前导零的十进制非负整数，点号仅为单个字符；源长度不符、非法有理数、GT越界或映射不闭合整次拒绝。交付宿主调用例和测试，以小N/P全组合参考核对排列、合并导致多对一基因型、drop后归一化、零保留质量、部分缺失GT与混合分隔符，并用超过2^53的rank往返验证精确寻址。
