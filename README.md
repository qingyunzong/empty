# 采集载荷的紧凑字段差与容器半字节

采集到的结构载荷把字段标识差和类型挤在同一个字节里，布尔值没有单独的值字节，短列表的长度也放在类型旁边。实现可导入的Go包，供载荷接入调用，只解码一个值，不解析外层网络帧。变长整数是无符号LEB128，32位最多5字节且第5字节只使用低4位，64位最多10字节，非最短编码拒绝。zigzag把该位宽的无符号值逻辑右移一位，再异或其最低位的算术负值；结果超出目标有符号范围则失败。结构的上一字段标识从0起。字段头高4位为1至15时，新标识等于上一标识加这个差，低4位是类型。高4位为0且低4位不是0时，低4位是类型，后面用32位zigzag写出绝对字段标识。标识必须为正且严格大于上一标识。低4位为0表示结构结束，此时高4位也必须为0。类型1和2分别是真和假，不再读取值字节。类型3再读1字节。类型4、5、6分别用16位、32位和64位zigzag变长整数，不是定宽整数。类型7再读8字节小端float64，保留NaN、无穷和负零。类型8再用32位zigzag读非负长度和这么多原始字节。类型9和10的头一字节高4位为0至14时，该数字就是元素个数，低4位是元素类型；高4位为15时，低4位仍是元素类型，后面再用32位zigzag读非负个数。类型11先用32位zigzag读个数；个数为0时编码就是单字节0，不再读类型字节，个数大于0时随后一字节的高4位是键类型、低4位是值类型。类型12是嵌套结构。列表、集合和映射的元素或键值类型不能是0、1或2；结构字段则允许1和2。模式由调用方给出：结构字段按标识列出类型，容器写明元素类型。缺少字段、出现模式以外的字段、类型不符，或值结束后仍有字节，都失败。嵌套深度、容器元素数和类型8的长度超过宿主预算时，在数量已知后拒绝，不按声明分配。切块可以停在变长整数或值的中间；Finish时值未完成则失败。失败不交付半个值，组件停止。测试独立编码，覆盖布尔字段、标识差大于15、长度0至14的列表、空映射、小端float64、容器中的布尔类型声明，以及过长变长整数。期望值不得调用被测解码器生成。
