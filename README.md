# interval_newton — 验证型区间牛顿法

对有理系数多项式在给定有理区间 `[a, b]` 内找全部实根，输出宽度小于
`eps` 的有理区间包，每个区间包恰含一个根。全程使用
`fractions.Fraction` 精确区间算术（含导数区间求值），牛顿步与二分回退
结合，保证终止。

## 用法

```
python -m interval_newton COEFFS_FILE INTERVAL EPS
python -m interval_newton COEFFS_FILE A B EPS
```

- `COEFFS_FILE`：系数文件，首项（最高次）在前。支持空白分隔的有理数
  （`1 0 -2` 表示 x²−2，可用 `p/q` 或小数形式）或 JSON 数组。
- `INTERVAL`：搜索区间，形如 `[a,b]` 或 `a,b`；也可用两个独立参数。
- `EPS`：正有理数，输出区间包宽度上界（如 `1e-30`、`1/1000000`）。

输出：stdout 打印 JSON 区间表 `[[lo, hi], ...]`（有理数字符串），按左
端点排序；区间内无根时输出 `[]`。

退出码：`0` 成功；`4` 多项式含重根（含零多项式，经 gcd(p, p′) 精确判
定）；`2` 用法/输入错误。

## 方法

1. **可平方性检查**：`gcd(p, p′)` 次数 ≥ 1 则存在重根，以退出码 4 拒绝。
2. **区间牛顿**：`N = m − p(m)/p′([lo,hi])`（区间扩展）。`0 ∉ p′([lo,hi])`
   时 `[lo,hi]` 内所有根都在 `N` 中，故取交不丢根；交集为空即验证排除。
   牛顿迭代向外吸附到 `eps/16` 有理网格，仅加宽区间包且约束分母规模。
3. **二分回退**：`0 ∈ p′([lo,hi])` 或收缩不足 10% 时二分，保证几何收
   敛、必然终止。
4. **精确根命中**：中点/端点处 `p(x) = 0` 精确成立时记录退化区间
   `[x, x]` 并精确降阶（deflate）后继续。
5. **认证输出**：宽度 `< eps` 且端点严格变号（存在性）且导数区间不含
   0（唯一性）且端点非已记录精确根，才输出区间包——每包恰含一根。
