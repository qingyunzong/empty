# 查询血缘的按基数计数与精确贡献分摊

## Go 包用法

`dataeng.Compile` 会复制并校验输入图，随后可重复调用 `(*CompiledGraph).Shapley`：

```go
g := &dataeng.Graph{
    Facts: []string{"a", "b"},
    Root:  "and",
    Nodes: []dataeng.Node{
        {ID: "and", Kind: dataeng.NodeAnd, Children: []string{"a", "b"}},
        // DECIDE(a, 1, 0) 可作为事实 a 的布尔字面量。
        {ID: "a", Kind: dataeng.NodeDecide, Variable: "a", Then: "a-one", Else: "a-zero"},
        {ID: "a-one", Kind: dataeng.NodeOne},
        {ID: "a-zero", Kind: dataeng.NodeZero},
        // 同理构造 b。
    },
}

compiled, err := dataeng.Compile(g)
if err != nil {
    return err
}
result := compiled.Shapley()
```

`ShapleyResult.Facts` 对每个事实返回完整的 `AWhenFalse`、`AWhenTrue` 和
`*big.Rat` 贡献；`RootSupport` 与 `CompiledGraph.Supports` 返回结构支持集。
所有系数和阶乘均为 `math/big` 整数，贡献为规范有理数，负贡献不会截断为 0。

## 算法边界

- 合法图限制为 60 个唯一事实、5000 个唯一节点，支持集用 64 位掩码表示。
- AND 子节点支持集两两不交，因此节点多项式通过卷积合并；空 AND 为常量 1。
- DECIDE 的真分支先按该节点自由支持集补齐 `(1+z)^d`，再乘 `z`；else 分支只补齐。
- 固定决策变量时只选择对应分支，但另一分支独有的其余变量仍按自由变量补齐。
- 根结构支持集之外的事实同样补齐 `(1+z)^d`，因此每个 A 数组都覆盖其余全部事实。
- 每次求值的缓存按“节点 + 当前固定事实 + 固定值”隔离，共享子图只计算一次。
- 实现不枚举 `2^n` 个集合或 `n!` 个排列；测试中的全赋值参考只用于 n ≤ 12 的独立核对。

数据血缘宿主已把一个输出事实的存在条件编译成决策与可分解合取DAG，需要为每个输入事实分摊贡献，不能把重复出现的同一事实当独立证据。开发Go可导入的精确Shapley包，事实全集V有至多60个唯一ID，图至多5000节点且所有节点ID唯一。节点只准常量0/1、AND(children)、DECIDE(x,then,else)三种；图须无环，所有引用存在，DECIDE的x属于V且不得在任一孩子的变量支持集中，AND各孩子的支持集两两不交，空AND为1。节点支持集由结构递归定义：常量为空、AND取并、DECIDE取孩子并集再加x，不能通过逻辑化简删掉结构上出现但真假结果无关的变量。共享子图允许，支持条件编译时逐项检查，违反时拒绝整图，不能默默展开成全世界枚举。给定S子集V，将在S内事实设真、其他设假，得到布尔函数f(S)；允许否定效果，增加事实可能令结果消失。输出每个i的规范有理贡献phi_i=sum_{S子集V减{i}} |S|!*(n-|S|-1)!/n! * (f(S并{i})-f(S))，可为负，不能把负贡献截0，也不把结果当概率；n=0返回空映射。不得枚举2^n个集合或n!排列，必须在图上用按集合基数的整数计数多项式计算。对i分别固定0/1，令A_i,b[k]为其余n-1个变量中恰有k个真时使根为1的赋值数；用A_i,1-A_i,0加权得到phi。AND节点因变量不交而卷积；DECIDE节点两分支可能支持集不同，必须给每分支缺少的自由变量乘(1+z)的相应次幂，真分支再乘z，不能简单把两个多项式相加或忽略未出现变量。固定i后，若DECIDE的x=i只选相应分支，但原节点支持集中仅在另一分支出现的其余变量仍是自由变量，也须补(1+z)^d；根支持集外的V变量同样补齐。缓存按节点、被固定事实和固定值隔离，共享节点不重复当作不同事实；每个返回多项式的计数域必须明确是该节点原支持集减去被固定变量，不能因选择一边而悄悄改变计数的总体。整数系数和阶乘任意精度，禁止浮点计算后再约分。返回每事实的两个完整A数组及贡献，附结构支持集，宿主可独立复核卷积和分支补自由变量；图输入及返回材料不可被下一次求值修改。给血缘接入调用例，用n<=12的所有子集独立真值参考核对A及phi，而不是只检查总和；覆盖同一子图被多个决定分支引用、AND里重复支持被拒绝、决定变量藏在后代、分支支持不对称、固定变量后只存在于未选分支的变量、全集含根外无关事实、非单调负贡献及常量图。对所有合法结果验证sum(phi)=f(V)-f(空集)，无关事实贡献0；再构造60事实的AND与OR决策链验证可完成、对称事实贡献相等且没有枚举所有子集。
