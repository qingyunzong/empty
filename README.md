# 变更采集的最小行镜像与主键交换

数据库接入宿主需要可导入的Go行镜像应用包，表模式给各列固定int64或字节串类型及可空标志，并指定唯一非空主键列ID，单元格为null、int64或字节串，missing与null不同。事务批内update/delete按旧主键引用提交前行，同一旧行只能操作一次；未知列ID拒绝；before仅含已知字段且须与原行精确一致，update的after缺字段表示未变，显式unchanged标记也从旧行取值，insert则须给全列且不可含unchanged。仅本批update/delete引用的旧行先移除再发布更新及新增，因此允许两行交换主键或新增复用本批已删键；最终重复主键、缺行、坏before或类型不符整批回滚。返回净变化及每字段来自旧镜像或after的来源，旧快照不变。以构造最终完整表的独立模型验证主键交换、null替换、部分镜像和跨操作冲突，禁止按到达顺序覆盖丢行。
