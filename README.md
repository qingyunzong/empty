# asm_layout — 短/长相对跳转布局优化

汇编指令序列中，相对跳转有两种编码：短编码（默认 2 字节，位移范围
[-128, 127]，从跳转指令末尾起算）与长编码（默认 5 字节，无条件合法）。
每条跳转选择短或长会改变自身长度，从而改变所有后续指令的偏移，进而改变
其他跳转的位移。目标：在所有跳转合法的前提下，使代码总长度最短。

## 算法

- **迭代松弛**（`solve_relaxation`）：全部跳转先按短编码布局，找出所有
  非法跳转并改长，重算偏移，直到不动点。由于增长任何指令都不会缩小任何
  位移的绝对值，松弛增长的集合是任意可行解增长集合的子集，因此不动点即
  最优解。每一轮翻转记录为迭代轨迹。
- **全枚举核对**（`solve_optimal`）：跳转数 k ≤ 20 时枚举全部 2^k 种
  短/长组合，取合法且总长最短者，用于核对松弛结果的最优性。
- **偏移证书**：最终布局给出每条指令的偏移、长度、编码、位移与合法性，
  `verify` 可从编码选择重算并校验证书自洽。

## 构建与测试

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
cd build && ctest --output-on-failure
```

## CLI

```sh
./build/asmlayout_cli                 # 内置级联增长演示
./build/asmlayout_cli examples/cascade.asm
```

输入格式（每行一条，`#` 为注释）：

```
encoding 2 5 -128 127   # 可选，须在最前
fixed 125               # 定长指令
jump 3                  # 相对跳转到指令 3
```

输出：迭代轨迹、偏移证书、证书自检结果，以及（跳转 ≤ 20 时）全枚举
最优总长与松弛结果的对比。

实际测试结果见 RESULTS.md。
