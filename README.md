# dirdiff

目录差分库（仅 Go 标准库）。按稳定 ID 匹配条目，把路径变化输出为移动
而非删除+新建；输出为依赖有序的操作计划；环路移动经临时路径中转，且
临时路径绝不占用目标清单中的任何最终名称；逆差分在应用前核对目标版本。

## 设计

- `Manifest`：至多 `MaxEntries = 12` 个条目，ID 与路径各自唯一。
- `Diff(old, new)`：
  1. 仅存在于 old 的 ID → `delete`（最先发射，只释放路径）；
  2. 两边都有但路径/版本变化的 ID → `move`，按“目标路径已空闲”拓扑
     发射；出现环路时把环上首个移动暂存到 `.dirdiff-tmp-<id>`（不与任何
     最终名称、也不与当前占用路径冲突），随后继续；
  3. 仅存在于 new 的 ID → `create`（最后发射）。
- 每个操作携带 `Version`/`NewVersion`；`Apply`/`ApplyFS` 在变更前核对
  条目当前版本，不匹配即报错。
- `Invert(ops)` 逆序生成反向计划（create↔delete、move 反向、版本互换），
  应用逆差分同样先核对目标版本。
- `Materialize`/`Snapshot`/`ApplyFS` 在真实目录树上执行并回读验证。

## 验收

- 路径置换枚举：n=1..6 全枚举（873 个置换）+ n=12 固定种子随机 300 例，
  逐一验证计划可执行、临时路径不占最终名称、正向后等于目标清单、逆差分
  应用后恢复原清单。
- 真实目录树（`t.TempDir`）正向/逆向快照一致。
- 混合移动/删除/新建随机 200 例。
