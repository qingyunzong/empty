# 消息命令的长度与空字节结尾

消息采集遇到content-length时，正文里的空字节不再是帧结尾，结尾空字节还在长度之后。实现可导入的Go组件，供消息采集调用，不建立连接。帧以一行命令名开始，命令名只能是CONNECTED、MESSAGE、RECEIPT或ERROR。随后是头，每行是名字、冒号、可选一个空格和值，以LF结束。头名字不区分大小写，返回时用小写。空行结束头部。若有content-length，其值是无前导零的非负十进制，正文恰好这么多原始字节，之后必须还有一个0x00。没有content-length时，正文持续到第一个0x00，空字节本身不属于正文。同一帧的content-length只能出现一次。content-length大于宿主maxBody时，在头部结束且该值已知后拒绝，不按声明分配。其他头按原始顺序保留，允许重复。命令名和头必须是严格UTF-8，正文按原始字节保留。LF是唯一换行，CR失败。Push可停在正文中间；Finish时帧未完成则失败。失败停止组件，已交付帧保留。测试独立组帧，覆盖正文中的空字节、长度后缺少0x00、重复content-length、前导零和帧被切开。期望帧不得调用被测组件生成。
