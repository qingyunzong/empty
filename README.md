# logrec — 检查点日志恢复 CLI

从检查点版本和多个重叠日志段恢复日志：同序号同内容去重，缺口及异内容拒绝，
只应用检查点之后的连续前缀，并输出首个缺失序号及来源段。仅使用 Go 标准库。

## 段文件格式

每行一条记录：`<seq> <content>`（序号为无符号整数，内容可含空格）。
空行与 `#` 开头的行被忽略。

## 用法

```
logrec -checkpoint N segment1 segment2 ...
```

- 应用的条目（检查点之后的连续前缀）以 `<seq> <content>` 打印到 stdout。
- 首个缺失序号（下一个期望序号）打印到 stderr。
- 异内容冲突或缺口（缺失序号之后仍存在更高序号条目）以非零码退出，
  并报告首个缺失序号及来源段（跨越缺口的段，或缺口两侧最近的段）。

## 合并规则

1. 同序号同内容：去重。
2. 同序号异内容：拒绝（`ConflictError`，报告两处来源）。
3. 缺口：拒绝（`GapError`，报告首个缺失序号与来源段）。
4. 仅应用检查点之后的连续前缀；前缀尽头之后无更高序号时，
   该缺失序号作为“下一个期望序号”正常报告。

## 测试

随机分割重排对照完整日志解释器：随机生成完整日志，随机切成若干重叠段、
随机重排（偶尔整段复制）后合并恢复，与直接解释完整日志的参考实现
`interpretFullLog` 对照；另有随机缺口注入与随机冲突注入测试。
