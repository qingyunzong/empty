# 设备采集日志的物理分片边界

设备采集宿主要顺序读取LevelDB式日志并恢复掉电前完整记录，请实现可导入Go读取包，格式以本题为准。文件按32768字节物理块划分，每片头7字节：小端uint32掩码CRC、小端uint16载荷长、uint8类型，CRC是CRC32C(Castagnoli)对类型字节接载荷求值后rotateRight32(crc,15)+0xa282ead8按uint32回绕；类型1/2/3/4分别FULL/FIRST/MIDDLE/LAST。片不得跨物理块；块内不足7字节的尾部必须全零并跳过，完整零头表示当前块剩余部分全零填充，不能把它当空记录。FULL独立形成逻辑记录，FIRST开始、零或多个MIDDLE延续、LAST结束，逻辑记录可跨块；空FULL合法，其他空片也允许但仍遵循序列。输入任意切块，只有片CRC通过且逻辑记录闭合才向回调交付，附所有物理载荷区间和逻辑起始偏移。严格模式在EOF遇到残头、残载荷或未闭合记录报错；恢复模式只可丢弃真实EOF处未完成的尾记录并返回截断报告，完整片CRC错误、块内跨界、非法类型、非零填充和片序错误仍是损坏，不能跳过后继续冒充成功。已经交付的完整前缀保留，错误返回首个相关物理偏移。宿主限制单逻辑记录及总产出字节，超限停止且不缓存声明巨量数据。提供可从已确认逻辑记录边界建立的检查点，绑定文件已读取前缀的SHA256与物理位置，回调成功视为确认，失败立即终止，不能再颁发包含失败记录的检查点；恢复需扫描所绑定前缀以确认检查点确为完整逻辑记录边界，不仅比较用户提供哈希。恢复先核验前缀，不能从MIDDLE直接开始拼接。用独立编码器对每个切块点核验跨块长记录、剩余6或7字节边界、空记录、CRC损坏与真正断电尾部，并验证检查点恢复不重复已确认记录。
