# broadcastsim

固定 3 节点的广播模拟器，仅使用 Go 标准库。

## 语义

- **有序编号交付**：消息携带从 1 开始的序号，节点按 1..k 的前缀顺序交付。
- **多数确认**：某序号获得至少 2 个（多数）不同节点的确认，且此前序号均已交付，才可交付。
- **重复与乱序**：重复确认幂等忽略；乱序到达的消息被缓冲，待前序交付后按序交付。
- **丢包与未决保留**：网络层按 `Loss` 判定丢包，被丢的包保留在未决队列中，后续 `Flush` 重试。
- **重启恢复**：每个节点把确认记录追加写入 `<dir>/<id>.acklog`（JSON Lines），重启时重放恢复确认与已交付前缀。
- **一致性检查**：`Cluster.Verify` 校验无冲突（同序号不同负载被拒绝，返回 `ErrConflict`）且各节点交付为一致前缀。

## 运行

```sh
go test ./...      # 运行全部测试
go run ./cmd/simdemo
```
