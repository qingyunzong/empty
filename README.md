# calib — 机器人相对坐标约束标定库

维护机器人间的相对坐标约束图，约束为整数平移与 90° 旋转复合的
平面刚体变换（组合顺序不可交换）。

## 变换模型

`Transform{Rot, DX, DY}`：先逆时针旋转 `Rot*90°`，再平移 `(DX, DY)`，
作用于点 `p` 为 `R*p + t`。`Compose` 为复合（`t.Compose(o)` = 先 `o`
后 `t`），`Inverse` 为逆变换。

## 约束语义

`Constraint{ID, A, B, T}` 表示 `value[B] = T ∘ value[A]`。

- 每个连通组以**最小机器人 ID 为原点**，其势变换为恒等；
  `Transform(v)` 返回 `v` 相对组原点的势变换。
- `Add` 时若新约束与现有约束构成非恒等闭环，**拒绝该约束**并返回
  `*Contradiction`：含闭环 `[]CycleStep` 与沿环复合变换证书
  （一致时应为恒等，非恒等即矛盾证据）。
- `Remove(id)` 按 ID 删除约束；连通组分裂后各自重新取最小 ID 为原点。
- 每次成功增删版本号加一并留存快照：`Snapshot()` 取当前版本，
  `SnapshotAt(v)` 取历史版本；旧快照在后续增删后保持有效。
