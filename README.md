# 单调数据索引的高低位分离编码

索引接入宿主需要可导入的Go单调序列包，非空输入是N个不降uint64及上界U>=末值，L=max(0,floor(log2(floor(U/N))))，U/N为0时L=0。低位流按原序存每值低L位，低位先行；高位位图第(value>>L)+原下标处置1，其余0，总位长为(U>>L)+N+1。解码按第i个1的位置恢复高位，支持At(i)、第一个不小于x的下标和不大于x的个数，不能为查询缓存完整解码序列。空输入用N=U=L=0及空流。导入必须验证传入L与公式一致、低位及高位末字节填充零、高位1个数、单调性、上界及所有长度溢出，错误不发布索引。用全解码二分参考验证重复值、全零、uint64最大值及低位跨字节，At越界报错，找不到第一个不小于x的值返回N；查询报告实际位图导航位置。
