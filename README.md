事务引擎需要供版本管理调用的Go水位回收库，跟踪最老活动事务与安全水位，沿版本链精确淘汰过期版本，处理并发事务推进与范围扫描的双重检查。被任一活动快照可见的版本不得回收，水位推进单调且不跳号，回收字节与删除版本一一对应。用小事务调度穷举，对照朴素活跃集合重算核对每个版本的存活与回收，并发推进与长扫描交错时不出现版本被提前删除。

## 用法

```go
eng := formal.NewEngine()

tx := eng.Begin()          // 快照 = 当前提交时钟
tx.Write("k", "v")
ts := tx.Commit()          // 分配提交时间戳并发布版本

snap := eng.Begin()        // 长事务/范围扫描，钉住水位
vs := snap.Scan("a", "z")  // 快照内重复扫描结果稳定
snap.Rollback()

stats := eng.GC()          // 双重检查后精确淘汰过期版本
```

- 安全水位 = 活动事务最小快照（无活动事务时为提交时钟），单调推进。
- 版本可回收当且仅当它在链中的后继 ≤ 安全水位；每个受害者删除前
  都会对原始活跃快照集合做朴素重算双重检查。
- `Stats` 保证 `Reclaimed + Live == Total`（版本数与字节数各自成立）。

## 测试

