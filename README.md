# logrules

日志规则引擎，仅使用 Go 标准库。

## 语义

- **按记录序号生效**：`Engine.Log` 为每条记录分配递增序号（`Seq`），并钉住当时的
  规则代（`Gen`）。`SetRules` 的动态更换只影响之后分配序号的记录。
- **同记录全部规则同代**：一条记录及其全部派生诊断在整个处理过程中只使用根记录
  钉住的那一代规则快照；即使规则在处理中途被更换（包括规则动作内部调用
  `SetRules`），本记录树也不会看到新规则。
- **不重复匹配原记录**：每条记录恰好被匹配一次。规则派生的诊断是**新记录**
  （深度 +1），它们各自只被匹配一次，永远不会导致父记录或根记录被再次匹配。
- **派生深度预算明确**：`NewEngine(rules, maxDepth)` 显式给定预算。深度达到
  `maxDepth` 的记录不再匹配；若此时仍有规则会派生，该记录被标记
  `Truncated = true`，预算耗尽在输出中显式可见。
- **来源树**：`Log` 返回完整来源森林（根 + 全部派生诊断，含 `ParentID`、
  `RuleID`、`Depth`、`Gen`、`Seq`），`FormatTree` 渲染为缩进树。

## 交叉核对

`reference.go` 中的 `Interpret` 是递归参考解释器；生产路径 `deriveAll`
（`engine.go`）是迭代广度优先工作表。`TestEngineMatchesReference` 对多组规则集
比较两者的规范化来源树（与 id 分配顺序无关），必须完全一致。
