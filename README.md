# interval_newton

验证型区间牛顿法：对有理系数多项式，在有理区间 `[a,b]` 内找出全部实根，
输出宽度严格小于 `eps` 的有理区间包，每个区间恰含一个根。全程使用
`fractions.Fraction` 精确区间算术（含导数的区间求值），无浮点误差。

## 用法

```
python3 interval_newton.py COEFFS_FILE INTERVAL EPS
```

- `COEFFS_FILE`：空白分隔的有理系数（最高次在前），支持 `2`、`-3/4`、`1.5`，`#` 为注释。
- `INTERVAL`：搜索区间，如 `"[-1,2]"`。
- `EPS`：正有理数，如 `1e-30` 或 `1/1000000`。

输出：JSON 数组 `[[lo, hi], ...]`，`lo/hi` 为精确有理数字符串。

退出码：`0` 成功；`1` 输入非法；`4` 区间 `[a,b]` 内存在重根（错误输入）。

## 算法

1. 用 `gcd(f, f')` 检测区间内重根，存在则以退出码 4 失败。
2. 区间牛顿步 `N(X) = m - f(m)/F'(X)`（`0 ∉ F'(X)` 时）与当前区间求交；
   收缩不足或 `0 ∈ F'(X)` 时回退二分，保证终止。
3. `0 ∉ F(X)` 的区间被剪枝（其内无根）；宽度 `< eps` 的候选区间需通过
   精确验证：端点变号（存在性）且 `0 ∉ F'(X)`（唯一性）才输出。
4. 在二分中点处恰为根时，相邻区间在去重阶段合并为点区间。
