# 循环关系的逐层交集连接

查询引擎的多表循环连接不能先物化巨大的两表中间结果。给宿主实现可导入Go多路自然连接包，输入1至8个有限关系，每关系带唯一关系ID和不同变量名组成的列列表、int64元组集合，以及覆盖所有变量且不重复的全局变量顺序。构建按该全局顺序限制到关系列的有序trie，并用逐层交集连接：到某变量时，同时打开含它的各关系在当前已绑定前缀下的下一层有序游标，通过seek把落后值推进到其他游标最大值，只有全部相等才向更深变量递归；返回后继续当前层，不能预先把两个关系连接成元组表或枚举全域笛卡尔积再过滤。输入元组重复按集合去重，列列表重复或元数不符拒绝；零列关系可为包含一个空元组的单位关系或空关系，后者令结果为空。结果按全局变量字典序逐条返回，允许消费者暂停后继续，同一结果不重发，取消关闭全部游标且后续不能再读取。提供可注入的有序游标适配器和默认内存trie，接口应暴露open、seek、next、up的调用计数，seek在当前层从当前位置起返回不小于目标的最小值，无则耗尽；next跨到下一不同值，open进入当前值的下一层，up返回父层，不能把逐项next伪装为seek。测试循环三元关系、关系列顺序不同、某变量只出现一表、空关系、int64端点与暂停在递归返回边界；用独立全元组组合加等值约束参考核对小数据，并构造大间隙游标夹具验证实现确实跳跃交集且不生成两表中间关系。所有索引绑定不可变输入快照，不能让后续调用改变已有迭代器结果。
