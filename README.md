# 抓取缓存的年龄与新鲜度判定

抓取调度器保存过一条响应后，要在不访问源站的情况下判断现在该直接使用、可接受陈旧，还是必须联系源站。实现可导入的TypeScript模块，供调度器调用，不发网络请求。构造参数给出共享或私有缓存，以及是否允许启发式寿命。时刻是整数秒，年龄、寿命和所有比较都用精确整数。头是有序的名字与值，比较名字时忽略ASCII大小写。仅GET与HEAD可能命中：保存的GET可满足GET或HEAD，保存的HEAD只满足HEAD。Cache-Control按出现顺序拼接，逗号分隔指令，双引号内部的逗号不分隔；引号内反斜杠转义后一字符，引号不闭合则未命中。指令名不区分大小写，只解释public、private、no-cache、no-store、must-revalidate、proxy-revalidate、max-age、s-maxage、min-fresh、max-stale、only-if-cached，未知指令忽略。delta-seconds允许前导零，范围0至2147483647；重复指令只取第一个，第一个值非法则未命中。多个Age或多个Date未命中，Age必须是单个delta-seconds。Date、Expires、Last-Modified只接受“Sun, 06 Nov 1994 08:49:37 GMT”这种IMF日期，星期必须符合公历；年份被4整除是闰年，被100整除时只有再被400整除才是闰年。单个日期字段无法解析就当缺失。有Date时apparent为max(0,响应时刻减Date)，否则为0；响应时刻小于请求时刻或now小于响应时刻则未命中。corrected等于Age，缺失Age按0，再加响应时刻减请求时刻。初始年龄取apparent与corrected的较大值，当前年龄等于初始年龄加now减响应时刻。寿命依次决定：共享缓存已经取到合法s-maxage时用它，私有缓存不使用该值；否则用max-age；否则Date与Expires都有效时取Expires减Date，负数改为0；否则只在允许启发式、状态是200、203、204或206、Date和Last-Modified都有效且Last-Modified不晚于Date时，取二者之差除以10的下限；否则为0。s-maxage值本身非法时，私有缓存同样未命中。默认可缓存状态是200、203、204、206、300、301、308、404、405、410、414、501，其他状态需要public、max-age，或共享缓存下的s-maxage。响应no-store，或共享缓存遇到无论是否带字段列表的private，都未命中。Vary含星号未命中；其他Vary字段把新旧请求中同名头的全部原始值按序用逗号直接连接后区分大小写比较，缺头为空串。请求no-store未命中。need等于当前年龄加min-fresh，没有min-fresh则加0。初步结果取第一条满足者：上述硬未命中；响应或请求含no-cache，或响应含must-revalidate，或共享缓存且响应含proxy-revalidate，此时为revalidate且不能再被max-stale改写；need小于等于寿命时为fresh；请求含无值max-stale，或含数值且need小于等于寿命加该值时为stale；其余为revalidate。之后请求only-if-cached只把revalidate改为miss，fresh和已接受的stale不变；revalidate若没有非空ETag也没有有效Last-Modified，则改为miss。返回决定、当前年龄、寿命、max(0,当前年龄减寿命)、max(0,need减寿命)和原因；硬未命中时四个数字为空。模块不得修改入参，同一输入只能有一个结果。测试按公式另写算术表，覆盖响应延迟、两种缓存对s-maxage的差异、min-fresh与max-stale同时生效、only-if-cached、Vary、整除启发式、Expires早于Date、错误星期、1900-02-29和私有缓存接受private；不能调用被测函数制造期望。
