# coverage

加权整数区间覆盖库（仅 Go 标准库）。

## 语义约定

- 区间为半开整数区间 `[L, R)`，权重 `W` 带符号；`L >= R` 的零长区间一律忽略。
- 每个区间归属一个来源 ID；一个来源可拥有多个区间，`Remove` 按来源整体撤销。
- `Segments()` 输出规范分段：相邻且覆盖和与来源证据都相同的段被合并；
  覆盖和为 0 的区间不输出。每段附带证据——对该段净贡献非零的来源 ID（排序去重）。
- `Total()` 为覆盖和，即覆盖函数沿数轴的积分（等价于 Σ 长度×权重）。
- `Max()` 返回最大覆盖及最早达到位置；空集合返回 `(0, _, false)`。
- `MaxSegments()` 返回所有达到最大覆盖的段及其来源证据。

## 快照、批修改与逆补丁

- `Snapshot()` 产生独立分支（写时复制，互不影响）。
- `Apply(ops...)` 批量执行 `AddOp`/`RemoveOp`，返回逆补丁 `Patch`；
  `Revert(patch)` 精确恢复到批修改前状态（同批次重复来源按逆序恢复）。

## 持久化与故障恢复

- `Publish` 先写入并 fsync 新树文件 `tree-<gen>.json`（含 SHA-256），
  再原子 rename 替换根指针 `root.json`，最后 fsync 目录并回收旧树。
- `Recover` 只读取根指针指向的完整树并校验校验和；崩溃恢复只会得到
  完整的旧代或新代，绝不混合。根或树损坏时返回错误而非静默降级。

## 测试

```
$ go test ./...
ok  	coverage	0.238s
```

实测（Go 1.27.1，linux/amd64）：15 个测试全部通过，包括
5000 组随机小坐标与逐点全扫描核对、2000 组随机批修改+逆补丁恢复、
以及发布过程全部 5 个故障注入点（fail-at-0..4）的恢复一致性核对。
