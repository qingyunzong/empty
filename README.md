# patrol — 有向图巡检 CLI

在不超过 10 个顶点的有向图上求解"巡检问题"（有向乡村邮路问题）：
从固定起点出发，覆盖所有指定必巡边（允许重复经过任意边，费用非负），
最终回到起点，输出最小费用、完整边序列以及每条必巡边的覆盖次数。

## 构建与测试

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

## 输入格式

从文件或标准输入读取（顶点编号 1..n，`#` 之后为注释）：

```
n m s            # n 个顶点(≤10)，m 条边，起点 s
u v w required    # m 行：边 u->v，非负费用 w，required=1 表示必巡边
```

限制：顶点数 ≤ 10，必巡边 ≤ 20 条（精确状态空间搜索）。

## 使用

```sh
./build/patrol [--verify] [input_file]   # 无文件时读 stdin
```

输出：

- `status ok` + `cost`（最小费用）+ `steps`（逐条边的巡检序列，
  标注边编号、端点、费用、是否必巡）+ `coverage`（每条必巡边的覆盖次数）
- `status unreachable` + 每条不可达必巡边的原因
  （起点不可达边尾 / 边头无法返回起点）
- `--verify`：用独立的参考求解器（状态图上 Bellman-Ford 不动点松弛）
  交叉验证最优费用，输出 `verify ok` 或不一致时报错并非零退出

## 算法

主求解器在扩展状态图 `(顶点, 已覆盖必巡边位掩码)` 上跑 Dijkstra，
状态数 `n * 2^R`（R 为必巡边数），起点 `(s, 0)`，终点 `(s, 全集)`。
任何覆盖全部必巡边的闭行走一一对应于该状态图上的一条路径，
费用非负保证最短路即最优解；回溯父指针得到边序列与覆盖次数。

可达性预检：对每条必巡边检查"边尾可从起点到达"且"边头可回到起点"
（满足即整体可行：起点→边尾→边头→起点逐边拼接即可）。

参考验证器对同一状态图做 Bellman-Ford 式不动点松弛，独立实现，
用于测试中与主求解器在随机小图上交叉比对（`tests/test_solver.cpp`，
800 组随机实例，同时模拟校验返回路径的合法性、费用与覆盖计数）。
