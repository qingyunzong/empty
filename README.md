# 采集分区未压缩记录批的边界与序号

分区采集宿主收到的响应里，未压缩记录批可能被任意切断并与下一批粘连。实现可导入的Go包，供分区采集宿主调用，只重组并校验这种批，不实现压缩、网络客户端或磁盘日志。多字节整数均为大端。批依次为int64 baseOffset、int32 batchLength、int32 leaderEpoch、int8 magic、uint32 crc、uint16 attributes、int32 lastOffsetDelta、int64 baseTimestamp、int64 maxTimestamp、int64 producerId、int16 producerEpoch、int32 baseSequence、int32 recordsCount和随后的记录。batchLength从leaderEpoch计到批尾，整批占12+batchLength字节；该值小于49，或12+batchLength超过宿主maxBatchBytes时，必须在长度字段已读出后立即拒绝，不得按声明长度预分配或吞入超限正文。magic必须为2。crc覆盖自attributes起到批尾，算法为余数初值0xFFFFFFFF，每字节先异或入余数，再对8个比特从低到高处理：最低位为1则右移后异或0x82F63B78，否则只右移；结束后异或0xFFFFFFFF。ASCII字节123456789的结果必须是0xE3069283。attributes的bit0至bit2必须为0，否则整批拒绝且不解压；bit3为0表示创建时间、为1表示追加时间；bit4表示事务批；bit5表示控制批；bit6至bit15必须为0。记录字节必须恰好用尽batchLength。每条以32位zigzag varint写出其后字节数，再正好消费这些字节。varint按无符号LEB128解码，变长整数最多5字节且第5字节仅低4位有效，变长长整数最多10字节；非最短编码拒绝。zigzag在目标位宽的补码上计算无符号值逻辑右移一位再异或其最低位的算术负值。记录体依次为必须是0的int8、64位zigzag时间差、32位zigzag偏移差、键长、键、值长、值、头数量和头部。键长与值长为32位zigzag，-1表示缺失且无后续字节，小于-1拒绝，非负表示原始字节数，字节不作文本解码。头数量非负；每个头的键长至少为1，值长规则与记录值相同，重复键保留顺序。记录数必须等于recordsCount且不超过宿主maxRecords。偏移差非负且严格递增，最后一条等于lastOffsetDelta；绝对偏移等于baseOffset加偏移差，int64溢出拒绝。无记录时recordsCount、lastOffsetDelta和batchLength必须分别是0、0和49。创建时间下绝对时间等于baseTimestamp加时间差且不得溢出，maxTimestamp等于这些绝对时间的最大值；无记录时maxTimestamp必须等于baseTimestamp。追加时间下每条时间差必须为0，记录时间取maxTimestamp，baseTimestamp原样保留。producerId小于-1拒绝；等于-1时producerEpoch、baseSequence都必须为-1且bit4为0，记录没有序号；不小于0时producerEpoch与baseSequence都须不小于0且producerEpoch不超过32767，第i条（i从0计）序号为baseSequence+i模4294967296的结果。bit5为1时每条键恰好4字节，前两字节大端版本必须为0，后两字节大端类型只能为0中止或1提交，值必须缺失且头数量为0；bit5为0时不解释控制类型。crc、长度和记录规则全部通过后才交付不可变的批，包含每条绝对偏移、时间、序号或无序号标记、原始键值与头、控制类型及该批在字节流中的闭开区间。Push可在任意字节边界返回，未完成前缀不交付；Finish仍有残字节则失败。任一失败使组件停止，已交付结果保留，后续Push返回同一失败。测试用独立编码器和逐比特CRC核对半批拼接、预算拒绝、压缩位、过长varint、偏移倒退、时间溢出、序号越过2147483647、控制记录、producerId与事务位矛盾、crc篡改、空批，以及123456789的已知CRC；期望字节不得由被测编码器生成。
