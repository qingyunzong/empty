# trajlib — 轨迹连段库

## 语义
- 点 `Point{ID, T, X, Y}`，坐标与时间均为整数。
- 点按 `(T, ID)` 排序，**相邻两点**满足 `|ΔT| <= g` 且 `dx²+dy² <= r²` 才连边；
  全程整数运算，不计算平方根（`Linked`，traj/traj.go）。
- 段是极大的连边点串；`Upsert` 更正点会触发拆段/合段，`Remove` 删点也可能拆段。
- 输出稳定：段身份为**最小成员 ID**（与时间顺序、更新历史无关），段按 MinID 排序，
  段内边按时间顺序排列。

## 对照验证
`TestRandomUpdatesVsRebuild`：固定种子下随机插入/更正/删除 2000 步，
每步将增量维护的结果与 `Build`（排序重建）的结果做 `DeepEqual` 对照，
并校验重复调用输出确定一致。

## 实测结果（go1.27.1 linux/amd64）
```
$ go test ./...
ok  	trajlib/traj	0.733s
```
6 个测试全部 PASS：连边边界（g、r² 等值取到）、更正拆段、更正合段、
最小成员 ID 稳定性、删点拆段、随机更新 vs 排序重建对照。
