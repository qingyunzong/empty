# 计费属性里的厂商子属性

计费采集按属性长度跳过厂商号时，子属性的长度字节会落到值里面。实现可导入的Go组件，供计费采集调用，不发送请求。包以1字节代码、1字节标识、大端uint16长度和16字节鉴别码开始。长度包含这20字节，小于20则失败。代码只能是1、2、4或5。长度减去20之后是属性。每个属性是类型、1字节长度和值。属性长度包含类型和长度字节，必须不小于3，不能超过剩余。类型26的长度必须不小于7，值以前4字节厂商号开始，其余正好由子属性排满。子属性也是类型、1字节长度和值，长度包含这两字节且不小于3。其他类型的值原样返回。包长度必须正好用完。长度大于宿主maxPacket时在这2字节可读后拒绝，不按声明分配。Push可停在属性中间；Finish时包未完成则失败。失败停止组件，已交付包保留。测试独立组包，覆盖子属性越过厂商属性结尾、类型26长度为6、属性长度为2和包被切开。期望包不得调用被测组件生成。
