# 跨精度的去重计数草图归并

采集聚合服务的不同分片使用不同精度去重计数，归并时不能简单截断寄存器编号。实现可导入Go草图包，宿主注入确定性64位哈希并提供哈希方案ID；p为4至18，哈希最高p位是寄存器号，其余64-p位从高到低首个1的位置为rho，全零时rho=65-p；每个寄存器初始0，更新取最大。支持任意顺序与重复更新、同精度并集、降至更小精度及混精度并集，混精度默认降到最小p，不能升精度冒充恢复信息；不同哈希ID整次拒绝。降精度后的寄存器须逐个等于同一原始哈希流直接以目标p构建的结果，不能仅保证估计值接近，也不准保留原始键或哈希列表。提供稀疏和稠密表示，稀疏仅保存非零项，达到宿主指定的1至2^p范围内非零项数阈值后单向转稠密，两者导出同一规范寄存器序列；降精度和归并遵循目标实例阈值。估计采用E=alpha*m*m/sum(2^-R)，m=2^p，m=16/32/64的alpha分别0.673/0.697/0.709，其余0.7213/(1+1.079/m)；若E<=2.5*m且零寄存器数V>0改用m*ln(m/V)，否则返回E，不做其他偏差或大范围修正，空草图严格返回0并明确这是近似值。序列化携带版本、p、哈希ID、阈值和寄存器，严格拒绝重复稀疏索引、越界rho及尾杂数据，恢复后后续更新等价；合并不修改来源实例。用可控哈希构造被丢弃索引位既全零又非零、后缀全零和最高rho的夹具，并随机比较直接低精度构建与多次降精度/乱序多层归并，不能用一次随机估计误差来证明实现正确。
