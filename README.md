# 网页结构化条目的引用展开

网页采集宿主已有只读DOM快照，需要可导入的TypeScript条目抽取包，处理本题明确的microdata子集。节点分text与element，text仅含文本且无孩子，element含以下字段：唯一nodeId、可选HTML id、标签、属性及有序子节点；属性取值存在才使用对应优先项，缺失时回退到后代文本，文本遍历不受scope边界限制。itemscope节点形成条目；itemprop按ASCII空白拆为去重但保序的属性名。对每个条目，先对直接孩子按文档序深度优先遍历，再按itemref token顺序对各HTML id入口深度优先遍历，同一条目内每节点最多访问一次；节点带itemscope时它是嵌套条目值，不再向下搜该条目的属性；节点不是scope时取自身itemprop后继续子节点；同一节点带多个属性名时每个名各追加一个相同值。itemref按token顺序加入搜索入口，重复引用去重，缺失ID报错，HTML id重复使整份输入拒绝。嵌套条目依相同规则抽取且可共享；条目引用图有环时返回具体scope节点环，不无限递归；共享子条目不应误报为环。含itemprop的text节点返回自身文本；非scope element属性值优先取meta.content、a或link.href、img.src、time.datetime、data.value，否则串联全部后代文本，URL类值按节点向祖先最近的显式baseURL解析，无baseURL时用文档URL。文本原样保留，不执行脚本。输出条目图以scope nodeId为身份，多属性及多值保序，另附每个值来源节点及遍历路径；所有scope均须扫描并建立图，返回完整条目节点表及不作为其他条目值的顶层ID列表，孤立但循环的条目仍须报错。给出宿主调用例和测试，覆盖itemref跨树、重复入口、共享scope、循环、嵌套scope隔离、不同base及多名属性，不能依赖真实浏览器或网络。
