# 页面采集的稳定等待

浏览器采集服务需要可导入的TypeScript页面等待组件。调用方提供可订阅文档变化的适配器、单调时钟及只依赖整个快照的纯谓词；每次文档变化均用其对应快照重新求值并重新计时，只有谓词连续成立满指定正时长才返回不可变节点快照。适配器提供递增版本，读取返回版本与该版本不可变快照；订阅从指定版本之后按版本顺序重放变化，每个变化携带对应版本的不可变快照，读取与订阅间变化不能遗漏。调用方以串行事件序列提供变化、取消和计时器触发，组件按接收顺序处理；计时器触发时仅当最新版本仍为计时开始时版本且当前时刻已达期限才成功，若总超时已到则超时优先。终止后解除订阅，迟到回调不得再次完成。用虚拟时钟测试读订阅竞争、边界变化及取消与计时器交错，检查最多一个终态。
