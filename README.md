# 流量模板与数据区的记录长度

流量采集若用上一包的模板字节数去切这一包，模板在同一包后部才出现时，前面的数据区会被切错。实现可导入的Go组件，供流量采集调用，不接收网络。分组头20字节都是大端：版本必须为9、流区个数、系统运行毫秒、Unix秒、包序号、源标识。流区个数必须和实际流区数一致。每个流区以大端uint16标识和大端uint16长度开始。长度包含这4字节，小于4则失败，大于宿主maxFlowSet时在这2字节可读后拒绝，不按声明分配。标识0是模板区。模板区里依次是模板号、字段个数和字段，不能留下不足一个模板的尾部。模板号必须不小于256，字段个数必须不小于1。每个字段是大端uint16类型和大端uint16字段长度，字段长度必须不小于1。标识不小于256是数据区，模板必须已经在本分组的更早位置或之前的分组里定义。记录长度是该模板全部字段长度之和。数据区长度减4必须能被记录长度整除，不能有填充。记录按字段顺序切开并原样返回。标识1至255失败。同一模板号再次出现时替换定义，只影响之后的数据区。Push可停在流区中间；Finish时分组未完成则失败。失败停止组件，已交付分组保留。测试独立按字段长度切分，覆盖模板与数据同组、使用尚未定义的模板、重新定义后的下一条记录和长度含有填充。期望记录不得调用被测组件生成。
