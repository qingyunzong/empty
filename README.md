# 抓取文本的类型声明与标签括号

抓取到的指标文本里，类型声明如果出现在同名样本之后，直方图的桶就无法判断该不该要求le标签。实现可导入的TypeScript模块，供抓取器按行调用。LF分行，行尾CR丢弃。空行忽略。以“# HELP”或“# TYPE”开头的行必须是井号、一个空格、HELP或TYPE、再一个空格、指标名和其余文本，否则失败；其他以#开头的行忽略。指标名以字母、下划线或冒号开头，其余为字母、数字、下划线或冒号。同一名字的TYPE只能出现一次，并且必须在该名字的任何样本之前；HELP至多一次，也必须在样本之前。TYPE的种类只能是counter、gauge、histogram、summary或untyped。样本是名字、可选标签、一个空格、数值和可选的一个空格后的十进制毫秒时间戳。标签整体放在花括号里，紧贴名字；各项为标签名、等号和双引号值，项之间一个逗号，逗号后无空格。标签名以字母或下划线开头，其余为字母、数字或下划线，不能重复。引号内只把\\、\"和\n还原，其他反斜杠失败。数值可以是NaN、+Inf、-Inf，或可选符号、数字、可选小数和可选指数，按十进制到binary64的最近偶数舍入，+0与-0保留符号。counter、gauge和untyped的样本名必须等于TYPE中的名字。histogram只接受原名加_bucket、_sum或_count；_bucket必须有且只有一个le标签，_sum和_count不能有le。summary只接受原名、原名_sum或原名_count；原名必须有且只有一个quantile标签，_sum和_count不能有quantile。le只允许出现在histogram的_bucket上，quantile只允许出现在summary的原名上。时间戳若存在，是无前导零整数，可有一个负号，负号后不能是0，且落在int64。坏行之前的样本保留，模块停止。测试独立解析，覆盖TYPE晚于样本、重复标签、histogram缺少le、summary的quantile、负零和行被切开。期望样本不得调用被测模块生成。
