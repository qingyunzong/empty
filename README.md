# 查询结果包的空值与结束标记

查询采集若把行首的0xFE一律当成结束包，长度超过8字节的文本列就会被截断。实现可导入的Go组件，供查询采集调用，不连接数据库。每个包是3字节小端长度、1字节序号和这么多载荷。长度不含这4字节，为0或大于宿主maxPayload时，3字节一旦齐备就拒绝，不按声明分配。序号必须等于调用方给出的起始序号，之后每包加1，模256。长度编码整数按首字节解释：0至250就是该值；0xFC后再读小端uint16；0xFD后再读3字节小端；0xFE后再读小端uint64。0xFB不能出现在长度位置。结果以列数包开始，载荷是一个大于0的长度编码整数。随后恰好这么多个列定义包，载荷原样保留。接着是结束包：首字节0xFE且载荷长度小于9，后接小端uint16警告数和uint16状态。再之后每个行包的列数必须与列数包一致。列值以0xFB表示空值且不再读字节；否则是长度编码字节数和这么多原始字节。行包首字节为0xFE且整个载荷长度不小于9时，按长度编码字符串处理，不是结束包。错误包首字节0xFF，后接小端uint16错误码、字符#、5字节状态和严格UTF-8消息。长度必须正好用尽。Push可停在包中间；Finish时包未完成则失败。失败停止组件，已交付包保留。测试独立组包，覆盖0xFE长字符串、0xFB空值、序号回绕、列数不符和长度被切开。期望行不得调用被测组件生成。
