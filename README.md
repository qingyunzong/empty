# counter

从带位宽的累计计数器读数重建单调事件总量。仅依赖 Go 标准库。

## 语义

- 输入为累计读数 `Reading{Time, Value, Reset, Version}`，可乱序、可含重复时刻。
- 读数下降时，仅在创建时允许一次回卷（`New(width, true)`）才按
  `(cur - prev) mod 2^width` 补模；否则该区间记为未知。
- 显式重置标记（`Reset: true`）使截至该读数的区间未知，该读数成为新基线。
- 重复时刻取版本号最高者；版本相同取输入中较后者。
- 不推测多次回卷：每个区间至多补偿一次回卷。

## 输出

`Process` 返回 `Result{Total, Known, Unknown}`：可计算区间的增量总和、
可计算区间数，以及未知区间列表（含起止时刻与原因）。

## 测试

```sh
go test ./...
```

测试包含手写边界用例（精确回卷、重置、重复时刻、位宽 64、越界拒绝等）
和重建模型对照：模拟真值计数器（保证采样间至多一次回卷、随机重置、
乱序并注入低版本重复读数），校验库输出与模型真值一致。
