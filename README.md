# fefo — 按到期日最早优先（FEFO）的配货库存账本

纯 Go 标准库实现（无第三方依赖）。

## 规则

- **FEFO 分配**：订单按批次到期日最早优先扣减（到期日相同按批次号），库存不足时记录缺货量。
- **跨日期**：事件日志按日期稳定排序重放；每进入新的一天，先将在该日之前到期的在架批次归入报废（到期日当天仍可发/可退）。
- **退货**：只能退回原订单的原批次（按分配逆序回补）；退货日批次未到期则回补库存，已到期部分直接归报废（`ReturnScrapped`，不经过在架库存）。
- **事件更正**：`Amend` 事件按 ID 替换（或作废）日志中已有事件，替换事件须保持原 ID 与原位置；更正通过 `Replay` 整体重放生效。
- **守恒核对**：`CheckConservation` 校验全局恒等式
  `received == onHand + (shipped - returned) + scrapped`，
  并逐日校验流水模型 `onHand = 前日 + 入库 - 出库 + 回补 - 报废` 与批次级库存一致。

## 输出

- `State.Sources(orderID)` / `State.Orders`：每单批次来源（批次、到期日、数量、已退量）。
- `State.Ledger`：逐日库存流水（入库/出库/退货/回补/在架报废/退货报废/期末在架）。
- `cmd/fefo-demo`：示例场景（含一次收货数量更正重放），打印每单批次来源与逐日台账。
