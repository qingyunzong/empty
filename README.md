# 紧凑记录头的字段号栈恢复

日志接入宿主调用可导入的Go紧凑对象包，字段头高四位是相对前字段ID的正增量，低四位类型为1布尔假、2布尔真、3整数、4字节串、5对象；高位为0时随后用最短无符号varint给完整正字段ID。整数用ZigZag后varint，字节串先varint长度，对象以零头结束，嵌套进入时字段基数归零，退出须恢复父基数。字段ID和所有varint均限uint64，ZigZag映射int64，正字段ID不得超出uint64；调用方给正整数深度、对象总字节及字节串长度上限。重复字段ID、溢出、未知类型及截断整对象拒绝，返回绝对偏移和字段路径。用嵌套夹具逐字节切块校验父ID恢复与预算。
