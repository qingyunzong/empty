# 遥测帧的发送序号与格式位

遥测采集把发送序号和格式位放在同一对字节里，只看低位会把序号加1后的下一帧判成乱序。实现可导入的TypeScript模块，供遥测采集按块调用。帧以0x68开始，随后1字节长度和这么多APDU字节。长度是4至253；小于4或大于宿主maxApdu时立即拒绝，不按声明分配。控制域4字节。第一字节最低位为0时是信息帧：发送序号是前两字节小端uint16右移1位，其中第二字节的最低位属于序号而不是标志；接收序号是后两字节小端uint16右移1位，且第三字节最低位必须为0。第一字节最低两位为01时是监视帧：第二字节必须为0，接收序号同样来自后两字节且第三字节最低位为0，长度必须为4。第一字节最低两位为11时是控制帧：第3至8位里只能有一位为1，后三字节必须为0，长度必须为4。信息帧的长度至少为10，其后是原样保留的数据。调用方给出期望发送序号。信息帧的发送序号必须等于它，然后模32768加1；监视帧和控制帧不改变发送序号。接收序号只原样返回，不在模块内推进。Push可停在长度或控制域中间；结束时帧未完成则失败。失败停止组件，已交付帧保留。测试独立拆序号，覆盖第二字节最低位属于序号、序号32767回绕、监视帧夹在信息帧之间、长度4的信息帧和控制帧多个功能位。期望帧不得调用被测模块生成。
