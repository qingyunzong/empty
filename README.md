# orderstats

按订单事件流构建状态时间线的统计库，仅依赖 Go 标准库。

## 语义

- **排序**：事件按 `(Time, Version, ID)` 排序；同一时刻的事件先比版本再比 ID。
- **非法转换**：不满足状态机的转换不生效，并记录 `Rejection` 证据
  （原事件、被拒绝时所在状态、原因）。
- **更正**：同一事件 ID 的更高 `Version` 是更正，替换旧版本；更低或相等
  版本视为过期被忽略。更正可能改变后继事件的合法性，因此该订单的时间线
  与拒绝证据会整体重估。
- **驻留区间**：`Segment` 与 `Residency` 查询均使用半开区间 `[Start, End)`；
  末段 `End` 为零值表示开放区间（当前状态）。
- **增量核对**：`Engine.Add` 增量摄入；`Replay` 从原始事件流完整重放，
  作为参照实现。测试在每一次增量后都与完整重放逐一对照（时间线、
  拒绝证据、随机窗口驻留）。

## 状态机

```
        -> paid -> packed -> shipped -> delivered -> returned
created -> cancelled (from created/paid/packed)
```

## 测试结果

`go test ./...` 实际输出（go1.27.1 linux/amd64）：

```
ok  	orderstats	0.081s
```

7 个测试全部通过：同刻排序、非法转换证据、更正使后继失效、更正使后继
生效、过期版本忽略、半开区间驻留、400 步随机增量 vs 完整重放。
