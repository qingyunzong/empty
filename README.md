# 多路遥测帧的位段信号解释

同一遥测帧的位段含义取决于多路选择信号。提供采集宿主可导入的Go信号包，模式给帧ID、固定字节长、信号位位置序列、是否有符号及有理scale/offset；按位置序列从低有效位到高有效位组整数，位编号为字节号乘8加字节内低位编号。信号可要求一个无符号选择器等于指定整数，选择器不得依赖其他选择器。只解码被激活信号，输出精确有理值及位来源；越界、重叠激活信号或模式环拒绝；位段位置不得重复，选择器必须无条件激活且其位段也参与重叠检查。用自行编码帧测试跨字节、有符号端点及非激活垃圾位。

## 包结构

- `signal`（导入路径 `example.org/dataeng/q0181/signal`）：核心信号包。
  - `Pattern`：帧 ID、固定字节长与信号列表；`Signal` 给定位位置序列、有符号标志及有理 `Scale`/`Offset`，可选 `Selector`/`Equals` 门控。
  - `Pattern.Compile`：一次性校验并返回 `CompiledPattern`。
  - `CompiledPattern.Decode`：只输出被激活信号，`DecodedSignal` 含精确有理 `Value`（`*big.Rat`）、原始整数 `Raw` 与逐位来源 `Sources`。
- `cmd/telemsig`：采集宿主示例，演示外部导入、编译模式与解码一帧。

## 规则

- 位编号 = 字节号 × 8 + 字节内低位编号；位置序列第 0 项是组整数的最低有效位。
- 有符号信号按位宽做二补码符号扩展；物理值为 `raw * scale + offset`，全程精确有理运算。
- 选择器必须无符号且无条件激活，不能再被其他选择器门控；选择器位段与普通位段一起参与重叠检查。
- 拒绝：越界位、信号内重复位、可同时激活信号的位重叠（同选择器不同取值的互斥信号除外）、选择器依赖环、零分母有理值、帧长度不符。

## 运行

```sh

go run ./cmd/telemsig
```
