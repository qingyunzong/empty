# 工作表采集的共享公式还原

工作表采集宿主要保存每个已有公式单元格的真实公式，不能把共享公式从属格误记为空。请实现可导入Go还原包，输入单张工作表的已解析单元格列表，每格有A1坐标及可选公式对象{text,t,si,ref}；t只支持缺省/normal/shared，其他类型拒绝；shared的si为uint32，非shared必须有非空text，单元格与ref坐标只接受大写A1且行号无前导零。不要求读取ZIP或计算公式值。t=shared且带ref与非空text的是master，同一si唯一，ref为包含master的矩形；同si的其他shared格以相对master的行列位移还原，slave自带text必须忽略。非shared格即使位于共享矩形内也保留自己的公式，不因master覆盖；ref里没有出现的单元格不补造，slave在ref外拒绝。不同master矩形不能重叠，缺master、重复单元格及错误si整表拒绝，输入顺序可任意。还原需自行识别公式中的A1引用及范围：列A至XFD、行1至1048576，$列或$行分别固定，未固定坐标按位移平移；任一端越界时整个引用或范围替换为#REF!。支持可选sheet前缀，未引号sheet名为ASCII标识符，含特殊字符用单引号包住且内部单引号写双份；前缀保留原样，跨sheet引用也按同样行列位移处理。范围为同一前缀下的A1:B2。双引号字符串内部双引号成对转义，里面的A1不可改；十进制及带E指数数字不可拆成引用，函数名后接左括号，LOG10(...)中的LOG10不能误认单元格。函数名以ASCII字母或下划线起始，后续支持ASCII字母数字下划线点，名称和左括号间可有空白，除函数名、布尔常量与引用外不支持命名范围；不支持外部工作簿、3D引用或结构化表引用，遇到这些语法明确报错。其余算术、比较、连接运算符与空白原样保留，不要求执行表达式。输出按行号再列号顺序排列的还原文本、master来源与各引用变更的原始字节区间，任何非引用片段必须逐字节不变。用独立token夹具测试混合绝对地址、字符串伪引用、带单引号sheet、负位移越界、slave先到、普通格覆盖及范围重叠，验证还原不改变输入快照。
