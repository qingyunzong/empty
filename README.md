# intervalx

纯 Go 标准库实现的加权区间分析库。

## 语义

- 区间为整数端点半开区间 `[Lo, Hi)`，权重为带符号 `int64`；零长区间（`Lo >= Hi`）一律忽略。
- 区间按来源 ID（`SourceID`）归组，一个来源可拥有多个区间；`DeleteSource` 整体撤回该来源的全部区间。
- `Version` 不可变（写时复制）：`Add` / `DeleteSource` / `Apply` / `Revert` 都返回新版本，天然支持分支快照。
- 查询：
  - `CoverageSumAt(x)`：覆盖点 `x` 的权重和。
  - `Segments()`：规范分段——覆盖域上按区间端点切分、相邻同和合并的最大定和段，未覆盖空隙省略。
  - `MaxCoverage()`：覆盖和最大值及最早达到位置；空集合返回 `(0, 0, false)`，即最大定义为 0。
  - `MaxSegments()`：每个最大段及其来源证据（排序后的贡献来源 ID 集合）。
- 批修改：`Apply([]Op)` 原子应用一批操作并返回逆补丁 `Patch`；`Revert(patch)` 精确撤销全部生效变更（`DeleteSource` 的逆操作是逐条补回被撤区间）。
- 持久根：`Root` 采用双槽位 + FNV 校验和 + 原子提交指针发布；`Publish` 在 `invalidate`/`midData`/`data`/`meta`/`commit` 任一故障点崩溃后，`Recover` 只返回完整的旧树或完整的新树，绝不混合。

## 测试

`go test ./...` 全部通过（含 `-race`）：

- 随机化测试（8 个种子 × 300 步增删）每步与 `[-14, 14)` 整数坐标逐点扫描的暴力模型核对：逐点覆盖和、规范分段、最大覆盖与最早位置、最大段来源证据。
- 分支快照独立性、批修改 + 逆补丁恢复、删除来源整体撤回、零长区间忽略、空集合最大为 0。
- 持久根在全部 5 个故障点 + 无故障点的发布崩溃恢复核对，以及槽位交替、损坏槽位回退。

最近一次实际运行结果：

```
$ go test ./... -count=1
ok  	intervalx	0.102s
$ go test ./... -race -count=1
ok  	intervalx	1.428s
```
