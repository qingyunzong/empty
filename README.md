# joinview

维护袋语义（bag semantics）关系 `R(A, K)`、`S(K, B)` 的物化视图：
按 `A` 分组统计 `R ⋈ S`（在 `K` 上等值连接）的连接行数与 `B` 之和。
连接键 `K` 为 NULL 的行不参与连接。

## 用法

```sh
python -m joinview state.json script.json
```

- `state.json`：持久状态，格式为 `{"R": [[A, K], ...], "S": [[K, B], ...]}`。
  文件不存在时视为空状态。仅在脚本执行了 `commit` 时才会被（原子地）重写。
- `script.json`：操作数组，见下。
- 标准输出打印提交后状态的物化视图：
  `{"view": [{"A": ..., "count": n, "sum_b": s}, ...]}`。

## 脚本操作

| 操作 | 说明 |
| --- | --- |
| `{"op": "begin"}` | 开启事务；事务中再 `begin` 报错 |
| `{"op": "commit"}` | 提交并持久化；无活动事务时报错 |
| `{"op": "rollback"}` | 回滚整个事务 |
| `{"op": "rollback", "name": n}` | 回滚到保存点 `n`：撤销其后的变更并销毁其后的保存点，但保留 `n` 本身 |
| `{"op": "savepoint", "name": n}` | 建立保存点（嵌套栈）；与活动保存点重名报错 |
| `{"op": "release", "name": n}` | 释放 `n` 及其后的所有保存点；之后再回滚到 `n` 报错 |
| `{"op": "insert", "rel": "R"|"S", "row": [x, y]}` | 插入一行 |
| `{"op": "delete", "rel": "R"|"S", "row": [x, y]}` | 删除一行（重数减一） |

## 语义规则

- 保存点按嵌套栈工作；回滚到外层保存点会销毁内层保存点。
- 删除超过重数、重名活动保存点、无事务提交等均为语义错误：
  以退出码 2 终止，活动事务被回滚，已提交状态不变。
- 未提交的脚本不改变持久状态（退出码 0，状态文件不被改写）。
