# libreadcheck — 库读日志校验器

按票据代际重建库读日志状态，校验规则与不变量，输出首错及完整因果链。

## 日志格式

每行一条事件（空行与 `#` 注释被忽略）：

| 事件 | 语义 |
| --- | --- |
| `CAP <n>` | 调整当刻上限为 `n`（`n >= 0`） |
| `REQ <ticket> <n>` | 申请：为票据开启新一代，申请 `n` 份（`n > 0`） |
| `GRT <ticket>` | 授予：申请中的票据转为已授予，计入在途总额 |
| `CXL <ticket>` | 取消：仅对未授予票据有效，取消不释放任何额度 |
| `REL <ticket>` | 释放：释放已授予票据；重复释放报错 |

## 规则与不变量

- 票据按代际管理：`REQ` 开启新一代，上一代必须已关闭（释放或取消）。
- 取消未授予的票据不释放额度；已授予的票据不能取消，须用 `REL`。
- 重复释放、释放未授予/已取消/陌生票据均为错误。
- 任意时刻在途授予总额不得超过当刻上限（授予与调低上限时都校验）。
- 发现首错即停，输出错误行号、说明与完整因果链
  （票据类错误给出该票据跨代际历史；上限类错误给出上限变迁与全部在途授予）。

## 使用

```sh
go run . 日志文件        # 或 cat 日志文件 | go run .
```

退出码：`0` 合法；`1` 发现违规；`2` 解析失败。

## 测试

```sh
go test ./...
```

包含单元测试与验收测试：随机生成合法日志（必须全部通过），
再施加单处破坏（重复释放、删除授予、虚报申请额度、上限低于在途、
释放陌生票据、取消已授予、重复申请），检查器必须全部检出。
