# 传输块的长度与填充

传输采集若按块长度直接寻找下一块，长度不是4的倍数时就会把填充当成下一块的类型。实现可导入的Go组件，供传输采集调用，不建立连接。分组以12字节公共头开始：大端uint16源端口、大端uint16目的端口、大端uint32验证标签、大端uint32校验。校验是反射CRC-32C，多项式0x1EDC6F41，初值0xFFFFFFFF，结果异或0xFFFFFFFF；ASCII“123456789”的结果是0xE3069283。计算时公共头里的校验4字节视为0，覆盖整个分组。随后是若干块。每块是类型、标志、大端uint16长度和值。长度包含这4字节和值，不包含填充，小于4则失败。长度大于宿主maxChunk时在这2字节可读后拒绝，不按声明分配。长度模4的余数不为0时，后面有4减余数个填充字节，填充必须为0。类型0是数据块，长度至少16。值以大端uint32传输序号、大端uint16流号、大端uint16流序号、大端uint32载荷协议开始，其余是用户数据。标志字节的第2位是无序，第1位是开始，第0位是结束，第3至7位必须为0。类型最高位为0且类型不是0时，整个分组失败。类型最高位为1时按长度和填充跳过，不交付该块。Push可停在块中间；Finish时分组未完成则失败。失败停止组件，已交付分组保留。测试用独立CRC和填充对照数据块后的3字节填充、最高位为1的跳过、最高位为0的未知类型和校验字段未置零。期望分组不得调用被测组件生成。
