# exact-convolution

`convolve`：对有符号 64 位整数序列做**精确**卷积，输出十进制大整数系数，无截断。

## 构建与测试

```sh
cmake -B build -S . && cmake --build build -j
cd build && ctest --output-on-failure
```

## 用法

```sh
./build/convolve <file1> <file2>   # 文件为空白分隔的 int64；'-' 表示 stdin
```

输出 `n + m - 1` 行，每行一个精确十进制系数。两序列长度之和不得超过 200000（超限报错退出）。

## 方法：多模 NTT + Garner CRT 精确重建

1. 对 5 个 30 位 NTT 素数分别做模卷积（均为 `c·2^k+1`，`k ≥ 21`，支持长度 `2^19 ≥ 200000-1` 的变换）：
   `998244353, 1004535809, 469762049, 167772161, 754974721`。
2. 用 Garner 算法把每个系数的 5 个剩余重建为模 `M`（素数之积）的唯一剩余，再对称提升到 `(-M/2, M/2]`，用自研大整数（`src/bigint.hpp`，基 2^32 符号-模值表示）表示，全程无截断。

### 模积充分性证明（且在运行时精确验证）

先验界：`|c_k| ≤ min(n,m)·max|a_i|·max|b_j| ≤ 100000·2^63·2^63 < 2^143`
（`n+m ≤ 200000`，元素为 int64，`|x| ≤ 2^63`）。

模积：`M = 998244353·1004535809·469762049·167772161·754974721 ≈ 5.96×10^43 > 2^145`。

故 `M > 2^145 > 2·2^143 > 2·max|c_k|`，对称提升唯一且等于真值。

此外，程序在每次卷积时用大整数按**实际数据**精确计算 `2·min(n,m)·max|a|·max|b|`
并与 `M` 比较，若不满足 `M > 2·bound` 立即抛错（`src/convolution.hpp`），
保证任何情况下都不会输出被截断/错误的结果。

## 测试（CTest）

- `test_convolution`：200 组随机短序列（混入 `INT64_MIN/MAX/0/±1`）与 O(n·m) 大整数参考对照；
  极值正负相消（`{M,-M}*{M,M} = {M²,0,-M²}`）；`INT64_MIN` 平方得精确 `2^126/2^127`；
  500 项交替极值；满规模 `100000+100000` 与闭式解全系数比对；长度上限检查。
- `test_cli`：端到端运行可执行文件，验证极值相消输出与错误输入的非零退出码。
