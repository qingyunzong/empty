# seqquery

序列查询库：在连续事件序列中找满足约束、收益最大的连续事件段。仅使用 Go 标准库。

## 口径

- 输入允许乱序，库内按 `(Time, ID)` 排序；事件总数至多 30（`MaxEvents`）。
- 约束：时间跨度（末-首时间）≤ `MaxSpan`；段内 distinct 类型数 ≥ `MinTypes`；
  来源互斥（段内 Source 不重复）；段内逐前缀库存（Inv 累加）始终 ≥ 0。
- 目标：收益（Value 之和，可为负）最大；空段恒为合法候选，收益 0。
- 并列依次按：段更短 → 开始更早 → 段内 ID 序列字典序更小。
- `Result` 携带逐前缀库存 `PrefixInv` 与覆盖证书 `Coverage`（类型 → 事件 ID 列表）。
- `Correct` 更正数据后版本号递增，旧 `Result` 失效（`Valid` 返回 false）。
- `BruteForce` 独立枚举全部区间并从头检查约束，用于小规模核对；
  `CheckCertificate` 独立验收结果的段连续性、约束、库存与覆盖证书。

## 测试

`go test ./...`：14 个用例，含 3000 组随机小规模与暴力枚举交叉核对及 30 事件上限验收。
