# ellipse-line-intersection

有理椭圆与有理直线的精确求交工具（TypeScript，零依赖，全 BigInt 精确运算）。

- 椭圆：一般二次曲线 `A x² + B xy + C y² + D x + E y + F = 0`，系数为有理数
- 直线：`a x + b y + c = 0`，系数为有理数
- 输出三种结果：**无交** / **切点**（精确有理坐标）/ **两交点**（代数表示 + 有理隔离区间）
- 退化圆锥曲线（点、直线对、虚椭圆、双曲线、抛物线）一律拒绝

## 使用

```bash
npm test     # 编译并运行全部测试 (tsc + node --test)
npm run build
```

```ts
import { intersectEllipseLine, verifyIntersection } from './src/index.js';

const res = intersectEllipseLine(
  { A: 1, B: 0, C: 1, D: 0, E: 0, F: -1 },   // 单位圆
  { a: 0, b: 1, c: '-1/2' },                 // 直线 y = 1/2
);
// res.kind === 'secant'
// res.points[i].x === { p, q, r, radicand, interval }
//   值 = (p + q·√radicand) / r, 例如 x = ±√3/2
//   interval 为有理隔离区间 [lo, hi]，两点区间互不相交
verifyIntersection({ A: 1, /* ... */ }, { a: 0, /* ... */ }, res); // 代回核验
```

## 方法

1. **椭圆判定**：`δ = 4AC − B² > 0` 且 3×3 矩阵行列式 `Δ ≠ 0` 且 `Δ(A+C) < 0`，
   否则抛出 `NotAnEllipseError` / `DegenerateConicError`。
2. **代入**：直线参数化代入圆锥曲线，通分为本原整系数二次式 `a₂t² + a₁t + a₀`。
3. **精确判别式**：`D = a₁² − 4a₂a₀`（BigInt）。`D<0` 无交；`D=0` 切点
   （有理精确解）；`D>0` 两交点 `(p ± q√D′)/r`（`D′` 已约去平方因子）。
4. **隔离区间**：由 `isqrt(D′)` 得初始夹逼区间，再用精确符号判定做二分，
   默认 64 次迭代（宽度 ≤ 初始宽度·2⁻⁶⁴），两根区间保证不相交。
5. **代回区间核验** `verifyIntersection`：
   - 切点：精确代回 `Q(x,y)=0` 与 `ax+by+c=0`，残差为零；
   - 两交点：坐标区间盒上做区间运算，椭圆式与直线式的取值区间均含 0；
     参数区间上一元二次式端点异号；两参数区间互不相交。

## 测试

`test/intersect.test.ts` 覆盖：

- **已知切线验收**：圆 `x²+y²=25` 在 `(3,4)` 的切线 `3x+4y=25`；
  椭圆 `x²+4y²=4` 在有理点 `(6/5,4/5)` 的切线 `3x+8y=10`；
  旋转椭圆 `x²+xy+y²=1` 在 `(1,0)` 的切线 `2x+y=2`；
  斜率构造 `y = mx + √(a²m²+b²)`（`16x²+9y²=144`, `m=1` → 切点 `(−9/5,16/5)`）。
- 无交（负判别式）、有理两交点、无理两交点（`±√3/2`）、竖直直线、
  判别式平方因子约化（`√8/4 → √2/2`）、隔离区间收缩。
- 退化/非椭圆拒绝：点椭圆、平行直线对、双曲线、虚椭圆、退化直线。
- 代回核验：篡改区间或交换交点顺序均无法通过核验。
