# regx — 寄存器表达式库

C++20 实现的寄存器位域表达式库：解析 → AST 求值 / 编译为可暂停栈字节码。

## 语言

所有值都是 **8–64 位无符号整数**（每个表达式节点都带位宽类型）。

| 语法 | 含义 |
| --- | --- |
| `255:8`, `0xFF:16`, `0b1010:8` | 字面量（十/十六/二进制 + 位宽），值必须放得下 |
| `42` | 无后缀字面量，取能容纳该值的最小位宽（至少 8） |
| `r0` | 寄存器，位宽由 `Schema` 声明 |
| `e[hi:lo]` | 切片，要求 `0 <= lo <= hi < width(e)` 且结果 ≥ 8 位，否则拒绝 |
| `{a, b, ...}` | 拼接（左高右低），总宽 ≤ 64 |
| `a + b` | 加法，结果位宽取两操作数最大值，按结果位宽取模 |
| `a << b`, `a >> b` | 移位，结果保持 `a` 的位宽；移位量 ≥ 位宽时结果为 0 |
| `a == b`, `a != b` | 按数值比较（零扩展），结果为 8 位 0/1 |
| `a && b`, `a \|\| b` | 逻辑运算，短路，结果为 8 位 0/1 |
| `c ? a : b` | 条件表达式，短路；两分支位宽必须相同 |
| `(e)` | 分组，纯透明，不改变 AST 与语义 |

优先级（松 → 紧）：`?:` < `||` < `&&` < `==` `!=` < `<<` `>>` < `+` < 切片后缀。

## 错误模型

- `ParseError`：词法/语法/静态语义错误，携带**源串字节偏移**（`e.pos`）。
  非法切片、未知寄存器、字面量超宽、拼接超 64 位、`?:` 分支位宽不等都在此拒绝。
- `RuntimeError`：执行时读到未赋值的寄存器，或寄存器值超出其声明位宽。
  短路保证**未执行的分支永不报错**（AST 求值与 VM 行为一致）。

## 字节码与验证

`compile()` 把 AST 编译为栈机字节码（`Program`），`&&`/`||`/`?:` 降级为条件跳转。
编译产物必经 `verify()`：

- 从入口做抽象解释，验证**所有跳转入口的栈类型**（宽度序列）一致；
- 检查栈下溢、跳转目标越界、切片/常量位宽合法、`Halt` 时栈顶恰为结果类型。

`VM` 是**可暂停**解释器：`step()` 逐条执行；VM 可复制，任一指令边界处
复制并继续执行，结果都与 AST 求值一致（测试逐边界核验）。

## 构建与测试

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

CTest 四个可执行测试：

- `test_parser` — 字面量/错误字节位置/非法切片/分组透明性/优先级
- `test_eval` — 取模加法、移位、切片、拼接、短路、运行时错误
- `test_vm` — VM 与 AST 一致、逐指令边界暂停恢复、验证器拒绝非法字节码
- `test_exhaustive` — 8 位域穷举（加/移位/切片/拼接/比较/逻辑/条件）+ 随机 AST 差分

## 布局

- `include/regx/` — 公共头（`value` `ast` `parser` `eval` `bytecode` `compiler` `verifier` `vm`）
- `src/` — 实现
- `tests/` — 测试（自带极简框架 `test_framework.hpp`）
