视频编辑器要接入C++YUV420到RGB浮点管线，调用方提供平面跨度、奇数尺寸、有限或全量程及BT.601或BT.709矩阵。色度样点位置可选居中或左对齐，按双线性插值并在边界钳位；色度尺寸向上取整，负行跨度允许表示倒置帧。输出前验证所有平面的可访问范围，不读填充字节。用小尺寸手算颜色、两种色度位置和带哨兵缓冲测试索引边界，比较翻转视图与显式翻转帧结果。

## 实现

- 接口：`include/yuv420_to_rgb.hpp`，实现：`src/yuv420_to_rgb.cpp`，C++20、无第三方依赖。
- 入口 `yuvconv::convertYuv420ToRgb`，输出每像素 3 个 float（行主序，结果钳位到 [0,1]）。
- `ConvertParams` 选择 `Bt601`/`Bt709` 矩阵、`Limited`/`Full` 量程、`Center`/`Left` 色度位置。
- 色度平面尺寸按 `ceil(width/2) x ceil(height/2)` 推导，天然支持奇数宽高。
- 色度双线性插值：连续坐标钳位到样点跨度 `[0, dim-1]`，边界权重收敛到边缘样点，绝不越界读取。
- 负行跨度通过 `data + row*stride` 寻址表达倒置帧；行内填充字节从不读取。
- 转换前 `validatePlanes` 校验尺寸、跨度、空指针及每个平面相对其可访问缓冲的字节窗口
  （`planeFits`/`requiredPlaneBytes`），窗口只覆盖可用样点，不含填充。

## 构建与测试

```
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

测试 `tests/test_yuv420_to_rgb.cpp`（208 项断言）覆盖：

- 1x1 手算颜色：BT.601 全量程、BT.709 有限量程（含钳位）、中性灰。
- 奇数 3x3 帧、2x2 色度下 Center 与 Left 两种位置的双线性权重与边界钳位。
- 哨兵填充缓冲：转换后填充字节保持哨兵值，验证不读填充。
- `mmap`/`mprotect` 双守卫页缓冲：平面窗口两端紧邻不可访问页，越界读即触发段错误；
  并验证声明范围差一字节时返回 `OutOfRange`。正、负行跨度各一组。
- 参数与范围校验：零/非法尺寸、跨度过小、零跨度、色度尺寸不符、输出几何不符。
- 翻转等价：负跨度视图与显式行翻转帧逐位相等（两种色度位置）；恒定色度下负跨度视图
  等于正立转换的垂直镜像。
