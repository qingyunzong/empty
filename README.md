# 批量数据写入的错误行精确拆分

远端批写接口只返回整批成功或拒绝，拒绝可由任意未知冲突组合导致，不能假定坏行独立。写供Go采集宿主导入的隔离包，调用方提供确定性无副作用的试写函数和正调用预算；返回原顺序的最大可接受子序列，空子序列保证可接受；长度并列取原下标列表字典序最小者，至多18行。预算不足只返回已证实可接受子序列及最优性未闭合标记；函数错误停止。用全部子集验证存在成对冲突时仍找全局最优。

## 用法

```go
indices, optimal, err := dataeng.Isolate(rows, func(subset []Row) (bool, error) {
    return remoteBatchWrite(subset)
}, budget)
```

- `rows` 可为任意切片，也可直接传入行数 `n`；返回的 `[]int` 是原切片下标，按原顺序排列。
- 试写函数也可接收 `[]int` 原下标或 `uint32` 子集位掩码；返回 `(bool, error)` 或单独的 `bool`。
- `optimal == false` 表示预算不足以闭合最优性证明；此时返回的子序列仍已证实可接受。
- 行数超过 `MaxRows`（18）、预算非正或试写函数签名不支持时返回错误；试写函数报错会立即终止并原样返回该错误。
