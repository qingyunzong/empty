# corrector

扫码序列校正工具：输入物品预期顺序与扫码序列，容忍重复扫码、漏扫和
错序，求把扫码序列校正为预期顺序所需的最少删除/插入操作，并在平局时
输出字典序最小的编辑脚本。条码按值比较，但每个条目保留自己的位置
（相同条码是不同物品，不会合并）。

## 用法

```sh
go run ./cmd/corrector -expected expected.txt -scanned scanned.txt
```

输入文件每行一个条码。输出编辑距离和可重放脚本，例如：

```
distance: 2
D 0 "B2"
I 3 "C3"
```

## 语义

- `Diff(expected, scanned)` 返回把 `scanned` 变换为 `expected` 的最短
  删除/插入脚本；`Script.Apply` 按序重放并校验删除处的条码。
- 操作索引相对于“演化中”的序列（已对齐前缀的长度），脚本内索引单调
  不减，可流式重放。
- 平局规则：脚本按操作逐条比较，操作按 种类（`D` < `I`）、索引、条码
  字节序 排序，取字典序最小者（见 `Compare`）。
- `Script.String` / `ParseScript` 提供规范文本形式的序列化与解析。

## 测试

```sh
go test ./...
```

测试包含一个独立的全编辑路径暴破参考实现（按代价迭代加深枚举所有
脚本），对短串全量枚举及随机用例逐一核验 `Diff` 的最优性、字典序
平局规则和脚本可重放性。
