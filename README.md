# 响应式图片采集的候选还原

图片采集宿主要复现给定视口下picture选择了哪条资源，简单按逗号切srcset会拆坏data URL。实现TypeScript可导入选择包，输入有序source及最后img、绝对base URL、正有理数视口宽与DPR；媒体条件与MIME支持性由宿主确定性回调判断。按source顺序找media成立且type支持的首个可用候选集，否则用img。srcset扫描规则为跳过ASCII空白和逗号，取直到空白的URL串；若URL以逗号结尾，去掉所有尾逗号并作为无描述符候选，URL和候选不得为空；否则从随后内容按空白取描述符，直到首个逗号结束本候选，URL内部逗号不能另作分隔。只支持一个无前导加号的正十进制整数w或正有限十进制x描述符，无描述符为1x；其他、多个或非正描述符只丢弃该候选并记录原字节范围与原因，继续扫描。十进制x允许整数或带小数点且两侧均有数字的形式，x不支持指数，w不允许小数；同类型同数值描述符重复只保留最早候选，一个候选集混有w和x时整个集不可用。URL按base解析，解析失败也仅丢弃本候选，禁止抓取网络。仅img且集无w、无1x时将非空src补为1x；空集不算可用。w集按sizes计算slot宽，sizes输入为有序的{media,expression}列表而非CSS原文，取首个media成立且表达式有效的正值，均无则用视口宽；表达式的十进制数使用同样语法，+/-同优先级左结合，不支持一元符号；表达式仅由非负有限十进制px或vw长度、括号、加减、min/max函数组成，vw按视口百分比，禁止其他单位和乘除，函数参数至少两个，运算按精确有理数，长度中间值可负但最终必须正。密度为w/slot或x，选择最小的>=DPR密度，否则最大密度，密度并列取原顺序，输出规范URL、有效密度、采用的source/sizes入口和候选原始范围。这里采用题面确定性策略，不模拟浏览器节流或缓存偏好。用独立有理数候选模型测试data URL逗号、URL尾逗号、无描述符、错误候选恢复、src补入、媒体切换、重复密度和嵌套min/max，给采集宿主示例。
