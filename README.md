# curve-roots

曲线求根工具：读取有理控制点的分段三次 Bezier 参数曲线（1–8 段）与一条直线，
精确求解曲线与直线交点的全部参数根，输出每个根的**隔离区间**与**重数**；
若某段曲线整体落在直线上，则报告该段的参数区间。

全部计算使用 BigInt 精确有理数，**不以采样代替根计数**：根的存在性与个数由
Descartes 符号变化法则（对 Mobius 变换后的多项式精确计数）保证。

## 构建与测试

```sh
npm run build     # tsc 编译到 dist/
npm test          # 编译并运行 node:test 验收测试（已知根构造）
```

## 使用

```sh
node dist/src/cli.js input.json [--budget N] [--refine-bits N]
```

输入 JSON（坐标建议用 `"p/q"` 字符串以保证精确；也接受整数与小数）：

```json
{
  "line": { "p0": ["0", "0"], "p1": ["1", "0"] },
  "segments": [
    { "points": [["0", "-3/32"], ["1/3", "13/96"], ["2/3", "-13/96"], ["1", "3/32"]] }
  ]
}
```

- `line`：直线上两个不同的有理点。
- `segments`：1–8 段，每段 2–4 个控制点（次数 ≤ 3 的 Bezier）。
- 全局参数 `t = 段号 + u`，其中 `u ∈ [0, 1]` 为段内参数。

输出 JSON：

- `roots[]`：每个根含 `segment`、`multiplicity`（重数）、段内区间 `u` 与全局区间 `t`；
  `exact: true` 表示根被精确命中（`lo == hi`），否则根被隔离在 `(lo, hi)` 内，
  区间宽度 ≤ `2^-refineBits`（默认 24）。
- `onLine[]`：整段落在直线上的段及其参数区间。
- `unknown[]`：预算（`--budget`，符号变化求值次数，默认 100000）耗尽时未闭合的
  区间，原因标为 `budget-exceeded`；这些区间内根的个数与位置未知。
- `stats`：预算与实际消耗的节点数。

示例：`node dist/src/cli.js examples/intersections.json`

## 算法

1. **代入**：每段 Bezier 控制点由 Bernstein 基转幂基，代入直线隐式方程
   `a·x(u) + b·y(u) + c = 0`，得到关于 `u` 的精确有理系数多项式（≤3 次）。
   零多项式 ⇒ 整段在线上。
2. **重数**：对交点多项式做 Yun 平方自由分解（精确有理数 GCD），
   因子 `f_i` 的根即为原多项式重数恰为 `i` 的根。
3. **端点**：`u = 0`、`u = 1` 处的根精确判定并 deflate。
4. **隔离**：对每个平方自由因子，在 `(0, 1)` 上用 Descartes 符号变化 +
   二分（二分点为二进制有理数）隔离根；落在二分点上的根精确输出。
   符号变化数给出区间内根数的上界且同奇偶，为 0 则无根、为 1 则恰有一根——
   这是精确的根计数，而非采样。
5. **预算**：每次符号变化求值计 1 个节点；预算耗尽时，未闭合区间进入
   `unknown`，绝不猜测。

注意：相邻两段共享接头处的根会按段分别报告（每段各一条，参数 `t` 相同）。

## 目录

- `src/fraction.ts`：BigInt 精确有理数。
- `src/poly.ts`：有理系数多项式运算、GCD、Yun 平方自由分解、Mobius 变换、符号变化。
- `src/bezier.ts`：Bernstein→幂基、直线隐式化、代入求交点多项式。
- `src/isolate.ts`：Descartes 二分根隔离（含预算与未知区间）。
- `src/solve.ts`：逐段求解、重数标注、全局参数映射、JSON 输出。
- `src/parse.ts` / `src/cli.ts`：输入解析与命令行。
- `test/solve.test.ts`：已知根验收测试（单根/二重/三重/端点/整段共线/多段/预算未知等）。
