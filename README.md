# 前缀压缩数据页的随机定位

## 包 `page`

导入路径 `example.org/dataeng/q0161/page`，供键值存储宿主读取前缀压缩页：

- 条目模型：共享前缀长 `Shared`、键后缀 `Suffix`、值 `Value`；长度与重启索引由调用方解析后传入。
- 注入式访问：`page.Reader` 接口只有 `ReadEntry(index) (Entry, error)`，整页验真与查询的全部条目访问都经该接口；包自身不会发起越界调用，接口实现对越界返回错误即计入调用方统计。
- 整页拒绝：`page.Open` 完整解压校验，非法前缀（负数或长于前键）、非零前缀的重启条目、重复/逆序键、重启索引越界或重复、空页携带重启点均返回哨兵错误（`ErrInvalidPrefix`、`ErrDuplicateKey`、`ErrRestartOutOfRange`、`ErrEmptyPageRestarts`）。
- `LowerBound(target)`：二分重启点（严格小于 target 的最近重启点）后线性重建，返回命中条目与重建链 `Result.RebuildChain`；空页或无命中返回 `ok=false`。
- 访问留痕：`VerifyAccess()` 记录整页验真访问，`QueryAccess()` 记录查询访问（含重启探测），两者分离且均返回副本。
- 并发与缓存：`Page` 支持并发查询；缓存键与返回的 `Key`/`Value`/索引切片全部为私有副本，外部修改不可污染缓存。

测试以独立的完整解压参考实现核验空页、共享前缀键和每个重启边界，并包含 200 组随机页性质测试、`-race` 并发测试与越界读取计数断言。

键值存储宿主要在压缩页中定位lower_bound。提供可导入Go页读取包，页内条目为共享前缀长、后缀字节和值，另有重启索引，重启条目前缀必须为0；长度与索引由调用方已解析给定。键严格按原字节递增，非法前缀、重复键或重启索引越界整页拒绝。允许从最近重启点重建，返回目标条目及查询重建链涉及的条目下标（整页验真与查询访问分别记录），不能把索引指向页外；查询可并发且缓存不暴露可变键；全部访问通过调用方注入的按条目读取接口，越界调用计为错误。用完整解压参考核验空页、前缀键和每个重启边界。
