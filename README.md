# quorum — 仲裁（法定人数）模拟库

模拟旧配置到新配置的联合（joint）重配置提交协议，仅使用 Go 标准库。

## 协议阶段

- `OldOnly`：提交须旧配置各自严格多数（按权重，`2*sum > total`）。
- `Joint`：提交须**旧配置和新配置各自**严格多数。
- `NewOnly`：切换完成后，提交仅须新配置严格多数。

阶段只能按 `OldOnly -> Joint -> NewOnly` 前进，且进入 `NewOnly` 前必须在
联合阶段完成一次提交，保证旧多数派与新多数派永不同时活跃。

## 安全性论证

每个节点全程只投一票，因此两个不同取值的提交能同时成立，当且仅当存在
一对不相交的法定人数。`TestExhaustiveNoConflictingCommits` 在小集合上
枚举所有投票子集，验证所有可同时活跃的阶段对（相同或相邻阶段）的法定
人数两两相交，故不存在两个冲突提交；同时验证若跳过联合阶段，旧/新
配置的法定人数可以不相交（联合阶段是必要的）。

## 投票证据

每次提交返回并记录 `Evidence`：取值、阶段、各配置的投票者、权重和、
总权重与严格多数阈值。见 `ExampleSimulator` 的输出。
