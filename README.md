# 采集数据的断点续传校验

下载采集服务需要可导入的Go流组件，调用方提供远端请求函数和事务暂存接口。初次响应须为200并提供强ETag与非负总长度，暂存字节和长度原子持久化。长度为零时直接校验空内容摘要，不发续传请求；否则从已持久长度发Range并携带If-Range。206须有相同强ETag及完整Content-Range，其起点等于请求起点、终点等于总长减一、总长与暂存一致，正文长度须等于区间长度；缺失或不一致则丢弃暂存并返回错误，下次调用从零请求。续传收到200时丢弃旧暂存，将该响应按初次响应规则从零处理。仅在完整长度及调用方给定SHA256均匹配后原子发布。用可控HTTP服务测试中断、实体轮换、错误区间、空文件及取消，确认不会混合不同版本。
