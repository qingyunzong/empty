# geomlib

动态整数点集几何库（仅 Go 标准库）。按整数 ID 增删点，维护凸包与凸层剥离，
所有查询基于不可变快照，旧版本永久有效且版本间结构共享。

## 功能

- `Snapshot`：不可变点集版本。`New()` 创建空集；`Add`/`Remove` 返回新快照，旧快照不变。
- `Add(id, p)`：按 ID 加点；ID 已存在则为坐标更正（可能改变所有凸层）。
- 重复坐标按 ID 分组：同一几何点只出现一次，`Sources(p)` 返回该坐标全部来源 ID，
  最后一个来源删除后几何点才消失。
- `Hull()`：凸包顶点，逆时针，从字典序最小点开始；边上共线点仅留端点；
  全共线时返回两个端点；单点返回该点。
- `Area2()`：凸包面积的双倍（整数）。
- `Layers()`：凸层剥离（洋葱分解），`Layer{Rank, Hull, Area2}`，Rank 1 为最外层。

## 实现

- 快照内部使用持久 treap（键哈希作优先级，路径复制），分支快照间结构共享，
  单次增删 O(log n)，不改动任何旧版本。
- 凸包为单调链 O(n log n)；凸层为逐层重复求包。

## 测试

`go test ./...`：

- 朴素支撑线检查核对每个版本：每条包边所有点均在左侧、严格逆时针、
  起点为字典序最小、无连续三点共线。
- 随机批更新（多种子）与从头逐层暴力凸包模型（O(n²) 支撑线枚举 + 逐层剥离）
  逐版本对照凸包、双倍面积、凸层、重复坐标分组与计数。
- 旧快照在后续更新后重新核对，验证持久性；分支快照验证结构共享。
