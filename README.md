# 气象描述流的延迟复制与位宽状态

气象采集宿主已拆出BUFR式未压缩数据区，请交付Go可导入的描述符编译与解码包，只实现下述自足子集，不下载外部表。输入描述符三元组F/X/Y，F取0..3、X取0..63、Y取0..255，均为整数、元素表、序列表、非负整数子集数S及MSB先行位串。F=0查元素表，元素给基础位宽1..64、-64..64的整数scale和任意精度有符号reference，取无符号u后若全1则missing，否则精确值为(u+reference)*10^(-有效scale)。F=3以序列表给出的原始描述符列表替换执行；模板可达的所有引用须存在，可达序列递归环即使位于零次复制中也拒绝。F=1是复制，X为正且表示紧随的X个原始描述符位置，不是展开后的叶数；Y>0执行该段Y次，Y=0则紧随一个专用因子0/31/1或0/31/2，分别从数据读8或16位无符号次数，然后复制再后面的X个原始描述符，因子不计入X。因子全1非法、0合法，因子不作为普通观测输出，也不受任何操作符影响；专用因子在其他位置非法。复制体可含完整嵌套复制及序列引用，但其原始X位置边界不得切断嵌套复制的因子或体，越界拒绝，不可先全展开后才数X。F=2只支持X=1位宽偏移和X=2 scale偏移，Y=0清除相应偏移，其余Y在1..255时设置偏移为Y-128，不是累加；操作符不占数据位，对随后执行的普通元素生效，序列和复制体退出时不恢复旧偏移，各次复制沿用上次结束状态，每个新子集开始两偏移均清0。执行元素时有效位宽须1..64，有效scale为基础scale加当前偏移；reference不变，missing须按有效位宽判断。模板编译检查所有结构、引用及基础元素定义，包括未执行分支；有效位宽越界只在实际执行该元素时拒绝，零次复制体不产生执行效果。每子集按模板执行，从上个子集结束位继续，不字节对齐；最后只允许不足8位的全0尾填充。输出每个观测的子集号、元素标识、嵌套序列/复制迭代路径、原始位范围、missing或规范有理值；同一个元素重复出现不能覆盖，宿主可只选择某些元素输出，但未选元素及操作符仍要执行和验证，不能改变后继位位置。宿主给最大输出观测数、最大执行描述符步数和最大嵌套深度，每次实际执行F=0/1/2/3各计一步，延迟因子读取另计一步；嵌套深度是当前活跃F=3展开及F=1体层数，根为0；零次复制仍计执行复制描述符一步，达到上限前拒绝超限，不靠巨量展开数组处理；任一错误不发布整个消息的部分结果。提供实际接入调用例和独立小规模展开参考，测试嵌套延迟因子、X与展开叶数不同、序列内部操作符影响外部、跨子集偏移复位、0次不改变状态、选择输出不改变解码以及非零尾填充。无需完整BUFR文件头、压缩子集或联网。
