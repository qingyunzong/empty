# statmatch

Go 标准库实现的时间序列对齐与 Pearson 相关统计库（仅依赖 `math/big`、
`sort`、`fmt`、`strings` 等标准包）。

## 语义

- **匹配**：两序列候选对满足有理最大间隔 `|tA−tB| ≤ maxGap`（`big.Rat`
  精确比较），按 `(时间差, A的ID, B的ID)` 升序扫描，一对一贪心匹配；
  同差按 ID 次序。绝不使用"相同时间点直接相连"的简化。任何增删都会
  重跑匹配并因此重算相关。
- **统计**：对匹配上的 `n` 对值维护精确大整数幂和
  `Σx, Σy, Σx², Σxy, Σy²`，输出精确整数
  `Cov = n·Σxy − ΣxΣy`、`VarX = n·Σx² − (Σx)²`、`VarY = n·Σy² − (Σy)²`
  （即总体协方差/方差的 `n²` 倍）。Pearson 相关
  `r = Cov/√(VarX·VarY)` 化简为 `Num·√Sqr/Den`（`Sqr` 无平方因子，
  可保留根式）。`n < 2` 或任一方差为零时返回无定义。
- **增删核对**：`Aligner` 增删点后按匹配差集增量更新幂和；测试
  `TestAddRemoveVsDirectSummation` 每步与 `DirectSums` 直接求和模型
  逐步核对。
- **证书**：`Certificate` 记录两序列（每序列至多 20 点）、最大间隔、
  匹配对、幂和与统计量；`Verify` 独立重放匹配与直接求和并逐项校验。
- **枚举核对**：`VerifyMatchingByEnumeration` 独立枚举全部一对一匹配，
  验证满足贪心刻画性质（每条非匹配边都有端点被键值严格更小的匹配边
  覆盖）的匹配唯一且等于贪心结果；每序列限 8 点以保证可枚举。

## 根式化简说明

`splitSquare` 对 `VarX·VarY` 做 10⁶ 以内素数试除并提取完全平方余因子；
素因子全部超过 10⁶ 的余因子按无平方因子处理（库的设计规模
`n ≤ 20`、`int64` 取值下足够精确）。

## 文件

- `match.go` — 点、匹配、独立枚举核对
- `stats.go` — 精确幂和、增删、直接求和模型、统计量
- `radical.go` — 根式化简与格式化
- `aligner.go` — 增删点、重匹配、增量统计
- `certificate.go` — 匹配及统计证书、独立验证
