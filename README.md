# 传感器采集的事件时间区间连接

遥测服务通过Go包连接左右两条事件流，两条流的ID分别独立，事件为唯一ID、key及int64时间，匹配条件为同key且右时间位于左时间前A到后B的闭区间，A和B为非负整数，比较不得溢出。每条流可显式结束，结束等同于正无穷水位线，此后拒绝该流输入；未结束时有单调水位线W，保证未来事件时间不小于W；违约或相同ID异内容的输入拒绝且状态不变。输出所有匹配对，并为最终没有匹配的左事件输出unmatched；同ID相同内容重投忽略。仅在左右水位线都已使某个左事件不可能再新增匹配且所有更早左事件已封口后交付该左事件的一整组结果；封口条件为左水位线严格大于左时间，右水位线严格大于数学整数意义下的左时间加B，结束水位线为正无穷。按左时间、左ID排序，组内右时间、右ID排序，ID按UTF-8字节比较。成功回调后释放组，失败或结果不明保留同组重试，调用方按左ID幂等。测试恰好边界、水位线相等、乱序和int64端点，以全量连接对照。
