# arctool — 安全目录归档/恢复 CLI

仅使用 Go 标准库（`archive/tar`）。

## 用法

```
arc create  <源目录> <归档文件>   # 归档目录
arc restore <归档文件> <新根目录> # 恢复到新根
arc verify  <源目录> <恢复目录>   # 核对硬链接 inode 关系一致
```

## 行为保证

- **硬链接**：按 `(dev, inode)` 去重，重复成员记为 `TypeLink`；恢复时目标可晚到，
  先挂起、流结束后重试，仍缺失则整次失败。
- **符号链接**：一律 `Lstat` 不跟随，循环链接安全；仅接受相对目标，
  且词法解析后不得逃出根目录。
- **路径穿越**：条目名禁止绝对路径与 `..`；硬链接目标同样校验。
- **失败原子性**：先解压到目标旁的临时目录，任一非法条目 → 删除临时目录、
  整次发布失败、旧目标目录保持不变；成功才原子替换。
- **核对**：`InodeGroups` 比较恢复前后硬链接分组，`Snapshot` 校验目录内容未变。
