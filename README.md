# queuecheck

诊断至多 12 个队列操作的历史（含调用/返回时间），判定是否存在满足
**真实时间偏序**的串行解释（可线性化）：

- 操作 i 的返回时间严格小于操作 j 的调用时间 ⇒ i 必须排在 j 之前；
- 时间上重叠的操作可以任意排列；
- 未返回（pending）的操作可以省略，或以任意合法结果补全。

找到解释时输出**见证**（一个合法的串行化），否则在穷举后给出
**不可行结论**。主算法为带记忆化的深度优先搜索（状态 = 已放置操作
掩码 + 队列内容），另用一个**独立的排列穷举**实现交叉核对两者结论。

## 输入格式

每行一个操作（空行与 `#` 注释忽略）：

```
enq <值> <调用时刻> <返回时刻|->
deq <值|-> <调用时刻> <返回时刻|->
```

- `deq` 的值列为 `-` 表示返回空；
- 返回时刻为 `-` 表示该操作未返回（pending）；
- 操作数 ≤ 12。

## 用法

```
go build -o queuecheck . && ./queuecheck examples/linearizable.txt
cat history.txt | ./queuecheck        # 无参数时读标准输入
```

退出码：0 = 可线性化（打印见证），1 = 不可线性化（穷举结论），
2 = 用法/解析/内部错误。

## 测试

```
go test ./...
```

测试包含固定用例、CLI 端到端，以及随机历史下主求解器与独立穷举的
对拍（3000 例），并由第三个独立校验器验证见证合法（真实时间偏序 +
FIFO 语义）。
