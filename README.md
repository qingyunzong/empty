# 购物车拆单优化（TypeScript + Node 内置库）

至多 14 件商品拆分为多个订单，求**实付最低**、同价时**订单数最少**的拆分方案，
并输出拆分明细与券使用证书；小件数用全分区暴力枚举对照验证最优性。

## 规则（见 `src/problem.ts`）

- 金额门槛优惠：每单商品金额满门槛减对应百分比，取可满足的最高档；
  折扣额 `floor(金额 × 百分比)`，**逐单向下取整**。
- 运费：每单折后金额（券前）满 ¥99 免运费，否则收 ¥8。
- 券：每张券**全局（跨所有订单）限用一次**，每单至多用一张，券后金额不为负。
- 目标：总实付（含运费）最小；并列时订单数最少。

## 算法

- 子集 DP：状态 `(商品集合 mask, 已用券集合 cmask)` → `(最低实付, 最少单数)`，
  转移枚举含最低位商品的一单 `S ⊆ mask` 并选择用哪张未用过的券（或不用）。
  复杂度 `O(2^k · 3^n · k)`，`n=14, k=3` 实测约 0.6 s。
- 券全局限用一次通过 `cmask` 状态位保证，回溯父指针还原拆分。
- 对照验证：`src/brute.ts` 用受限增长串枚举**全部集合分区**，
  每个分区内部再做"订单×券"指派小 DP；测试中对 `n=1..8`（多种子）与
  `n=10`（抽样）的随机实例逐一比对实付与单数，完全一致。
- 证书：`src/solver.ts` 的 `verifyCertificate` 独立重算每单金额、检查拆分
  不重不漏、每张券至多使用一次、合计一致，防篡改。

## 运行

```sh
npm test        # 编译 + node --test（9 个用例）
npm run solve   # 输出主算例拆分方案与券证书
```

环境：Node.js ≥ 18（测试用 v22.22.1），TypeScript 编译器 `tsc`（测试用 7.0.2）。
运行时代码零依赖，仅使用 Node 内置模块（`node:test`、`node:assert/strict`）。

## 实际结果（主算例，14 件商品 / 3 张券）

```
订单 1（8 件）: P01 机械键盘、P04 数据线、P07 笔记本支架、P08 鼠标垫、
               P11 摄像头、P12 键盘膜、P13 收纳包、P14 清洁套装
  商品金额 ¥317.00，门槛档 20% 减 ¥63.40，券 A 抵 ¥30.00，运费 ¥0.00，实付 ¥223.60
订单 2（3 件）: P02 鼠标、P09 扩展坞、P10 蓝牙音箱
  商品金额 ¥307.00，门槛档 20% 减 ¥61.40，券 B 抵 ¥10.00，运费 ¥0.00，实付 ¥235.60
订单 3（3 件）: P03 降噪耳机、P05 手机壳、P06 充电宝
  商品金额 ¥307.00，门槛档 20% 减 ¥61.40，券 C 抵 ¥5.00，运费 ¥0.00，实付 ¥240.60

总实付 ¥699.80，共 3 单
券使用证书: { "A": 0, "B": 1, "C": 2 }   // 券 id -> 订单序号（-1 为未使用）
```

对照：若全部并为一单，实付为 ¥743.80（93100 减 20% 再抵券 A），拆 3 单更优。
