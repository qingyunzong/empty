# 日志采集的八位组计数帧与结构化数据

日志采集连接里的多条消息只靠前面的十进制长度分开，长度若把下一条一起吞掉，结构化参数里的转义也会错位。实现可导入的Go组件，供采集连接调用，按任意字节块增量取消息。每帧是无前导零的1至9位十进制长度、一个0x20和恰好这么多载荷字节。长度0、前导零、帧首不是数字，或长度大于宿主maxMessageBytes，都在已经能够判定时失败，不得等待后续字节，也不得为超限载荷分配缓冲。未收齐的帧保留；Finish时缓冲不空则失败。载荷必须不多不少构成一条消息，帧内提前结束或帧内字节不够都是坏帧，多余字节不能留给后一帧。消息依次为尖括号中的PRI、版本字符、空格、时间、空格、主机、空格、应用名、空格、进程、空格、消息号、空格和结构化数据；此后要么结束，要么恰好再有一个空格及正文。PRI为1至3位、数值0至191，除单个0外禁止前导零；设施是PRI除以8的商，严重性是PRI模8。版本只能是字符1。时间可以是单个减号，或年月日T时分秒、可选点号加1至6位小数、再加Z或正负HH:MM。日期必须真实存在于公历，年份被4整除为闰年，但被100整除时仅被400整除才是闰年，因而0000是闰年、1900不是；时0至23，分和秒0至59，秒值60拒绝。小数保留原始数字。Z、+00:00和-00:00都合法且互相区分，组件不做时区换算。主机、应用名、进程、消息号可用单个减号表示空，非空时每个字节都在ASCII 33至126，长度上限依次为255、48、128、32。结构化数据是单个减号，或若干个直接相邻的元素。元素为左方括号、SD-ID、由单空格分隔的零个以上参数和右方括号。SD-ID与参数名长度为1至32，字节属可见ASCII，但不得含等号、空格、右方括号或双引号。参数写作name="value"；值中仅\\表示反斜杠、\"表示双引号、\]表示右方括号，别的反斜杠失败。反转义后的参数值以及正文都必须是严格UTF-8，并且不含0至31的控制字节。正文以EF BB BF开始时去掉这三字节并标记BOM，允许空正文；结构化数据后没有空格则正文缺失，与空正文不同。长度按原始字节计，转义和BOM都计入。重复参数按出现顺序保留。全空且无正文的载荷正好是“<134>1 - - - - - -”，长度为18。失败后组件停止，已交付消息保留。测试独立计数原始字节和反转义，覆盖长度跨入下一条、每个切块位置、转义、BOM、空正文与缺失正文、2000-02-29、1900-02-29、PRI边界、重复参数和Finish半帧；不得用被测组件生成期望帧。
