# 倒排词典的在线输出推动与后缀合并

倒排索引构建器按无符号字节字典序交付词项及其uint64 posting偏移，希望冻结后相同的剩余映射共享状态，而不是仅压缩单子树边。开发可导入Go词典构建包，Add接收严格递增且不重复的任意字节键与uint64值；键可含0和255，空键只能最先加入，输出值不要求递增。Finish返回不可变的确定无环加法转导图：一条边恰消耗一个字节，带非负uint64输出，状态可带非负uint64终止输出，根还有initialOutput；查询接受键的值是根输出、沿途边输出与终止输出之和。不存在的键不得因到达非终止状态而成功。每个可达非根状态须有至少一个接受后缀，并使所有接受后缀的剩余输出最小值为0；根也按同样规则规范化，整词典最小值放在initialOutput。规范化后，终止标记及终止输出、按字节排序的每条边的字节/输出/规范目标完全相同的状态必须合并；每个状态只能有一个给定字节的出边，不允许靠保存全量键值表代替转导图。增量加入新键时立即最小化上一键已经封闭的后缀，并将其放入不可修改的规范状态注册表；只允许当前最后键的前缀路径处于未封闭可变状态，不能先建立全量trie再在Finish最小化。新键的值变小时，必须沿公共前缀推动输出并修正分叉输出，不能修改已共享的目标状态或把uint64减法下溢当合法输出。记录每次Add后的可变状态数、已注册规范状态数、保留的完整历史键数量；后者至多1，可变路径状态数至多最后键长度加1；注册表和最终图存储不计为完整历史键，但不能在其他容器隐藏展开键或未最小化trie。输入顺序或重复键错误使本次Add完全无影响，调用者可继续加入合法下一键；Finish幂等，之后Add拒绝。空词典用一个无出边非终止根、initialOutput=0表示，是剩余输出规范规则的唯一例外。冻结图供宿主调用Lookup、Rank和Select：Rank给严格小于查询键的已收录键数，Select按0起始字节字典序返回键及原值，越界明确返回不存在；用每状态接受后缀路径数跳过分支，不能把共享状态只计一次，也不能为每次Rank/Select全量枚举词典。所有计数与路径输出相加检查uint64溢出，不能浮点化。给宿主构建及查询例，独立小数据参考先建普通trie、把每子树最小值上提后按完整状态签名归并，再与在线图的可达状态数、边数、每个键值及有序查询结果比较；图节点编号不作正确性条件。构造两个不同前缀共享同一残余输出子图、后来值降低导致输出向分叉推动、前缀本身也是键、全uint64端点、非法Add后继续及同一共享后缀从多条路径可达的测试，不以随机命中率替代最小性核对。
