# tx-indexed-db

TypeScript 实现的事务型内存索引库。

## 语义

- **字段索引映射行 ID**：每个表可声明普通索引（值 → 行 ID 集合）与唯一索引（值 → 行 ID），随提交增量维护。
- **差量合并发布**：事务内对同一行的多次写只发布最终净差量（`before` = 提交前映像，`after` = 最终映像）；净零变更不发布。
- **延迟唯一性校验**：唯一约束在提交时针对批内最终状态校验（先删后增），因此同一事务内两行可互换唯一键。
- **整体回滚**：校验失败或回调抛异常时，已提交状态不被部分修改，订阅者也不会收到通知。
- **提交后订阅、可重入**：订阅回调在提交完全应用后执行，回调内可再次开启并提交新事务（通知安全嵌套）。
- **模型核验**：`ModelTable` 是朴素复制表，仅靠订阅通知驱动，每次校验时全量重建索引，与真实库的增量索引逐项深比较。

## 运行

```sh
npm test   # tsc 编译 + node --test 执行全部测试
```

## 结构

- `src/database.ts` — `Database` / `Transaction` / 索引维护 / 提交管线（校验 → 应用 → 发布）
- `src/model.ts` — 全量重建索引的参照模型
- `test/database.test.ts` — 上述语义的规格测试
- `test/model-verification.test.ts` — 多种子随机操作序列下真实库 vs 模型的核验
