# raster

整数有向闭环 → 像素行区间的栅格化库（仅 Go 标准库）。

## 语义约定

- 像素 `(x, y)` 覆盖 `[x, x+1) × [y, y+1)`，像素中心为 `(x+1/2, y+1/2)`。
- 中心在多边形内部即填充；中心恰好落在边上（边界）也算内部。
- 填充规则：`NonZero`（非零绕数，洞需反向）与 `EvenOdd`（奇偶，方向无关）。
- 扫描线取半整数 y，永不经过整数顶点：顶点不会被重复计交点，
  每条非水平边每行至多贡献一个交点。
- 水平边（`y1 == y2`）位于整数 y 上，永不与扫描线相交，直接排除。
- 交点横坐标用 int64 精确有理数表示（`num/den`），排序用交叉相乘比较；
  坐标应远小于 int32 范围以避免中间乘积溢出 int64。
- 输出 `[]Row`：按 Y 升序，每行 `Spans` 为排序合并后的闭区间 `[X0, X1]`。

## 用法

```go
rows := raster.Fill([][]raster.Point{
    {{0, 0}, {8, 0}, {8, 8}, {0, 8}}, // 外环，逆时针
    {{2, 2}, {2, 6}, {6, 6}, {6, 2}}, // 洞，顺时针
}, raster.NonZero)
```

## 验证

测试用独立的逐像素精确射线模型（`contains`，+x 方向射线、精确整数运算、
边界算内部）在包围盒上逐像素求值，与扫描线输出做 `DeepEqual` 核对：
固定用例（方块、洞、三角形顶点行、边界像素中心、退化/自触/共享边/
三层嵌套/蝴蝶结）+ 3000 组随机多环 × 两种填充规则。

实测结果（Go 1.27.1, linux/amd64）：

```
$ go test ./...
ok  	raster	0.252s
$ go test -race -count=1 ./...
ok  	raster	2.006s
```
