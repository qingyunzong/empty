# vv-replica-sim

Dynamo 风格副本模拟：版本向量、冲突集合（siblings）、读修复、分区愈合，
并保证被撤回的旧版本永不复活。零依赖，TypeScript 实现。

## 运行

```sh
npm test    # 编译并执行全部测试（node:test）
npm run demo  # 打印一次分区/愈合场景及支配关系证据
```

## 模型

- **版本向量**（`src/version-vector.ts`）：逐副本计数器，偏序比较得到
  `dominates / dominated / equal / concurrent`，合并取逐点 max。
- **冲突集合**（`src/siblings.ts`）：每个键保存一组两两并发的版本。
  集合并模型 = 并集 + 按支配关系剪枝；并发版本全部保留，绝不按时钟覆盖。
  由于剪枝基于并集内部的支配关系，被撤回的版本在任何后续合并中都会被
  再次剪除 —— 撤回是单调的，不会复活。
- **副本与集群**（`src/replica.ts`, `src/cluster.ts`）：写入携带客户端
  因果上下文；协调读至少联系 2 个副本，合并后对缺版本的副本做读修复；
  链路矩阵模拟网络分区，愈合后反熵同步至不动点。
- **支配证据**：每次合并输出 `DominanceEvidence` 记录
  （谁支配谁 → 撤回谁 / 谁与谁并发 → 双双保留）。

## 测试要点（`test/`）

- 版本向量偏序与合并性质；
- 并发写保留为冲突集、支配写撤回旧版本并输出证据；
- 读仲裁（≥2 副本）与读修复；
- 随机分区 + 随机写/同步/读修复的模型核验（多种子、确定性 PRNG）：
  逐步检查每副本“见过支配者后旧版本不复活”，愈合后所有副本收敛到
  参考模型（全部写入的并集剪枝结果）；
- 撤稳定性：任意投递顺序（全排列）下最终冲突集一致。
