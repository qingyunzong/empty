# tier-assign：质量档分配优化

为 ≤16 个用户各自选择独立质量档（档 0 表示不服务），在两类资源预算（均 ≤100）下求最优分配。

## 问题定义

- 每个用户有若干档，每档给出两类资源消耗 `(r1, r2)` 与收益 `profit`；档 0 固定为 `(0,0,0)`（不服务）。
- 用户间约束：
  - **组合收益** `combos`：用户 i 选档 ti 且用户 j 选档 tj 时额外加 `bonus`（可为负）。
  - **同档** `sameTier`：两用户档索引必须相同。
  - **分档** `diffTier`：两用户档索引必须不同。
- 由于预算与跨用户约束，预算状态不可逐用户独立分解，整体用分支限界搜索。

## 目标（字典序）

1. 总收益（档位收益 + 组合收益）最大；
2. 处于各自最高档的用户数最多；
3. 分配向量字典序最小。

## 输出

最优解的分配向量、总收益分解、两类资源用量，以及**逐条约束证书**
（每个用户档位合法性、两条预算、每个组合是否触发、每条同档/分档约束、收益合计、独立重算一致性）。

## 保存 / 恢复

求解器为确定性 DFS（显式栈），任意时刻可序列化检查点（含问题哈希，防止错配恢复）；
暂停后恢复继续搜索，最终结果与节点总数和不暂停完全一致（有测试保证）。

## 使用

```bash
npm test                 # 编译并运行全部测试（含与暴力枚举的对拍）
npm run cli -- solve examples/small.json
node dist/src/cli.js solve examples/small.json --steps 3 --save cp.json   # 暂停并保存
node dist/src/cli.js resume cp.json                                       # 恢复并求完
```

## 结构

- `src/types.ts` — 问题/解类型、校验、求值、字典序比较
- `src/solver.ts` — 分支限界求解器（确定性、可检查点化）
- `src/bruteforce.ts` — 暴力枚举基准，用于小例核验
- `src/certificate.ts` — 逐条约束证书生成与独立核验
- `src/cli.ts` — 命令行入口
- `test/` — 对拍、断点恢复、约束语义、证书核验测试
