# 调查数据码组与字面槽交错接入

历史调查数据的压缩区把8个操作码先写在一起，再跟其中需要的8字节字面槽，不能按“码后立刻一个值”解析。给数据导入宿主开发Go可导入的增量行解码包，只处理下面封闭S8数据区，不解析SPSS文件字典或运行统计分析。宿主给按序字段：numeric占一个槽，bytes(width)占ceil(width/8)个槽，width为1..1048576；字段名唯一，数值为IEEE binary64原始位型或missing，bytes保留原字节且不做字符集转换。给定数值端序、整数bias在-32768..32767，以及明确的行数上限和单行字节预算。输入由连续码组组成，每组先有8个u8操作码，之后按码在组内的顺序依次存放所有253码需要的8字节字面槽，再开始下个码组。0为padding，不生成槽也不前进字段；1..251仅可用于numeric，生成精确整数code-bias的binary64位型；253消费一个字面槽，numeric按端序保留位型但固定0xffefffffffffffff转missing，bytes原样；254仅可用于bytes，生成8个ASCII空格；255仅可用于numeric，生成missing。252是终止码，不生成槽，必须位于完整行边界，所在组其后所有操作码必须0，终止组之后不得再有物理字节。终止组里252之前的253字面槽仍在整个8码头之后，必须消费并验证后才结束，不能看到252就跳过此前字面数据；252之后不允许藏253及字面槽。每行按字段顺序消费槽，字节字段由相邻逻辑槽拼接，最后一个槽超出width的字节必须全是ASCII空格再裁去；不能把长字符串的后续槽误当下一个字段，也不能让0码消耗字段位置。字段列表至少一项。只有明确252和Finish成功后才报告流完整；物理EOF没有252即截断，即使已到行边界，组头不足8字节或字面槽不足8字节同样截断。Push支持任意字节切分，返回已完成且校验通过的行前缀，当前未完成行不交付；错误为永久失败态，之前已交付行保持有效，Finish重复或失败后Push报状态错误。允许投影字段子集并保留请求次序，但所有未投影字段的码类型、填充、行完整性仍要验证，不能以跳列漏掉坏数据；不为未投影bytes拼接完整字符串，只保留其当前槽及计数。给出物理来源：每个输出数值或字节片段标明码组偏移、码下标和对应字面物理区间，重复0码没有伪造行来源。除未交付一行的投影值、8码头和一个字面槽外，不保留整个流；声明字段宽度超过单行预算在读任何数据前拒绝，超过行数上限在产生该行前拒绝。提供接入宿主例、独立码组编码夹具及一次性参考解释器，比较所有切块点的值和来源；覆盖码组跨两行、一个长bytes跨多个组、最后一行的253字面槽位于252之后的物理位置、同组多个253、数值NaN和负零位型、系统missing、字符串包含0和0xff、未投影列坏填充、非法码类型、终止后额外字节，以及数据在每个字节处截断。只证明符合S8契约，不声明完整SAV兼容。
