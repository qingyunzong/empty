# 虚拟列表采集的锚点恢复

浏览器采集宿主调用TypeScript虚拟列表读取组件，适配器提供read()返回视口中的有序行和滚动代数，以及move(anchorId,delta)返回新代数；行含稳定ID、非负版本及内容。同一代数read结果不变，move可能成功后响应丢失，此时read可确认代数是否增加；若增加只能读新视口，不得重复滚动；代数未变则可重试同一移动，读取失败先停止。每次移动以当前最后一行为锚点、delta固定为1；若锚点已被移除则适配器返回stale且不移动，重新read后再试。只接受代数递增，行同ID较高版本覆盖旧版、同版本不同内容报错。连续K次成功移动后没有新ID且没有更高版本即结束，stale不计次数；调用方设正整数移动预算，预算耗尽返回未完成及已采集数据。由状态机驱动适配器，测试重排、删除锚点、响应丢失和终止边界；外部网络不参与验收。
