# 压缩文档ID差分列表与跳跃块（纯标准库，Python 3.11）

从空仓库实现的迷你倒排索引：文档ID 差分压缩（delta + varint）+ 跳跃块，
支持交 / 并 / 差与 `advance(target)`，严格递增验证，统计实际解码块数。
不使用任何搜索服务或全文检索库，仅依赖标准库，测试基于 `unittest`。

## 文件

- `postings.py` — 压缩列表编码/解码、`PostingsReader`（`next`/`advance`）、交并差
- `index.py` — 分词器与倒排索引（布尔查询 AND/OR/NOT）
- `demo.py` — 运行样例（合成 UTF-8 中文文档）
- `test_postings.py` — 25 个 unittest 用例

## 压缩格式

```
流  = 块*
块  = varint(条目数) varint(块内最大文档ID) varint(负载字节数) 负载
负载 = 逐条 varint(差分)，差分 = 当前ID - 前一ID（首条相对 -1），必须 >= 1
```

- 块头的「块内最大文档ID」即跳跃指针目标：`advance(target)` 时若它小于
  `target`，整块跳过（不解码、不计入 `blocks_decoded`）。
- 解码时每块结束校验「解码末ID == 块头声明ID」，差分 <= 0、块目标倒退、
  数据截断均抛 `CorruptPostingsError`（损坏差分导致倒退会被拒绝）。
- 构建时强制文档ID严格递增（重复/倒退抛 `ValueError`）。

## 分词规则（index.py）

1. 先 `str.casefold()` 大小写折叠；
2. 词元 = 连续 Unicode 字母/数字串（`[^\W_]+`），空白、标点、下划线、符号均为分隔符；
3. 长度 > 1 的连续 CJK 串额外产出全部单字与相邻二字（bigram）词元，
   如「苹果手机」额外产出 苹/果/手/机 与 苹果/果手/手机；
4. 文档ID = `add_document` 调用序号，从 0 开始，天然严格递增。

查询时 `postings(term)` 先精确命中；长度 > 2 的纯 CJK 词未命中时退化为
其 bigram 列表求交。

## 语义要点

- `advance(target)`：`target <= 当前ID` 时不移动、不跳过（含相等）；
  否则前进到第一个 `>= target` 的ID，沿途整块跳过未命中的块。
- `reader.blocks_decoded` 统计**实际解码**的块数（被跳过的块不计）。
- 空列表参与交/并/差均正确：交空得空，并空得另一方，差空不变/得空。

## 运行样例（`python3.11 demo.py`）

```
== 分词样例 ==
  '香蕉和苹果都是常见水果。' -> ['香蕉和苹果都是常见水果', '香', '蕉', '和', '苹', '果', '都', '是', '常', '见', '水', '果', '香蕉', '蕉和', '和苹', '苹果', '果都', '都是', '是常', '常见', '见水', '水果']

苹果: [0, 1, 3, 7]  手机: [0, 2, 4, 6, 7]  芯片: [0, 2, 6, 7]

== 交集：苹果 AND 手机 ==
  文档ID: [0, 7]
== 并集：苹果 OR 芯片 ==
  文档ID: [0, 1, 2, 3, 6, 7]
== 差集：手机 NOT 芯片 ==
  文档ID: [4]

== advance 演示（block_size=3）==
  列表: [2, 5, 7, 11, 13, 17, 19, 23, 29, 31]
  next()        -> 2  (解码块数=1)
  advance(2)    -> 2   # 到当前ID不跳过 (解码块数=1)
  advance(18)   -> 19  # 整块跳过 (解码块数=2)
  advance(100)  -> None  # 越过末尾 (解码块数=2)

== 损坏差分拒绝演示 ==
  已拒绝: CorruptPostingsError: 差分必须为正整数（严格递增），得到 0
```

## 测试结果（`python3.11 -m unittest test_postings -v`）

25 个用例全部通过（0.01s 量级），覆盖：

- 编解码往返（空/单条/多块/大ID）、`from_bytes` 往返
- 构建期严格递增校验、非 int 拒绝
- 损坏拒绝：零差分、块跳跃目标倒退、负载截断、块校验不符、varint 截断
- `advance`：到当前ID不跳过、块内推进、整块跳过（解码块数不增）、
  越过末尾、与 `next` 交替、`blocks_decoded` 精确统计
- 交/并/差：空列表组合、固定样例、50 组随机数据对照 Python set
- 分词：casefold/分隔符、CJK 单字+二字、中英数字混合
- 索引：布尔查询、未命中词返回空、长 CJK 词 bigram 求交
