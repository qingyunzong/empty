# mix-cli 配比 CLI

从 ≤12 种液体中选择整数单位量（总量 ≤ 40），使混合浓度落在有理闭区间
`[lo, hi]` 内；在所有可行解中先最小化整数总成本，成本并列时取用量向量
字典序最小者。输出精确浓度（最简分数）与用量；无解时完备搜索后报告无解。

## 使用

```sh
npm run build          # 编译到 dist/
node dist/src/cli.js [--json] [config.json|-]   # 缺省或 "-" 读标准输入
```

输入 JSON：

```json
{
  "liquids": [ { "concentration": "0.10", "cost": 5 }, ... ],
  "target": ["1/5", "3/10"],
  "maxTotal": 40
}
```

- `liquids`：1..12 种；`concentration` 支持 `"p/q"`、整数、有限小数（精确解析）；
  `cost` 为非负整数。
- `target`：闭区间 `[lo, hi]`，同上有理数格式。
- `maxTotal`：可选，默认 40，上限 40。

退出码：`0` 有解；`1` 无解（已完备搜索）；`2` 输入非法。

## 方法

设 `x_i ≥ 0` 为整数用量，`S = Σx_i ≥ 1`。浓度约束
`lo ≤ Σc_i·x_i / S ≤ hi` 两边同乘正数 `S`，等价于两个线性约束
`Σ(c_i − lo)·x_i ≥ 0`、`Σ(hi − c_i)·x_i ≥ 0`。所有系数用 BigInt 有理数
通分为整数后：

1. **第一阶段** 分支限界求最小成本：按变量深度优先枚举，利用成本下界
   （成本非负）与浓度可达性（剩余容量 × 后缀最大系数）剪枝；剪枝条件均为
   充分必要条件的安全侧，因此搜索完备——返回 `null` 即证明无解。
2. **第二阶段** 固定成本为最优值，按字典序升序深度优先，第一个可行向量
   即为用量向量字典序最小解。

## 测试

```sh
npm test               # tsc 编译 + node --test
```

测试包括：有理数运算单元测试、手算用例、字典序并列用例、无解用例、参数
校验，以及 **小域全向量核验**——400 个确定性随机小实例（≤4 种、总量 ≤7）
与暴力枚举全部向量的参照实现逐一比对成本与向量；另有 12 种液体、总量 40
的满规模有解/无解性能用例。
