# 间断多通道采集的时间标注与样本定位

实验采集宿主要把EDF+式记录接入统一时间查询，请交付TypeScript可导入的记录解码与区间定位模块，不诊断、不绘图。宿主已解析文件头，给连续C或间断D模式、正有理记录时长T、普通通道顺序及每通道正整数每记录样本数ns、digitalMin<digitalMax和不同的有理physicalMin/Max，最后固定一个标注通道容量a个字节。每记录先按通道顺序存各自ns个little-endian int16，再存a字节标注；a>=4，int16允许超出声明digital范围，仍按pmin+(raw-dmin)*(pmax-pmin)/(dmax-dmin)精确转换，不裁剪。标注区连续TAL，每条为onset、可选0x15加duration、0x14、若干由0x14结尾的UTF8注释、0x00；onset严格匹配[+-][0-9]+(.[0-9]+)?，duration匹配[0-9]+(.[0-9]+)?，点为字面句点，二者均转换为任意精度有理数。注释允许TAB/LF/CR，拒绝其余U+0000..U+001F，0x14作为分隔符不进入文本，0x15只能出现在时间字段；非法UTF8拒绝。第一条TAL必须恰为onset、0x14、0x14、0x00且无duration，其空注释仅给本记录起点，不输出事件；后续TAL必须有至少一条非空注释，每个注释包括空串均成为同onset/duration事件，保留次序、允许同文重复，duration缺失和0不同。遇到TAL边界处0x00表示余下全部须0填充，TAL不能跨记录。首记录起点s必须0<=s<1；C模式下一记录起点恰为前起点+T，D模式下一起点须>=前起点+T，允许间隙但不允许重叠。通道j样本k的时刻为s+k*T/ns[j]，不把不同采样率强行对齐，不把记录间隙填成0；注释onset可负且可在本记录之外，不用它改变普通样本的记录起点。任意字节切块输入，整记录全部验证后才交付样本与事件，后记录错误保留先前已提交记录且不泄漏失败记录。宿主可对已提交记录查询任意有理半开时间区间[L,R)，返回各通道匹配样本的连续索引段、字节来源和对应精确首末样本时刻，空段不输出，不先展开所有样本；L>R拒绝，L=R为空。事件查询按onset落入[L,R)选择，不按duration相交选择，按记录号、TAL号、注释号稳定排序。提供调用示例及独立逐样本参考测试，覆盖多速率、负增益、非零首记录小数、D间隙、C误差、跨记录事件、空注释与填充、非整数字节边界切块和精确端点；输入头结构及测试用字节由项目定义，无需实现EDF文本头或访问设备。
