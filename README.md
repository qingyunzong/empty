# routecli — 受限路径费用 CLI

在通行费网络中规划 **先实付最小、再行驶时间最短** 的简单路径（不重复节点，至多 12 个节点、6 张券）。仅使用 Go 标准库。

## 费用模型

- **每边通行费 / 时间 / 油耗**：每条有向边带 `toll`、`time`、`dist`。
- **单次累计满额返还**：累计通行费达到 `rebate.threshold` 后，**只有在指定收费站**（`rebate.stations`）才一次性兑现 `rebate.amount`。返还是路径级事件，**不作为独立负边**加入图模型。
- **优惠券**：`coupons[].requires` 依赖**已走路段集合**，全部走过才生效；券之间**互斥**，每条路径至多生效一张（取折扣最大者）。
- **燃料**：油箱容量 `fuel.capacity`、初始油量 `fuel.start`；节点可设 `fuelPrice` 按单位售油，补给费用计入实付。固定路径的最优加油方案由 (位置, 油量) DP 精确求得。
- **目标**：字典序 `(实付, 时间)`。

## 用法

```sh
go run . -input examples/network.json            # 不限预算，分支限界求最优
go run . -input examples/network.json -budget 6  # 预算截断：保留最佳可行解 + 下界
go run . -input examples/network.json -verify    # 与简单路径枚举、有限状态搜索对照
```

输出包含搜索状态、实付下界、以及**逐边状态与精确费用**（每边通行费、加油量与费用、油量变化、累计通行费、返还在哪站兑现、累计实付）。

## 求解器（互为对照）

1. **简单路径枚举** `Enumerate`：穷举所有不重复节点路径，`EvalPath` 精确求值，作为基准真值。
2. **有限状态搜索** `StateSearch`：在 `(节点, 油量, 累计通行费(封顶), 已访问集, 已走边集, 返还是否兑现, 券)` 的有限状态图上做标号修正松弛；状态各维单调，图有限且无环。返还与券都是**状态条件转移**，不是负边。
3. **分支限界** `BranchBound`：DFS + 乐观下界（当前实付 − 尚可兑现的返还 − 最佳可用券）剪枝；带扩展预算，**预算未完时保留最佳可行解与有效下界**。
