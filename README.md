# 采集分片键集的可剥离差分

两个采集分片要定位遗漏的记录ID，只传输固定单元摘要，不能把摘要失败写成两边相同。实现Go可导入的IBLT集合差分包，ID为uint64，两个输入均为集合不含重复；配置给正整数单元数m、1<=k<=m个互异种子和哈希方案ID。宿主给ID到k个互不相同单元下标及64位校验值的确定性函数，返回下标重复或越界要整次拒绝。每格是任意精度有符号count、uint64 keyXor及checkXor，插入键在各格count加1并异或键与校验，删除是count减1且同样异或；两个表配置完全相同才可相减，count相减、两个xor分别异或。对差表执行剥离：格count恰为1或-1，keyXor的校验等于checkXor且该键确实映到本格时才是候选，每步选当前最小候选格号，输出键及正负方向并从该键的全部格消去该符号贡献。每次使用候选前须重新校验，防止队列里过期候选被重复消费；已输出键再次出现或同键反向出现报矛盾并保留残余现场，不无限循环。全部格归零为peeled状态，仍有非零格但无候选为incomplete，返回残余格，不能推断具体未恢复键。有限校验有碰撞风险，peeled仅表示摘要被完全剥离，不能宣称无条件相等；另提供验证接口，由宿主传入两边完整集合快照，检查输出的正负键恰为真实A减B与B减A，只有这个接口成功才返回verified。剥离在工作副本上进行，原摘要不变；一步定义为成功消去一个候选键，候选检查不另计步；支持正整数步预算和暂停状态，恢复绑定原差表及配置指纹并验证状态一致，暂停不重复产出。交付宿主调用例和测试，用小集合直接差分核对成功剥离、负格、0键、两个格同时暴露同键、不可剥离环、校验碰撞及每个暂停点，造出假纯格证明摘要完成和完整集合验证必须区分。
