# 库页帧的盐值与滚动校验

副本采集若用文件字节序计算帧校验，魔数最低位不同的文件会把下一帧的页号算进上一帧。实现可导入的Go组件，供副本采集调用，不打开数据库。头32字节是8个大端uint32：魔数、版本、页大小、检查点序号、盐1、盐2、校验1、校验2。魔数只能是0x377F0682或0x377F0683，版本必须是3007000，页大小是512至65536的2的幂。校验把输入按8字节分组，每组按魔数决定字节序读出x和y：0x377F0682用大端，0x377F0683用小端。s0与s1都是uint32，从0开始；每组先把s0加上x与当时的s1，再把s1加上y与更新后的s0，加法都模4294967296。头的校验只覆盖前24字节，必须等于头里的两个校验字。每帧是24字节帧头加一页。帧头是大端uint32页号、大端uint32提交后的页数、盐1、盐2、校验1、校验2。盐必须与头相同，页号从1起。帧校验从上一帧或头的校验继续，先覆盖页号和提交页数这8字节，再覆盖整页。提交页数为0表示该帧不是提交点。页数据超过宿主maxPage时在头读出页大小后拒绝，不按声明分配。Push可停在页中间；Finish时帧未完成则失败。失败停止组件，已交付帧保留。测试用独立滚动加法对照两种魔数、盐不匹配、提交页数为0和页被切开。期望帧不得调用被测组件生成。
