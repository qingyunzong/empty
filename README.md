# tlv

BER 风格 TLV（Tag-Length-Value）二进制解析库，仅使用 Go 标准库。

## 功能

- 短形式（< 128）与长形式（最多 8 个长度字节）定长长度，以及构造值的编码与解析。
- 拒绝非最短长度编码：长形式用于 < 128 的长度、长度前导零字节、保留字节 0xFF、长度溢出。
- 拒绝嵌套深度超限（`ParseDepth` 可配置，默认 `DefaultMaxDepth = 64`）。
- 拒绝子项越过父项内容边界（含不定长子项的 EOC 越界）。
- 不定长度（0x80）仅构造项可用，原始项使用即报错；EOC 仅允许作为不定长终止符。
- 所有错误携带字节偏移（`Error.Offset`）与分类（`Error.Kind`）；截断输入的
  错误偏移恰为 `len(输入)`。
- `Node.Encode` 以最短长度重新编码，合法树的解析-编码往返与原字节完全一致。

## 用法

```go
n, err := tlv.Parse(data)          // 默认深度限制
n, err := tlv.ParseDepth(data, 8)  // 自定义深度限制
out := n.Encode()                  // 重新编码
```
