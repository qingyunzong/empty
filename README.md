# pathrule

路径规则交集 CLI：判断两个允许模式是否存在共同路径，并给出**段数最少、
其次字节序最小**的见证路径；可同时指定排除模式集合，见证须属于两个允许
模式且不属于任何排除模式。

## 模式语法

- 段以 `/` 分隔；每段只能是小写字母字面量 `[a-z]+`、单段通配 `*`（恰好
  一段）或整段双星 `**`（零段或多段）。
- 空段（`a//b`、前导/尾随 `/`、空模式）及其他形状（`***`、`a*`、大写
  等）一律拒绝。
- 每个模式至多 12 段；排除模式至多 10 个。

## 使用方法

```sh
npm run build          # tsc 编译到 dist/
node dist/src/cli.js <allow1> <allow2> [-x pat]... [--budget n] [--max-depth n]
```

输出与退出码：

| 输出              | 含义                                   | 退出码 |
|-------------------|----------------------------------------|--------|
| `WITNESS <path>`  | 段数最少、字节序最小的共同路径         | 0      |
| `WITNESS (empty)` | 零段路径即见证                         | 0      |
| `EMPTY`           | 已证明不存在共同路径                   | 1      |
| `UNKNOWN: <原因>` | 预算/深度不足，既未证明空也未找到见证  | 2      |
| 用法或模式错误    |                                        | 3      |

示例：

```console
$ node dist/src/cli.js 'a/*' '*/b'
WITNESS a/b
$ node dist/src/cli.js 'a/**' '**' -x 'a,a/*'
WITNESS a/a/a
$ node dist/src/cli.js 'a' 'b'
EMPTY
$ node dist/src/cli.js 'a' '**' --budget 0
UNKNOWN: expansion budget 0 exhausted
```

## 算法

1. 每个模式编译为 NFA：字面量边、`*` 任意边、`**` 自环任意边加 ε 跳过边。
2. 搜索状态为每个 NFA 的子集构造掩码组成的积（两个允许 + 全部排除）。
   允许 NFA 掩码归零即死路；排除 NFA 掩码归零反而是好事（永不可能被
   排除），不剪枝。
3. 符号段字母表 = 规则集中出现过的全部字面量 + 一个 "other" 字母，代表
   所有非字面量段；其最小具体代表是未被占用的字节序最小串（必为
   `a`*i 形）。具体化见证时用它替换 other。
4. 以（段数, 拼接串字节序）为键的最小堆做最佳优先搜索。追加段严格增大
   键且保序（`/` 小于任何小写字母），因此首个弹出的接受状态即最短、
   字节序最小见证；同一自动机状态只保留最优键。
5. 前沿被完全耗尽 → `EMPTY`（已证明）；扩展预算或深度上限触顶 →
   `UNKNOWN`，与空交集严格区分。

## 测试与验收

`npm test`：编译后运行 `node --test`，包括

- 模式解析（合法/非法/段数上限）与直接 glob 匹配器单测；
- 交集搜索单测（最短优先、字节序平局、排除迫使泵长、空路径见证、
  预算/深度不足时的 UNKNOWN）；
- **短域穷举对照**：3000 个随机小规则集（字面量 ∈ {a,b}，≤4 段，
  0–2 个排除），符号搜索结果与在有限域（段 ∈ {a,b,aa}，≤5 段）上
  用直接匹配器穷举出的最短见证逐一比对；
- CLI 端到端（输出文本与退出码）。

实际运行结果见 [RESULTS.md](RESULTS.md)。

## 说明

- 仅使用 Node.js 内置模块（`node:test`、`node:assert`）；无运行时依赖。
- 环境无法访问 npm registry，`@types/node` 不可得，故
  `types/node-shims.d.ts` 手写了用到的最小内置模块声明。
