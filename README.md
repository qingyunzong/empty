# 采集浮点值的最短往返十进制契约

采集网关要把binary64值写进语言无关的交换字段，固定17位虽然能往返，却会留下多余数字；按显示精度截断又会改变位型。开发Go可导入的规范格式化包，输入uint64原始位型，输出本题定义的带sign的十进制元组(sign,c,q)与文本，不负责JSON或界面显示。对正有限非零值v，寻找c*10^q，c为无前导零且不被10整除的正整数，c最多17位、q在-400..400，使该精确十进制值按binary64最近偶数舍入恰回原位型；先最小化c的十进制位数，再最小化与v的精确绝对差，仍并列优先c为偶数，最后选数值较小者。负值对绝对值按同样规则选再加负号，不能改用向零舍入。最短指有效数字数，不是全部文本字符数，不为省一个指数字符改选更多有效数字。文本固定科学表示：c首位后仅在有剩余位时加点及全部剩余位，再加小写e和q+digits(c)-1的最短十进制整数；正指数不带加号，例如c=125,q=-2为1.25e0。正负零分别为0e0和-0e0；正负无穷为inf和-inf；所有NaN为nan并在元数据标明非往返、原始NaN位型另行保留，不能声称统一nan文本恢复其payload。有限值用精确整数或有理数确定舍入区间，不调用strconv.FormatFloat、fmt浮点格式化、big.Float.Text、外部Ryu库或先格式化后删位。binary64指数域e和52位尾数f：e=0时v=f*2^-1074，1<=e<=2046时v=(2^52+f)*2^(e-1075)。用相邻正位型得到前后数，v的舍入区间为与两邻数中点之间，v的有效整数尾数为偶数时两端包含，否则两端不包含；最大有限数的后邻按虚拟2^1024处理，因此上端为有限溢出阈值且不包含。不能假设二次幂上下间距相同，也不能把严格端点用整数向下取整后误收。选择可按位数及q搜索精确整数区间并取最接近v的候选，允许math/big.Int与Rat，不枚举10^17个c或所有小数串；通过整数界排除全部较短位数，正确处理c不被10整除的条件。返回所选c/q、舍入区间端点及开闭标记，并提供核验函数：重算位型的精确区间，确认候选在内，再核对不存在较短有效位数且同位数没有更近或更优决胜候选；仅ParseFloat往返成功不足以证明最短。给交换字段宿主调用例，独立有理区间参考核验固定夹具及随机uint64位型；测试允许用strconv.ParseFloat作为额外往返检查，但生产选择和最短核验都不得借它试探。覆盖最小次正规数、最大次正规与最小正常数两侧、每个指数附近二次幂及其相邻位型、最大有限数、正负零、不同NaN、十进制整数附近、需17位的数和中点开闭；在缩小指数与尾数的玩具二进制格式上穷举全部有限值及有限c/q，独立核对最短、最近及偶数决胜，而不是只与另一个格式化库字符串相等。输入及返回证书不能被并发调用修改，不要求纳秒级性能或固定机器字实现。
