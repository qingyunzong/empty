# 采集词汇映射的存在约束分类与反模型

不同来源的采集词汇靠概念包含及关系存在约束对齐，不能把“有某类关联对象”误当成当前对象属于该类。为元数据接入宿主开发Go可导入的分类包。输入至多128个概念名、32个关系名和5000条带唯一ID的规范公理；另有保留概念Top和Bottom。只接受四类公理A包含于B、A1交A2包含于B、A包含于存在r.B、存在r.A包含于B，字母为概念名或Top/Bottom，r为已声明关系；不支持否定、个体常量、逆关系或文本语法，未知名和重复ID整批拒绝。语义是任意非空论域上的一元概念集合及二元关系，Top为整个论域、Bottom为空，交为集合交，存在r.B为所有至少有一个r后继属于B的对象。分类返回任意概念对A/B是否在所有满足公理的解释中A集合包含于B集合，及每个概念是否必为空；某个概念空并不意味着全局公理无模型，只有Top必为空时全局不一致，此时所有包含关系成立。循环存在公理可用有限环满足，不能无限创建新对象或把循环本身判不一致。实现基于有限完成图的工作队列：每个概念X有标签S(X)，初始含X及Top；关系边R(X,r,Y)表示要求的后继，命中A包含于存在r.B时创建X到概念节点B的边，而不是任意把B加进S(X)。用四类公理及目标Bottom向前驱传播的规则饱和；只在出现新标签或新边时登记工作，记录实际新事实次数，不枚举所有集合解释作为正式算法。Bottom标签使该概念对所有右侧概念包含成立；其不会自动导致Top空，除非存在实际推导。正面结论附可独立重放的有限推导DAG，叶为输入公理或初始事实，每步列出使用的前提及规则，不能把循环互相引用当证明；推导不要求最少。若全局一致且A不包含于B，给出一个显式有限反模型、指定根对象属于A而不属于B；反模型中逐个列出对象的概念成员和关系边，宿主可直接按集合语义验证全部公理，不能只返回“规则没推出来”。可从饱和完成图去除带Bottom的节点后构造反模型，但必须实际验证它符合所有四类公理，Top覆盖论域、Bottom为空，空论域不是有效模型。分类与证明、反模型必须对应同一个不可变公理快照；宿主替换一批公理时可重新分类，旧结果不得被修改。提供词汇对齐宿主调用例及独立直接集合模型核验器；对最多两个普通概念、一种关系的随机公理，测试枚举论域大小1..3上的全部集合和关系解释，逐项对照所有包含结论、概念空性和全局一致性，不只检查算法自身推导。覆盖仅A必为空但Top可满足、Top包含于Bottom、A包含于存在r.A的可满足循环、两个不同存在见证不能错误合并概念成员、后继被推成Bottom而前驱随之为空，以及A1交A2的条件不能拆成两个独立包含。较大链式与循环公理测试应终止，返回的反模型大小不超过普通概念数加1，且每个正面证明都能从输入独立重放。
