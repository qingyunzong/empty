# numimport — 列级小数符导入工具

读取分隔符分隔的数值表（默认 `;` 分隔，可用 `--delimiter` 修改），为**每一整列**
独立选择 `.` 或 `,` 作为小数符，把每个数字以**精确分数**输出，空值原样保留。

## 规则

- **整列判定**：每列的所有非空单元格分别用两种解释（`.` 小数 / `,` 千位，以及反之）
  尝试解析；绝不只看首行猜格式——首行有歧义时由后续行裁决。
- **千位分隔必须三位分组**：如 `1,234,567`、`1.234.567,89` 合法；`1,23`、`12,34`、
  `1234,567` 非法。小数部分不允许再出现任何分隔符。
- **歧义报错**：两种解释对整列都合法、但至少一个单元格的数值不同（如 `1,234`
  可为 1234 或 1.234）时，报错并指出首个分歧行，退出码 1。两种解释结果完全一致
  （如纯整数列）不算歧义。
- **无一致解释报错**：某列在两种解释下都含非法单元格时报错，退出码 1。
- **精确分数**：输出为最简分数 `num/den`（分母为 1 时只写分子），基于十进制
  字符串大数运算，任意长度数字不丢精度。空单元格保持为空。

## 构建与测试

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

测试（CTest）：

- `parser`：解析器与列判定的单元测试（`tests/test_parser.cpp`）。
- `exhaustive`：对长度 ≤ 7 的全部短数串（约 192 万个「串 × 解释」组合），把主解析器
  与一个独立的正则参考实现逐一对照，合法性与精确值都必须一致
  （`tests/test_exhaustive.cpp`）。
- `end_to_end`：驱动真实二进制的端到端测试，覆盖混合列、千位分组、整列裁决、
  歧义与非法列的报错（`tests/end_to_end.sh`）。

## 使用

```sh
numimport [--delimiter C] [输入文件]   # 缺省从 stdin 读
```

示例：

```
$ printf '1.5;1,5;\n2.25;2,75;7\n' | numimport
3/2;3/2;
9/4;11/4;7
```

每列选定的小数符会打印到 stderr。
