# 分支缩短：最短合法布局求解器

汇编相对跳转有短/长两种编码：短编码省字节但位移范围窄（默认 rel8，
[-128, 127]），长编码范围宽。一条跳转由短变长会增大其后所有指令的偏移，
可能连锁迫使其他跳转也变长。本项目在“所有跳转位移合法”的约束下，
求代码总长度最短的编码布局（跳转数 ≤ 20）。

## 方法

- **松弛迭代**（`branch::solve`）：从全短编码出发，每轮把所有越界跳转
  拉长，直到不动点。“越界即拉长”算子对编码选择单调，故收敛到最小
  不动点——其每个分量都不大于任何可行解，总长度必然最优。
- **枚举核对**（`branch::brute_force`）：穷举全部 2^J 种长短组合
  （J ≤ 20，最多 1 048 576 种），取可行布局的最短总长，与迭代结果比对。
- **位移约定**：`位移 = 目标偏移 - (跳转偏移 + 跳转自身长度)`，与 x86
  相对跳转一致；位移落在所选编码范围内才算合法。

## 构建与测试

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
cd build && ctest --output-on-failure
./branch_demo [种子]   # 打印迭代轨迹 + 偏移证书 + 枚举核对
```

## 实际结果（已记录于 results/）

- `ctest`：4/4 通过（unit_tests、3 个不同种子的 demo）。
- 单元测试 8/8 通过，见 `results/unit_tests_output.txt`：
  无跳转、近跳转保持短编码、远跳转被迫拉长、级联拉长（A 变长把 B 的
  目标推远、B 也被迫变长）、不可行检测、500 例随机模糊（≤10 跳转）
  与全枚举一致、20 跳转与 2^20 全枚举一致。
- 演示实例（120 条指令、12 条跳转、种子 5），完整输出见
  `results/demo_output.txt`：

  ```
  iter 0: 总长度=238 越界跳转={6,11,22,95,97,111}  -> 拉长 6 条
  iter 1: 总长度=256 越界跳转={4}                  -> 拉长 1 条（级联）
  iter 2: 总长度=259 越界跳转={}                   -> 收敛
  枚举 4096 种组合：最短可行总长 = 259，与迭代一致
  ```

  其中跳转 4 在 iter 0 原本合法，因 6 条跳转拉长把它的目标推远，
  在 iter 1 被迫变长——直观展示了“指令增长改变后续偏移”的级联效应。

## 文件

- `include/branch.hpp` — 布局计算、松弛迭代求解、全枚举核对、偏移证书
- `src/main.cpp` — 演示程序（确定性随机实例，输出轨迹/证书/核对）
- `tests/tests.cpp` — 单元与模糊测试（CTest 驱动）
- `results/` — 实际运行记录（ctest、单元测试、演示输出）
