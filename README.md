# 表格采集的堆数组描述符

科学归档接入宿主已解析FITS二进制表头，需要可导入的Go表格读取包，将固定行中的描述符正确映射到共享堆数组。调用方提供数据区ReaderAt、实际长度（允许区间末尾另有字节，但不得读取本表区间外）、行宽W、行数R、额外区字节数P、可选堆起点H及列定义。表总区间为[0,W*R+P)，H默认W*R且必须在该区间内；W/R/P/H及所有偏移、长度以非负精确整数描述，R可为0，列名唯一；每列含行内偏移、类型B/I/J/K/A/X、固定元素数，或变长P/Q描述符，描述符分别由两个大端有符号32/64位数组成count和offset，count是元素数，offset相对H。B无符号8位，I/J/K为有符号16/32/64位，A是原始字节串，X高位优先按位取值，所占字节数为ceil(count/8)。固定列占其数据宽度，变长列只占8或16字节描述符，列在行内不得相交或越界；不同描述符可合法引用同一段或重叠堆数据，不能误判别名为损坏。count为0时offset不参与寻址也不验证符号，非零count或offset为负须拒绝。整数列可给原始NULL哨兵与精确有理scale/zero，先判NULL再缩放，A/X不允许这两项。支持选择行号及列名返回批次，保留调用方行顺序与重复行，记录每个数组的物理来源范围，同批对完全相同的物理字节范围只读一次，输出数组须各自不可变且不能被其他结果修改；记录实际读取范围及次数。先校验本批全部描述符、总输出元素预算和寻址乘法，成功后才交付批次，短读不交付部分数据；不得全量读入表格。用自行编码夹具核验P/Q、零长负offset、非字节对齐X、重叠引用、显式H留空隙、NULL缩放及64位越界，给出接入宿主调用例与测试。

## 包结构

导入路径 `example.org/dataeng/q0260`，包名 `dataeng`，仅依赖标准库。

- `table.go`：类型/列定义、静态配置校验、行内区间相交检查、溢出安全的
  int64 乘法与加法（`mulOK`/`addOK`）。
- `batch.go`：`ReadBatch` 两阶段流程、P/Q 描述符解析、堆寻址、读取去重
  缓存、B/I/J/K/A/X 解码、NULL 哨兵与 `math/big.Rat` 缩放。
- `example_test.go`：接入宿主调用例（可执行 Example）。
- `*_test.go`：自行编码的内存 `ReaderAt` 夹具与全部规定场景测试。

## 接入流程

1. 宿主解析表头后，把几何参数与列定义填入 `dataeng.Config`，调用
   `dataeng.New` 一次性校验：区间包含关系、`H` 合法性、列名唯一、
   行内列不相交不越界、NULL/缩放仅用于整数列。
2. 每次需要数据时调用 `table.ReadBatch(rows, columnNames)`。行号顺序与
   重复行、重复列名都会原样保留；返回的 `Batch.Arrays` 与请求顺序一致。
3. 每个 `Array` 带 `Source Range` 记录物理来源；`Batch.Reads.Calls`
   记录本批实际 `ReadAt` 的区间与次数，完全相同的区间同批只读一次。

## 行为保证

- 先校验后交付：描述符符号、寻址乘法/加法、元素预算全部通过后才读取
  堆数据；任何失败返回 `ErrDescriptor`/`ErrAddressing`/`ErrBudget` 等
  哨兵错误（用 `errors.Is` 判定），短读返回 `ErrShortRead` 且无部分数据。
- 零长描述符（`count==0`）不寻址、不校验 `offset` 符号；非零 `count`
  或非零 `count` 下的负 `offset` 一律拒绝。
- 堆引用允许相同或重叠，别名不视为损坏；只有完全相同的物理区间去重。
- 输出切片按次独立拷贝，调用方修改任一结果不影响其他数组或后续批次；
  缩放结果为 `*big.Rat`，NULL 位置为 `nil` 且不参与乘法。
- 只读取被选中单元的描述符与数据区间，绝不把整张表读入内存，也绝不
  读取表区间 `[0,W*R+P)` 之外的字节（区间末尾额外字节保持不可见）。

## 测试

`go test ./...`（可选 `-race`）覆盖：P/Q 描述符、零长负 offset、
非字节对齐 X、重叠/相同堆引用、显式 H 留空隙、NULL 先于缩放、
64 位堆越界与定长宽度溢出、元素预算、短读不交付、行顺序/重复行、
结果独立性以及不读取区间外字节。
