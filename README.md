# 路由更新的属性长度位

路由采集若固定用1字节读属性长度，扩展长度位会把值的前两字节当成下一个属性。实现可导入的Go组件，供路由采集调用，不建立会话。报文以16个0xFF、大端uint16长度和1字节类型开始。长度包含这19字节，必须是19至4096。类型4的长度必须是19。类型2是更新，其他类型失败。更新先是大端uint16撤回长度和撤回前缀，再是大端uint16属性总长和属性，剩余字节是可达前缀。前缀以1字节位数开始，位数只能是0至32，随后是位数除以8向上取整的字节。属性以1字节标志和1字节类型码开始。标志的高4位依次是可选、传递、部分和扩展长度，低4位必须为0。扩展长度置位时，值长度是大端uint16，否则是1字节。值长度不含标志、类型码和长度自身。可选未置位时，传递必须置位且部分必须为0。传递未置位时，部分必须为0。属性总长必须等于各属性占用字节之和。撤回长度和可达前缀也必须正好用完，不能留下半个前缀。长度大于宿主maxMessage时在长度字段可读后拒绝，不按声明分配。Push可停在属性中间；Finish时报文未完成则失败。失败停止组件，已交付报文保留。测试独立组包，覆盖扩展长度、众所周知属性却未置传递、部分位出现在非传递属性、前缀位数为0和报文被切开。期望报文不得调用被测组件生成。
