知识采集服务需要可导入的Go图规范化组件，输入无序三元组，主语与宾语可为IRI或匿名节点，谓语只能为IRI；最多8个匿名节点，重复三元组去重。选择对匿名节点到0至n−1所有双射中字节字典序最小的排序序列作为规范结果，输出原节点映射，节点编码为类型字节I或B加32位大端内容长度及UTF-8内容，匿名编号用无前导零十进制；三元组按三项编码连接并排序。实现结构分区剪枝并保留精确结果，通过调用方接口合并同构抓取图。用全排列参考测试对称环、孤立分量、IRI与匿名名同字及随机改名不变性。

## 组件概览

包 `q220` 提供可直接导入的 RDF 图规范化能力，无第三方依赖。

- `Canonicalize(triples)`：去重、规范化并返回 `Result`（规范字节序列、有序三元组、
  原节点到规范节点的映射、匿名节点数量）。
- `CanonicalizeWithStats(triples)`：额外返回颜色细化次数、分支数、剪枝数与叶子数。
- `MergeGraphs(base, incoming)` 与 `Merger`：基于规范编码判定抓取图同构并合并，
  同构时返回匿名节点对应关系，不同构时返回 `ErrNotIsomorphic`。

## 编码规则

- 节点编码：类型字节（`I` 表示 IRI，`B` 表示匿名节点）+ 32 位大端无符号内容长度 +
  UTF-8 内容；匿名节点内容为无前导零十进制编号（0..n-1）。
- 三元组编码：主语、谓语、宾语三段节点编码顺序连接。
- 图编码：全部三元组编码按字节字典序排序后顺序连接。
- 规范结果：在匿名节点到 0..n-1 的全部双射中，取图编码字节字典序最小者；
  编码相同的多个双射取排列字典序最小者，保证结果唯一确定。

## 精确剪枝

搜索采用 1-WL 颜色细化做结构分区：每个 IRI 独立成类，结构等价的匿名节点同色，
只在同色块内枚举候选编号，消除对称等价分支。每个部分赋值节点用“最小未用编号”
松弛得到子树下界：每个松弛三元组与真实三元组等长且逐项不大于它，因此排序后的
松弛序统计量不大于子树内任意完整赋值；下界严格劣于当前最优解时安全剪枝，
相等时保留，从而与全排列枚举结果完全一致。

## 测试

- 全排列暴力参考对拍：对称 8 环、孤立同构分量、IRI 与匿名节点同字、
  自环与重复边、0..5 匿名节点的 1800 幅随机图。
- 随机改名不变性：对匿名节点做随机双射改名后规范编码保持不变。
- 合并接口：同构合并、不同构拒绝、无匿名节点场景与有状态 `Merger` 生命周期。
