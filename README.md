# 比对记录裁剪后的坐标契约

序列数据接入宿主按参考坐标截取比对记录，不能直接对字符串和CIGAR各截一次。开发可导入Go包，s/L/R和操作长度均为uint64，要求L<=R且所有端点加法可表示；输入参考起点s、非空正长度操作序列、原始读段碱基及同长质量数组；操作M/=/X同时消费参考与读段，I只消费读段，D/N只消费参考，S只消费读段且仅可在去除外端H后的两端，H不消费两者且仅可在最外端，禁止相邻同操作并要求已消费读段长度与输入相等。只处理给定方向，不做反向互补。裁剪到参考半开区间[L,R)，输出新起点、规范化操作串、保留读段原下标区间及碱基质量。双消费操作只保留参考交集，D/N同样按交集截断；I锚在它之前已消费的参考位置p，仅当L<=p<R才保留；原始S/H全部去掉。保留的D/N即使位于新记录首尾也不删除，相邻同类型合并；若未保留任何M/=/X，返回明确empty状态，不以纯I或D伪造比对。新起点是首个保留的消费参考操作坐标，保留读段若存在必须是原序列一个连续片段，错误要给操作下标，整数求和不能溢出。另提供新记录中读段下标到参考坐标或插入锚点、参考坐标到读段下标或D/N缺口的双向查询，区分不同缺口类别。交付宿主调用例和测试，用逐碱基展开的独立小参考核对所有裁剪边界、I恰在L或R、跨N、首尾D、原始软硬裁剪、空交集及大坐标，无需计算新的比对或读取SAM文件。

## 包用法

包路径 `example.org/dataeng/q0276`（包名 `dataeng`），纯标准库实现。

- `Clip(rec, L, R)`：按参考半开区间 `[L,R)` 裁剪 `Record`，返回 `Clipped`。
  - 全 `uint64` 坐标/长度；`L<=R`，所有端点求和经溢出检查。
  - M/=/X 与 D/N 只保留参考交集；I 以其之前已消费的参考位置为锚点，仅 `L<=p<R` 保留。
  - 原始 S/H 全部去除；保留的 D/N 即使在首尾也不删除，相邻同类型合并。
  - 无 M/=/X 保留时 `Clipped.Empty == true`，不以纯 I/D/N 伪造比对。
  - 保留读段保证是原序列的一个连续片段，`ReadStart/ReadEnd` 为原始半开下标。
  - 错误为 `*OpError`，`OpIndex` 给出原始 CIGAR 操作下标（无关错误为 -1）。
- 双向查询：
  - `Clipped.MapRead(idx)`：新记录读段下标 -> 参考坐标或插入锚点（`KindAligned`/`KindInsertion`）。
  - `Clipped.MapRef(coord)`：参考坐标 -> 读段下标或 D/N 缺口（`KindAligned`/`KindDeletion`/`KindRefSkip`）。
- `ParseCIGAR` 仅作词法解析辅助；结构合法性由 `Clip` 统一校验。
- 可运行宿主例：`go run ./examples/host`。
- 测试：`go test ./...`，包含逐碱基展开 oracle 的穷举边界核对与随机化差异测试。
