# debuglib

一个仅依赖 Go 标准库的"解释器 + 调试库"示例，演示带纯条件断点的调试语义。

## 组成

- `expr.go` — 纯表达式（常量、变量、算术、比较）及其解析器。表达式只读环境，
  从语言层面保证条件**不能改变程序**。
- `interp.go` — 语句（`Assign`/`Print`）、`Program`、`State`，以及无调试的参考
  解释器 `Run`。
- `debug.go` — `Debugger`：条件断点、`Continue`、`Step`。

## 调试语义

- **执行前求值**：断点条件在其所在行的语句执行*之前*求值；命中时语句尚未执行。
- **纯条件**：条件是纯表达式，求值只读状态，不会改变程序。
- **条件报错即停并保留状态**：条件求值出错（未定义变量、除零等）时返回
  `ConditionError` 与 `*CondError`（含行号与断点 ID），PC、环境、输出与调用前完全一致。
- **同位置多个条件按 ID**：同一行的多个条件按断点 ID 升序求值，遇到第一个为真的
  条件即命中，或遇到第一个错误即停，以 ID 顺序先到者为准。
- **Continue**：执行语句直到条件命中、出错或程序结束。为保证前进，上一次在同一 PC
  命中的断点在下一次 `Continue` 中跳过检查一次。
- **Step**：精确执行一条语句，忽略断点，然后停止（`AtStatement`）；到末尾返回
  `Finished`。
- **与无调试解释器核对**：断点的增删与 `Continue`/`Step` 的任意组合都不影响最终
  结果；测试（含 300 个随机程序/随机调试会话的交叉检查）验证调试器最终状态与
  `Run` 完全一致。
