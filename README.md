# 地震采集帧的压缩差分积分

地震数据接入器已经拆出记录头，需要Go可导入的Steim-1/2大端压缩体解码包，将任意切块输入的一个记录提交为完整int32样本序列；输入元数据给编码1或2、样本数N、压缩体字节数L及宿主允许的最大N，超限或损坏不得交付部分记录。本题仅支持大端，L必须为64的正整数倍且N>=1。每帧为16个大端32位字，字0的第30-2j起两位控制字j，j=0..15，字0自身控制须0；首帧字1、2分别是二补码X0、Xn且控制须0，数据从字3开始，以后帧从字1开始。控制0不含差分，除首帧字1、2积分常量槽外，控制0字的内容忽略；编码1控制1为四个8位、2为两个16位、3为一个32位有符号差分，均从字的高位到低位依次提取。编码2控制1仍为4个8位；控制2看最高两位dnib，值1/2/3分别把低30位切为1个30位、2个15位、3个10位差分，dnib0非法；控制3的dnib0/1/2分别把低30位切为5个6位、6个5位，或低28位切为7个4位差分，7个4位时第29、28位忽略，dnib3非法。所有差分按各自位宽二补码符号扩展，不把整个字当有符号再做算术右移切片。按帧与字序串起差分，首个差分d0是与上记录的桥接值，本记录忽略它，输出首样本X0，再用后续N-1个差分逐个累加；累加按模2^32后解释int32，不因宿主语言有符号溢出而改变结果。必须至少有N个差分，即使N=1也要求d0，最后样本须等于Xn，否则整记录拒绝。达到N后剩余差分作为填充不积分，但仍遍历全部声明字节验证所有控制组合；不得因样本齐了忽略后面的非法dnib或截断帧。push只接收至L字节，额外字节拒绝，finish发现不足拒绝；失败状态不可再次提交，成功仅一次交付。为每个输出附帧号、字号和字内差分序号，X0标记为首帧字1，索引不能把被跳过d0算成样本。交付宿主调用示例及独立逐位参考测试，覆盖两编码全部合法组宽、最小负差分、跨帧连续积分、int32回绕、错误Xn、d0不为0、N=1、达到N后的坏控制以及每一字节切块；不需要miniSEED文件头、联网或真实传感器。
