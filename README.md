# XML采集片段的独占命名空间输出

XML采集服务要对选中的子树保存稳定字节，直接复制祖先所有xmlns会让无关上下文影响摘要。实现可导入Go序列化包，输入是完整已解析树和要序列化的元素ID，不解析XML文本；处理以下无注释的exclusive-canonical子集。节点为element或text，ID唯一，element有前缀/local、有序孩子、命名空间声明及普通属性，属性也有前缀/local和值；名称仅接受ASCII的[A-Za-z_][A-Za-z0-9_.-]*，前缀可空。实际作用域初始也只有xml固定绑定和空默认，两者来源记$initial；树必须单根无环无多父且选中ID存在。先从根到所选元素建立实际in-scope绑定，子树内部按声明进出恢复；默认命名空间只作用于无前缀元素，不作用于无前缀属性，xml前缀固定为http://www.w3.org/XML/1998/namespace，不得改绑，xmlns不得作普通前缀，普通无前缀属性名xmlns也拒绝，xml的固定URI不得绑定到其他前缀或默认。非空命名空间URI须以[A-Za-z][A-Za-z0-9+.-]*:开头，前缀非空时不得声明空URI，只有默认可置空；同元素声明前缀重复、未绑定可见前缀或同展开名属性重复均拒绝。输出只保留选中子树；另维护独立的已渲染绑定栈，起点仅含xml固定绑定和空默认。一个元素可见使用的前缀为自身前缀及所有带前缀属性，再并入调用方inclusive前缀集合，集合里的#default表示默认，未绑定的非可见集合项忽略。仅当该前缀当前实际绑定不同于已渲染绑定时输出xmlns声明，xml永不输出；无前缀且实际命名空间为空的元素如面对已渲染非空默认，必须输出xmlns=""，不能因输入此处无显式声明而漏掉。已渲染栈只记录实际输出的声明，孩子退出恢复到父状态，不能以完整in-scope状态冒充已输出状态。namespace声明按前缀字节序输出，默认空前缀最先；普通属性按命名空间URI再local字节序排序，不按原前缀或输入次序；仍保留原合格名拼写，不重命名前缀。统一用双引号，空元素输出显式起止标签；文本转义&、<、>及CR为&amp;、&lt;、&gt;、&#xD;，属性和声明值转义&、<、双引号、TAB/LF/CR为相应实体及&#x9;/&#xA;/&#xD;，其他合法XML1.0标量按UTF8原样写，合法范围为U+0009/U+000A/U+000D、U+0020..D7FF、U+E000..FFFD、U+10000..10FFFF，拒绝非法标量或不成对代理输入。输出字节及各段来源节点/属性或实际绑定声明节点，祖先借入声明也须可定位。限制树深与输出字节，整次验证成功才交付；测试无关祖先声明不影响结果、祖先借入可见前缀、默认清空、未输出绑定在孙辈才出现、兄弟重绑隔离、inclusive集合和属性展开名排序，不支持DTD、处理指令或评论节点。
