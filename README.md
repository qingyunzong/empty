# rect-layout-optimizer

整数网格矩形布局优化：在**显式尺寸范围、对齐、不重叠**约束下，求相对旧布局的**总移动距离最小**的新布局，并输出**可独立校验的约束证书**。预算内未闭合时保留上下界；微小网格用穷举交叉校验。

- 纯 TypeScript + Node.js 内置库（`node:test` / `node:assert` / `node:crypto`），**零 npm 依赖**
- 至多 8 个矩形（`MAX_RECTS`），演示网格 20×20
- 目标：最小化 `Σ |x-oldX| + |y-oldY|`（曼哈顿距离；位置计费，范围内改尺寸免费）

## 运行

```bash
npm test        # 编译 (tsc) + 运行全部测试
npm run solve   # 求解演示实例并输出约束证书 (JSON)
npm run solve -- 1   # 等价于 node dist/src/cli.js 1：节点预算=1，输出 bounded 证书
```

## 模型（`src/model.ts`）

- 每个矩形：`minW..maxW × minH..maxH` 整数尺寸范围，旧位置/旧尺寸 `(oldX,oldY,oldW,oldH)`
- 对齐约束：`left/right/top/bottom/hcenter/vcenter` 两边值相等；中心用 2 倍坐标（`2x+w`）保持整数
- 不重叠：严格相交才算重叠，边贴边允许
- 边界：`0 ≤ x, x+w ≤ grid`（y 同理）
- `validateSpec` 拒绝非法定义（超 8 矩形、重复 id、未知对齐引用、越界等）

## 求解器（`src/solver.ts`）

最佳优先分支定界：

- 每矩形预生成按移动代价升序的候选 `(x,y,w,h)` 列表
- 下界 = `max(逐矩形独立最小代价之和, 对齐约束匹配下界)`，均为可采纳松弛
  - 匹配下界：选一组矩形互不相交的对齐约束，各自最小满足代价之和
- 贪心种子先给出上界；节点预算耗尽时返回 `bounded`，保留 `lowerBound`（开放节点最小界）与 `upperBound`（现任解）
- 状态：`optimal`（下界=上界）/ `bounded`（未闭合，上下界均有效）/ `infeasible`

## 约束证书（`src/verify.ts`）

证书含 spec 的 SHA-256、状态、目标值、上下界、展开节点数、布局及**逐条约束检查**（尺寸/边界/不重叠/对齐，每条带 id 与人读详情）。`verifyCertificate` 不信任求解器，从 spec 与 layout 重算一切：约束逐条重判、目标值重算、上下界一致性、状态闭合性。

## 穷举对照（`src/exhaustive.ts`）

枚举全部可行布局（仅可行性剪枝，不做代价剪枝），取最小总移动距离，用于微小网格交叉校验分支定界。
