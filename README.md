# ticketlog

校验库读票据日志：申请（APPLY）、授予（GRANT）、取消（CANCEL）、释放（RELEASE）、
上限调整（LIMIT）。按票据代际重建状态机，重放日志并报告**首个错误**及其**完整因果链**。

## 规则

- 每个 `APPLY` 为票据开启一个**新代际**，状态从零重建；同一票据 id 可跨代复用。
- `CANCEL` 仅对未授予的申请有效，且**不释放任何额度**（从未授予，无可释放）。
- 重复 `RELEASE`（或对未授予/已取消票据的释放）是错误。
- 任意时刻**总已授额不得超过当刻上限**（授予超额或下调上限低于在授总额均报错）。

## 日志格式

```
LIMIT 100        # 设定总额度上限
APPLY T1 30      # 票据 T1 申请 30 单位（开启新代际）
GRANT T1         # 授予
CANCEL T2        # 取消未授予的申请
RELEASE T1       # 释放
```

## 使用

```
go run ./cmd/ticketlog log.txt     # 或 cat log.txt | go run ./cmd/ticketlog
```

输出首错与因果链；日志合法时输出 `OK`。

## 测试

```
go test ./...
```

包含验收测试：随机生成合法日志，做单处破坏（重复释放、丢失授予、插入零上限、
重复授予、以取消替换释放），断言校验器必然检出并报告对应错误类型。
