# 采集正文的分隔边界与收尾

采集到的多段正文里，分隔串前后的短横线数量不同，前导段和结尾段就不能靠第一次出现的短横线切开。实现可导入的TypeScript模块，供采集器按块调用。调用方传入1至70字节的边界，不能以空格结尾。正文使用CRLF。分隔是两个短横线加边界；它前面必须是CRLF，只有整段正文的第一个分隔可以位于偏移0而省略这个CRLF。第一个分隔之前的前导字节忽略，但前导里不能出现完整分隔。每个部分接着若干头：名称、冒号、可选一个空格和值，以CRLF结束。空行结束头部。只解释Content-Type和Content-Disposition，其他头按原始字节保留。Content-Disposition若含filename，必须是双引号字符串，只允许反斜杠加引号或反斜杠还原，其他转义失败。头不允许折行。部分正文持续到下一个分隔，正文内部不能包含该分隔。闭合分隔是普通分隔再加两个短横线，其后到结尾的字节忽略。最后必须出现闭合分隔，不能停在普通分隔。没有部分的正文只要前导后直接闭合也合法。未形成完整部分时保留已见前缀；调用方声明结束时仍未闭合则失败。失败不交付半个部分，已完成部分保留。测试独立拼接，覆盖偏移0省略CRLF、空部分、filename转义、未知头、边界出现在正文中、缺少闭合短横线，以及分隔被切到下一块。期望部分不得调用被测模块生成。
