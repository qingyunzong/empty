# 采集对象的共享虚表与缺省字段

设备采集宿主收到FlatBuffers式对象，要按当前模式读旧消息，不能因旧虚表缺字段拒绝，也不能把共享虚表误报重叠损坏。实现Go可导入读取包，只处理题面子集，模式为宿主提供的已编译表定义，不调用flatc。缓冲所有数值小端，起点uint32相对偏移指向根table；每个table的首int32为距离d，vtable起点是table起点减d，d可负。vtable依次是uint16自身字节长、uint16对象字节长、各字段uint16对象内偏移，虚表长至少4且为偶数，对象长至少4；两个范围均须在缓冲内。字段槽号由模式固定，槽在虚表外或偏移0即缺失，标量返回模式缺省值，引用返回null；所有虚表槽的非零起点仍须在[4,对象长)内；多余未知槽不按猜测类型解引用或校验字段宽度。支持u8/i32/i64、string、table引用、这些标量或table引用的vector，不支持struct、union及嵌套vector；模式表类型可递归。字段非零偏移须>=4，值宽不得超对象长；标量及偏移按自身宽度绝对对齐。引用位置存uint32正偏移，目标为引用位置加偏移，不能回绕，0不代表已存在引用的null而应拒绝；table引用目标4对齐。string和vector目标均须4对齐；string目标先uint32字节长，再严格UTF8及一个0终止字节，正文允许嵌入NUL；vector目标先uint32元素数，元素区按类型连续排列，i64元素区需8对齐，table vector每项分别以该项位置为偏移基准。table/vtable和各对象可合法共享，不用全局区间互斥假设；按对象位置和模式类型缓存已验证结果，检测同位置不同表类型并拒绝，原始数据不改变。验证所有从根可达且模式已知的字段成功后才返回读取句柄，未知字段内容不作推断；句柄提供字段路径读取、缺省来源与每次读取的实际字节范围。宿主保证借用缓冲在句柄存活期间不可变，包不返回可修改的底层切片。限制独立table数、按独立对象计的vector元素总数和字符串字节总数，重复引用不重复收费，声明超限在分配前拒绝。测试独立字节构造的旧短虚表、虚表位于对象之后、多个对象共享虚表、共享字符串、缺失与显式0不同、非零空引用及超长vector；附采集宿主调用例，不要求完整FlatBuffers兼容。
