# 数据质量规则的否定递归三值语义

数据质量管线中的“未确认冲突才可用”规则会互相否定，不能把没有推导出的事实一律当假。开发由数据质量管线调用的可导入Go良基规则求值包，宿主已经把规则实例化为有限ground原子，不需解析语言或展开变量。输入显式全集B至多1000个唯一ASCII原子ID、至多20000条有唯一ID的规则h<-p1,...,pm,not n1,...,not nk，头和体引用均须属于B；体中重复字面量按集合归一，正负同时出现不自动删规则，空体为事实，多个规则可有同一头。只采用本题定义的交替不动点：对任意S子集B，Gamma(S)先删除所有负体与S相交的规则，再抹去其余规则的所有not字面量，得到正程序，从空集求其最小闭包。初始K为空、U=B，每轮令Knext=Gamma(U)，Unext=Gamma(Knext)，随后同时更新K/U，直到两者均不变；最终K为true、B减U为false、U减K为unknown。unknown必须作为独立结果返回，不能为方便下游改成false、选择某个稳定模型，或在没有稳定模型时宣称输入错误。每轮Gamma正闭包须用依赖索引及剩余前提计数推进，正递归中没有外部支持的环不能自己变真；同一正体原子只计一次，闭包为空也合法。返回各类按ID排序及所有轮次的K/U，给每个新true头记录本轮Gamma内实际首次触发的规则及正前提触发序号，多个可触发规则按规则ID ASCII序优先、待激活原子按ID ASCII序推进，不能给循环的有限推导。负体可被抹去的理由须指向该轮传入Gamma的S，不能写成“当前没见过所以假”。为false集合另返回封闭支持检查材料：对每个false头的每条原规则，指出至少一个正体原子也在false集合，或一个负体原子在最终true集合；无头规则的原子明确标无规则。这个材料允许正环的集体无根据性，不把环里的另一个false当已完成的独立真值推导。宿主可替换整份事实规则后重新求值，旧结果及原始规则保持不可变，允许重算而不强求增量算法；同一次求值只能对应一份规则快照。给管线调用例，独立参考不要枚举稳定模型当良基语义：从T=F=空开始，先按当前三值解释加入体全真的头，再算最大无根据集G。求G时从B减T出发，反复移除有某条规则满足“体中没有当前已假字面量，且正体不与G相交”的头，直到稳定，再把G加入F，交替直到T/F稳定；当前正字面量在F为假，负字面量对应原子在T为假，未决字面量不是假。用两种独立过程比较小规则集全部结果，覆盖a<-a无事实为false、a<-not a为unknown、互相否定为unknown、某原子无定义使其否定可真、一个负环通过正边影响外部头、正负同原子、重复前提、添加事实后从unknown变true/false及移除事实后恢复。逐轮检查K只增U只减、K子集U以及全部true/false材料，不要求外部逻辑引擎。
