# 事件循环模拟器

TypeScript + Node.js 内置库实现的事件循环模拟器：定时任务（宏任务）与微任务分别维护，
每个宏任务后排空微任务队列，再选最早定时项；微任务可继续派生；带步数预算，
预算耗尽返回未闭合状态；输出可重放轨迹。

## 语义

1. 初始先排空一次微任务队列（相当于 script 宏任务）。
2. 取触发时间最早的定时器作为下一个宏任务（同刻按注册顺序 FIFO），虚拟时钟前进到其触发时间。
3. 宏任务执行完毕后，排空整个微任务队列——包括执行期间新派生的微任务。
4. 重复 2–3，直到定时器与微任务均为空（`closed`）。
5. 每执行一个任务（宏或微）计 1 步；步数预算耗尽且仍有未完成任务时返回
   `exhausted`，并报告剩余的定时器/微任务数量（未闭合状态）。

## 结构

- `src/simulator.ts` — 主实现：定时器用二叉最小堆（键为 `(fireTime, seq)`），微任务用 FIFO 队列。
- `src/queueModel.ts` — 独立队列模型（核对用）：刻意不同的朴素实现，数组 + 线性扫描找最早定时器。
- `src/trace.ts` — 轨迹的 JSON Lines 序列化/反序列化与重放校验（`replay` 用同一程序重跑并比对轨迹）。
- `src/examples.ts` — 5 个手写小例，附人工推导的期望轨迹。
- `test/` — 手写小例核对、轨迹重放、随机程序（mulberry32 种子）双实现交叉核对。

## 运行

```sh
npm test    # tsc 编译到 dist/ 后用 node --test 运行测试
```

要求：Node.js（开发环境为 v22.22.1）与 `tsc`（开发环境为 7.0.2）。无第三方运行时依赖。

注：本机 Node 构建未启用内置类型剥离（`--experimental-strip-types` 报
`ERR_NO_TYPESCRIPT`），因此测试采用先 `tsc` 编译再运行 `dist/` 的方式。
