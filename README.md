# 字面量计数不含换行

邮件夹采集把字面量后面的换行也算进计数时，下一行的第一个字符会被吃掉。实现可导入的Go组件，供邮件夹采集调用，不建立连接。输入按CRLF分行。一行以{、无前导零的非负十进制、可选一个+和}结尾时，随后正好是这个数字的原始字节，可以包含CRLF。这串字节不包含花括号那一行的CRLF。有+时标记为非同步，没有+时标记为同步。计数大于宿主maxLiteral时，在该行完整后拒绝，不按声明分配。字面量结束后立即继续解析，可以停在一行中间。不以这种花括号结尾的内容一直到CRLF为止，CRLF保留。单独的CR或LF、未闭合的{、花括号里的前导零都失败。Push可停在字面量中间；Finish时行或字面量未完成则失败。失败停止组件，已交付片段保留。测试独立组行，覆盖字面量中的CRLF、计数把花括号行的CRLF算进去、+紧贴在数字后和行被切开。期望片段不得调用被测组件生成。
