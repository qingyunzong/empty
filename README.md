# esc

Go 字符串转义编解码库（仅标准库），支持十六进制与 Unicode 转义，
并为每个解码码点保留其在原始输入中的准确字节区间。

## 支持的转义

| 转义 | 含义 |
| --- | --- |
| `\\` `\n` `\t` `\r` | 简单转义 |
| `\xHH` | 码点 U+00HH（Latin-1 范围） |
| `\uHHHH` | BMP 码点；高代理必须紧跟 `\uDC00`–`\uDFFF` 低代理转义，合成一个码点 |
| `\UHHHHHHHH` | 完整码点（须 ≤ U+10FFFF 且非代理） |

## API

- `Decode(s) (*Result, error)`：解码整串。`Result.Spans[i]` 是解码后第 i
  个码点在源串中的字节区间（代理对映射到两段转义的整个区间）。
- `Encode(s) (string, error)`：编码为可逆的转义串，`Decode(Encode(s)) == s`。
- `StreamDecoder`：流式解码，`Write` 任意分块（可切在转义中间、代理对
  两半之间、UTF-8 序列中间），`Close` 收尾；所有区间与错误偏移都是
  整段流的绝对字节位置。
- `*Error`：错误的 `Span` 精确覆盖出错的原始区间（如孤立高代理
  `[start, start+6)`、非法十六进制位截至出错字符等）。

## 测试

`go test ./...`（Go 1.27.1，另需可写的 GOCACHE，如 `GOCACHE=/tmp/gocache`）：
16 个测试全部通过，含 `-race`；覆盖基本转义、代理对配对与错误区间、
位置映射回查、流式跨块切分（逐字节与随机分块对照一次性解码）、
以及随机串编码往返核对位置映射。
