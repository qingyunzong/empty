# geom

动态整数点集几何库（仅 Go 标准库）：按整数 ID 增删点，任意版本快照上查询凸包、
双倍面积、凸层剥离与排名。

## 约定

- 点按整数 ID 存储；多个 ID 可共享同一坐标。几何计算中每个坐标只出现一次，
  来源 ID 通过 `Group` 保留可查。
- 凸包逆时针输出，从字典序最小点（先 X 后 Y）开始。
- 边上共线点仅保留端点；全共线时返回两个端点（单点/空集为退化情形）。
- 面积以双倍整数 `Area2` 返回，保持精确。
- 凸层（onion peeling）从外向内编号（0 起）；每层的边界点（顶点及边上共线点）
  属于该层并在下一层剥离前移除；删除点或更正内点坐标可能改变全部层。
- 快照不可变且持久：`Add`/`Remove` 返回新快照，底层 treap 结构共享，
  分支互不影响。

## API 概览

- `New()` 空快照；`Add(id, p)`、`Remove(id)` 返回新快照；`Get`、`Len`、`Entries`。
- `Hull() []Point`、`Area2() int64`。
- `Layers() [][]Point`、`LayerAreas2() []int64`、`Rank(id)`、`Ranks()`。
- `Group(p) []int64`：同坐标来源 ID 分组。
- `VerifyHull(pts, hull) error`：朴素 O(n·h) 支撑线检查，与生产代码
  （单调链）相互独立，测试中用于核对每个版本。

## 测试

`go test ./...`：单元测试覆盖退化/共线/重复坐标/分支持久等约定；随机测试以
固定种子做 400 轮随机批更新，逐版本与朴素支撑线模型（暴力支撑线求凸包 +
逐层剥离）核对凸包、层、层面积、排名与分组，并复验保留的历史分支快照。
实际运行结果见 `TEST_RESULTS.txt`。
