# signal — 整数信号配时优化 CLI

在固定周期（至多 60 个时槽）内为每个相位选择整数绿灯时长，
冲突相位不得同时放行，每个相位有最短绿灯时间和等待费用表，
目标为最小化总等待费用。仅使用 Go 标准库。

## 问题定义

- 周期 `cycle`：1..60 个离散时槽。
- 每个相位 `i`：最短绿灯 `min_i`，费用表 `cost_i[g]`（该相位每周期获得
  `g` 个绿灯时槽时的等待费用；表短于 `cycle+1` 时末项平直延伸）。
- 冲突对：同一时槽内不得同时为绿灯的相位对。
- 决策：整数绿灯分配 `g_i >= min_i`，以及具体的时槽放行方案，
  使 `sum_i cost_i[g_i]` 最小。

## 算法

1. **分支定界（`solve.go`）**：在整数分配空间上搜索。用冲突图的
   所有极大团（Bron–Kerbosch）容量约束 `sum_{i in K} g_i <= cycle`
   剪枝；下界为各相位在当前团剩余容量下的最小可实现费用。
2. **精确调度器（`schedule.go`）**：把分配落成逐时槽放行表
   （图的多重染色）。同一占用掩码的时槽对称，按组决定取用量，
   配合前向检查，60 槽规模瞬时完成。团条件对非完美图不充分
   （如 C5），因此每个候选叶子都做精确调度验证。
3. **穷举核对（`brute.go`）**：小周期上枚举全部满足团约束的整数
   分配并逐一精确调度，独立给出最优值，用于交叉验证分支定界。

## 用法

```sh
go build -o signal .
./signal -f examples/crossroad.json            # 输出完整周期证书
./signal -f examples/crossroad.json -verify    # 附加穷举核对
cat instance.json | ./signal                   # 也可从标准输入读取
```

实例格式见 `examples/crossroad.json`。证书包含：周期、各相位绿灯
分配、逐时槽放行表、分项与总费用、自检结果（最短时间 / 冲突 /
费用全部重算校验）。

## 测试

```sh
go test ./...
```

（C5，cycle=2 不可行 / cycle=3 可行）、输入校验、CLI 端到端
（含 `-verify` 穷举核对）。
