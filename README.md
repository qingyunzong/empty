# 富文本采集结果的范围替换

RPA表单宿主要把规范化后的字段值写回contenteditable快照，请提供可导入的TypeScript范围编辑包，不能把整个控件替换成纯文本。树节点为带唯一ID的容器、文本、br或不可编辑原子节点；输入文本保证合法Unicode，容器可以嵌套但树必须无环且每节点恰有一个父节点。文档顺序串联文本的UTF-16单元，br贡献一个换行，原子节点贡献一个U+FFFC，容器不贡献字符。输入替换范围用节点ID与偏移锚定：文本偏移是UTF-16位置，容器偏移是子节点间隙，br与原子仅允许父容器间隙表示。先把两个锚点归一到逻辑串位置，要求范围有序且不切断合法代理对；跨到任何原子字符时整次拒绝。替换删除范围内文本与br，保留未被删除的文本节点ID和所有容器，空文本除起始文本节点外统一删除，空容器保留；新文本即使为空也总是作为一个新文本节点插入起始锚点，若起点在文本内部则原节点保存左半，新ID保存右半，替换文本在中间；当原节点左半为空时仍保留原节点。起点在容器间隙就在该间隙插入；删除在原始快照上解释，不能被插入改变。如果起始文本被右端范围完全覆盖，仍保留它的左半部分及原ID；起点落容器间隙时按原始子列表间隙确定插入位置，删除其他子文本不得改变该位置所属容器。返回新树、折叠到插入文本末尾的光标，以及每个保留字符到原位置的映射。调用方传入期望树版本，不符拒绝；生成ID由注入函数给出，冲突或任意非法锚点不改旧树。请写测试，以逻辑串的范围替换核对文本结果，同时核验跨嵌套容器、空范围、代理对、只删br、原子边界和节点身份保留。
