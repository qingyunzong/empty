渲染器需要可嵌入的 C++20 ICC v4 显示配置变换库，调用方提供完整 profile 字节和一批线性或编码 RGB 样本，组件不访问文件系统。严格校验 128 字节头、声明大小、tag table 的范围/对齐/重叠和共享数据规则，只接受 RGB 输入、XYZ PCS，以及 rXYZ/gXYZ/bXYZ 与 rTRC/gTRC/bTRC 组成的矩阵/TRC 配置；曲线支持 curveType 的 0、1、n 项和 parametricCurveType 的 0..4 型，所有 s15Fixed16、u8Fixed8 与分段定义按精确有理数解析，拒绝非单调曲线、奇异矩阵、NaN 等价计算和未完全覆盖的参数域。提供 device→PCS 与 PCS→device：前者按曲线再矩阵，后者求矩阵逆并对各 TRC 做确定性的单调反解；多解取最小设备值，超域按公开的 relative-colorimetric 裁剪规则处理，禁止偷偷套用 sRGB gamma。返回每阶段值、命中的曲线分段和原 tag 字节范围，profile 对象不可受调用方后续修改影响。用独立高精度参考核对端点、分段接点、共享 tag、非单位白点、近奇异矩阵和正反往返误差，并验证畸形偏移不能读取 profile 边界外数据。
