# scheduler

多租户赤字轮询（DRR）调度库，Go 实现。

## 语义

- **整数配额**：每轮开始时，每个活跃租户（队列非空）获得等于当前权重的整数配额，计入赤字计数器。
- **赤字累计**：队首任务费用超过可用赤字时，本轮跳过该租户，赤字结转到下一轮继续累计。
- **空队清零**：租户队列排空时赤字归零；空闲期间不累积配额。
- **负费用拒绝**：`Enqueue` 对 `Cost < 0` 返回 `ErrNegativeCost`。
- **权重下一轮生效**：`SetWeight` 只更新 `nextWeight`，在下一轮开始时应用。
- **扣费账本**：每次扣费记录一条 `LedgerEntry`（轮次、租户、任务、费用、生效权重、扣费前后赤字）。

## 用法

```go
s := drr.New()
s.AddTenant("a", 1)
s.AddTenant("b", 3)
s.Enqueue("a", drr.Task{ID: "job-1", Cost: 5})
s.SetWeight("a", 2) // 下一轮生效
entries := s.RunRound()
ledger := s.Ledger()
```

## 测试

```sh
go test ./...
```

- 单元测试覆盖：负费用拒绝、赤字累计、空队清零、权重下一轮生效、账本一致性、错误路径。
- `drr/reference_test.go` 内含独立的列表参考模型（与实现零共享代码），30 个随机种子下逐条比对账本，并断言所有任务（含超大任务）最终都被服务、不饥饿。
- 公平性测试验证长期服务量与权重比一致（DRR 经典保证）。
