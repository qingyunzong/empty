# 空间分区的 Morton 区间精确裁剪

空间数据扫描宿主用可导入的 Go 范围包裁剪二维分区。坐标 x、y 为 b 位无符号整数，1 <= b <= 12；Morton 编码从低位开始交错 x0,y0,x1,y1,...。查询闭矩形必须位于域内，返回恰好覆盖其所有编码的最大连续半开整数区间，不能含矩形外点，也不枚举整域。每个区间附带可验证覆盖的四叉前缀分解，前缀从最高位对开始表示四叉节点。相邻已完成区间会合并。

若输出区间数超过调用方预算，`Query` 返回未完成状态：`Intervals` 是 Morton 升序深度优先顺序下已确认的前缀区间，`Pending` 是精确补集的未展开四叉前缀。两者无交集，联合恰好等于原查询，不会用近似多读替代精确结果。

## 用法

```go
d, err := dataeng.NewDomain(12)
if err != nil {
    // b 必须在 [1,12] 内
}

r := dataeng.Rect{MinX: 10, MaxX: 200, MinY: 20, MaxY: 30}
res, err := d.Query(r, 8) // 最多确认 8 个连续区间
if err != nil {
    // 矩形越界或预算为负
}

if res.Complete {
    // res.Intervals 精确覆盖 r 的全部 Morton 编码
} else {
    // res.Intervals 是已确认部分；res.Pending 是剩余精确前缀
}

if err := d.Verify(r, res); err != nil {
    // 独立验证覆盖、互斥性、最大性和前缀分解
}
```

## 数据结构

- `Domain{Bits}`：b 位坐标域，坐标范围为 `[0, 2^b)`。
- `Rect{MinX,MinY,MaxX,MaxY}`：四边均闭的矩形。
- `Node{Bits,Depth,Prefix}`：深度为 `Depth` 的四叉节点。`Prefix` 保存 Morton 码最高的 `2*Depth` 位，低位补零，因此节点编码区间为 `[Prefix, Prefix+4^(b-Depth))`；`Digits()` 按最高位对到最低位对的顺序返回四叉数字。
- `Interval{Lo,Hi,Prefixes}`：半开编码区间 `[Lo,Hi)` 及其精确平铺的节点列表。合并后的区间可能不是单个四叉节点，所以可以包含多个前缀。
- `Result{Complete,Intervals,Pending}`：完整结果，或预算截断后的“已确认区间 + 精确剩余前缀”。

`Query` 只递归访问与查询矩形相交的四叉节点；全域查询直接返回一个根节点，单点查询只产生一个叶子。预算按最大连续区间个数计，而不是按前缀节点个数计。

## 验证与测试

`Domain.Verify` 检查前缀区间是否精确平铺、每个前缀是否完全位于查询矩形内、区间与待展开前缀是否互斥、已完成区间是否已合并，并把未覆盖的空隙分解成四叉节点以确认其中没有查询编码，因此不需要枚举整域。

测试在 `b = 1..5` 上对全部闭矩形做逐点参考穷举，并额外覆盖退化行/列、全域、跨四叉边界、预算截断的精确补集，以及 `b = 12` 的全域、单点和整行查询。
