# srx — 选择性重传设备传输模拟器

离散事件模拟的选择性重传（selective-repeat）链路，纯 Go 实现，无外部依赖。

## 特性

- **累积确认 + 选择确认**：接收方对每帧同时发出累积确认（按帧号覆盖之前所有帧）和选择确认（仅该帧）；发送方只重传仍未确认的帧（`sim.go` 中 `onAck` / `onTimeout`）。
- **同刻确认优先**：确认与超时落在同一模拟时刻时，事件队列保证确认先处理，超时看到帧已确认即放弃重传。
- **重传上限**：每帧重传次数计入 `MaxRetries`，超限标记为失败并滑过，不再发送。
- **环绕序号消歧**：窗口严格小于模数一半（`2*Window < Modulus`，构造时强制校验），线上序号相对当前窗口基址唯一解析（`seq.go` 中 `resolveSeq`）。
- **窗口动态调整**：存在未确认帧时也可调用 `SetWindow`；缩小窗口只暂停新帧发送，绝不丢弃在途帧，各帧截止与重传计数保持不变。
- **快照恢复**：`Sim.Clone` 深拷贝全部状态（端点、事件队列、计数器），每帧保留原截止与重传次数；逐事件暂停/恢复后发送轨迹与不间断运行完全一致。

## 测试

```sh
go test ./...
```

测试覆盖：序号消歧与窗口校验、仅重传未确认帧、同刻确认优先、重传上限、丢包轨迹全枚举下的交付唯一性（帧丢失 2^9、确认丢失 2^9、组合 2^6×2^6 全部轨迹）、序号环绕交付、窗口缩小保护在途帧、快照保留帧状态、逐事件暂停恢复轨迹一致性。
