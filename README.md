# 矩阵归档中紧凑标签与压缩单元格读取

科学数据接入器要读取MAT-Level-5式矩阵体，请用Go提供可导入解析包，输入已去掉文件头的字节流及固定端序，只支持下面闭合子集。普通元素头为uint32 type、uint32 payloadBytes，再跟载荷与补到8字节倍数的填充；type只允许1/5/6/9/14/15，分别为int8/int32/uint32/float64/matrix/zlib压缩。若头首uint32不在这些值中，则把头前4字节按端序解为uint16 type、uint16 n，n必须1..4且type为1/5/6/9，后4字节直接放n字节载荷及补齐，整个小元素恒8字节，不能按普通长度再跳转。所有填充字节忽略内容。顶层仅允许matrix或压缩；压缩元素使用普通头但其载荷之后不添加8字节填充，zlib解压后必须恰好是一个普通matrix元素且无额外字节，不允许压缩里再套压缩；必须确认zlib正常结束并耗尽声明压缩载荷，不把连接的第二条zlib流悄悄接受。matrix载荷由一串完整子元素组成，普通子元素各自含填充且总长度须恰好耗尽matrix载荷；首先是type6的8字节数组flags，首uint32低8位class只准1为cell、6为double、12为int32，位0x800为complex，其余位和第二uint32须0，complex只允许double；接着type5维度向量，至少2个非负int32维度；再type1名字字节，顶层名字非空严格ASCII字母数字下划线且首字符字母，cell孩子名字必须空。维度乘积为元素数，先检查是否有0维，有则乘积直接为0，不因其他维的中间乘积拒绝，索引按列主序，第一维变化最快，乘积必须先检查预算与溢出。double之后恰有type9实部，complex时再一个type9虚部，各字节数恰为8*元素数；int32恰有type5数据且长度4*元素数。double返回原始64位位型以保留NaN载荷及负0，不要求浮点运算。cell则紧随元素数个matrix子元素，按列主序一一对应，可递归空cell及不同形状/类型孩子，不能把孩子矩阵自身的维度当外层cell维度。顶层变量名字不得重复，全部成功后才发布不可变变量表；截断、额外子元素、类型与class不符或解压超限均不得留下半张表。宿主给总解压字节、矩阵节点、总数值单元及嵌套深度上限（顶层矩阵深度1），边解析边检查，不先按不可信长度分配。结果支持按变量名、cell多维索引链和最终数值坐标取值，保留元素标签的输入字节范围；压缩内来源为压缩元素物理范围加解压后逻辑偏移，不能伪造直接文件偏移。交付接入示例与独立编码夹具，核对两端序、紧凑名字、非8对齐压缩元素后直接跟新变量、多层cell、空维、复数和NaN位型、截断zlib及声明乘积溢出；不需要MATLAB或外部矩阵库。
