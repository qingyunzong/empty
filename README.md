# amount-cn：中文金额解析 / 格式化 / 增量编辑库

TypeScript 实现，仅依赖 Node.js 内置模块（`node:test` / `node:assert`），零 npm 依赖。

## 功能

### 1. 金额解析（`parseAmount`）

语法：

```
amount  := [亿段 '亿'] [万段 '万'] [个段] [('.' | '点') 小数]
各段    := 数字、十/百/千、零 的序列，数值 0..9999
小数    := 1 至 2 位数字
```

规则：

- 段内单位（十/百/千）必须**严格递减**，重复或逆序即拒绝（`1千2千`、`1百2千` 均非法）；
- **零占位不改变量级**：`零` 自身贡献为 0，仅截断位置链，其后的裸数字按普通整数累加（`1千零5 = 1005`）；零 token 不出现在任何金额位的来源中；
- 单位前的连续数字整体作系数（`12千 = 12000`），单位后的裸数字按递减数位落位（`3千12 = 3120`），落到个位以下报错；
- 万/亿 前必须有数字；万、亿至多各出现一次且亿在万前；每段上限 9999；全量上限 `9999亿9999万9999.99`（= 99,999,999,999,999 分）；
- 输出**整数分**与**每位来源**：结果分位 p 上的数字，由所有「贡献值最低非零位 ≤ p」的原 token 决定（进位只向上传播，定义见 `src/parser.ts`）。

### 2. 格式化逆函数（`formatCents`）

整数分 → 规范中文串。性质（均有测试保障）：

- `parseAmount(formatCents(c)).cents === c`（0 ≤ c ≤ MAX_CENTS）；
- `formatCents` 幂等，规范串是其不动点；
- 越界 / 非整数输入抛 `RangeError`。

### 3. 增量编辑（`AmountDocument`）

- 文档按 亿/万/个/小数 四段建模；词法结构保留**原字节**（UTF-8 字节偏移、原文片段）与**单位来源**（token 所属段与种类）；
- `setSegment(role, content)` 只重新词法分析并解析被编辑的一段，其余段的 token id、贡献值原样保留，仅重算受影响段并重新汇总；
- 每次成功编辑发布一个**不可变快照**（`Version`）；**错误编辑不发布**，版本数、当前文本、全部旧快照均不变；
- `version.digitSource(place)` 查询某金额位（分=1, 角=10, 元=100, …）由哪些原 token 决定；
- 随机编辑模糊测试：300 轮随机合法/非法编辑后，增量结果与完整解析**逐位来源映射**逐一核对一致，并周期性复核全部旧快照未被篡改。

## 使用

```ts
import { parseAmount, formatCents, AmountDocument } from './src/index.js';

parseAmount('1亿2千3百万45.67');
// { ok: true, cents: 12300004567, tokens: [...], digits: [{place, digit, tokenIds}, ...] }

formatCents(12300004567); // '1亿2300万零45.67'

const { ok, doc } = AmountDocument.create('1亿2万3.45');
doc.setSegment('wan', '6千7百');        // { ok: true, version } -> '1亿6千7百万3.45'
doc.setSegment('yi', '1万');            // { ok: false, ... } 不发布，旧快照不变
doc.currentVersion.digitSource(100);    // 决定「元」位的原 token 列表
doc.versionAt(0).text;                  // '1亿2万3.45'（旧快照不变）
```
