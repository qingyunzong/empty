# 采集选择器的相对位置语义

页面抽取服务通过Go包在只读元素树上执行选择表达式。元素有唯一ID、标签和有序子元素；表达式由/分隔的步骤构成，首步从虚拟根的孩子开始，每步是标签或*，可跟一个[n]或[last()]，n为正十进制整数；//表示在当前节点的所有后代中匹配该步。位置谓词对每一个输入节点的候选集合分别计算，候选按文档前序排列，再合并去重并按文档序返回，不能在合并后取第n个。支持以|连接多个完整路径并取文档序并集；空步骤、尾分隔符及其他语法返回零起始字节位置，解析失败不得遍历树。输入树结构由调用方保证无环。实现编译和重复求值接口，以逐路径朴素解释器核验嵌套同名节点、每父节点位置、后代重叠及并集。
