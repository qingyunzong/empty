# orderstats

按订单事件构建状态时间线的统计库，仅使用 Go 标准库。

## 语义

- **排序**：事件按 `(Timestamp, Version, ID)` 升序应用；同时间先比版本再比 ID。
- **非法转换**：不满足转换表的事件不生效，并作为 `Rejection` 证据保留
  （事件本身、尝试时的当前状态、原因）。
- **更正**：同 ID 更高 Version 的事件取代旧事件；后继事件的合法性可能
  因此改变，时间线通过完整重放重建。同 ID 同 Version 为重复事件，
  低 Version 为已取代事件，均记入 `Duplicates` 证据且不生效。
- **驻留区间**：状态驻留为半开区间 `[Start, End)`，未关闭区间 End 为零值；
  范围查询 `Residence` / `TotalResidence` 同样按半开区间 `[start, end)` 统计。
- **增量核对**：每次 `Add` 的增量结果都与一次完整重放比对，不一致返回
  `ErrInconsistent`。
