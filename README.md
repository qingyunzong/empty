# authz

资源树鉴权库（仅 Go 标准库）。

## 语义

- 规则挂在资源树节点上，沿树向下继承。
- 求值从目标资源向根逐层上行：**最近一层**有任何匹配规则即决定结果并遮蔽所有祖先层。
- 同一层内 **deny 优先**于 allow。
- 主体可以是用户或组；组可嵌套、可成环，成员闭包用 visited 集合计算，保证有限。
- 无任何层匹配时默认拒绝（`Matched=false`）。
- `Evaluate` 返回 `Decision`，含命中路径（途经节点、命中规则、组成员链 `Via`）。

## 一致性核对

`Verify(root, dir, users)` 将自底向上的 `Evaluate` 与独立的自顶向下
完整可达扫描 `ScanAll` 对每个 (节点, 用户) 对逐一比对。更正组成员边
（`RemoveMember`）或父节点（`SetParent`，会拒绝成环）后应重新运行
`Verify` 确认两种实现仍然一致。
