# linsolve-cli

精确求解**单变量线性不等式 + 同余约束**的 CLI。变量取值于给定的有符号 64 位闭区间，
输出全部解的**最简步长区间**（等差区间）或**无解证书**。全程 bigint 精确计算，
严格不等式通过整数平移处理（`a*x + k < 0` ⇔ `a*x + (k+1) <= 0`），绝不经过浮点转界。

## 使用

```sh
npm run build                      # 编译到 dist/
node dist/src/cli.js problem.txt   # 或: cat problem.txt | node dist/src/cli.js
npm test                           # 编译并运行全部测试
```

选项：`--json` 输出 JSON（bigint 序列化为字符串）；`--verify-limit N` 穷举核验阈值
（默认 1000000）；`--no-verify` 关闭核验。
退出码：`0` = SAT，`1` = UNSAT，`2` = 输入/运行错误。

## 输入格式

每行一条语句，`#` 开始注释：

```text
var x in [-100, 100]     # 变量及其 64 位闭区间定义域（必须声明）
2*x + 3 <= 15            # 线性不等式：<= < >= > == !=
x % 7 == 3               # 同余（亦支持 x == 3 (mod 7)）
-(x + 3) <= 2*(x - 1)    # 支持括号、一元负号、常数乘变量
```

约束须为单变量线性式；跨变量约束会被拒绝。多个变量可分别声明、各自独立求解。

## 输出

- **SAT**：每个变量的最简步长区间列表 `[start .. end] step s`（单点记为 `{v}`）。
  同余经 CRT 合并为一条等差列，不等式裁剪定义域，`!=` 排除点把区间切开；
  区间按构造极大、不可再合并（最简）。
- **UNSAT**：结构化证书 —— 常量矛盾 / 空区间（注明上下界来源约束）/
  同余不可解（gcd 不整除）/ CRT 冲突（注明冲突双方与 gcd）/ 等差列与区间无交。

## 求解与核验

1. 不等式经 floor/ceil 整除精确收紧定义域（缩小域）；
2. 同余用扩展欧几里得求模逆、CRT 逐条合并；
3. 等差列与缩后区间求交，扣除 `!=` 点，生成步长区间；
4. **穷举核验**：缩后定义域不超过阈值时，逐点用原始约束重判并与区间展开比对
   （UNSAT 时穷举确认全域无解）；定义域过大时退化为精确边界/缺口点核验。

示例见 `examples/`。

## 测试

`npm test`：单元测试（整除/CRT/解析/求解）、400 组随机系统与暴力枚举逐点对照、
CLI 端到端测试（含 64 位边界与超双精度常数的精确性回归）。
