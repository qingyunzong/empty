# 设备消息的选项增量与关键选项

设备采集把确认和响应粘在同一条流里，选项增量若把15当成扩展，载荷标记就会被当成下一个选项。实现可导入的Go组件，供设备采集调用，不访问网络。每条消息第一字节的高2位必须为1，随后2位是类型0至3，低4位是令牌长度且只能为0至8。其后是1字节代码和大端uint16消息号，再是正好令牌长度的原始字节。代码高3位只能是0、2、4或5。高3位为0时低5位只能是1至4；为2时低5位只能是1、4或5；为4或5时低5位为0至31。选项号从0起。每个选项头的高4位是增量、低4位是长度；半字节0至12就是该值，13表示再读1字节并加13，14表示再读2字节大端值并加269，15失败。选项号等于上一选项号加增量，长度后再读这么多原始字节。同一选项号只允许1、4、11、15重复，其他重复失败。未识别的偶数选项保留原始字节，未识别的奇数选项失败。载荷若存在，必须以单独的0xFF开始，且后面至少1字节；0xFF不能出现在选项区。空消息的代码、令牌长度都必须为0，且没有选项和载荷。单条消息超过宿主maxMessage时，在长度可判定后拒绝，不按声明分配。Push可停在选项中间；Finish时消息未完成则失败。失败停止组件，已交付消息保留。测试独立编码，覆盖增量13和14、奇数未知选项、偶数未知选项、重复路径、空确认、载荷标记后没有字节，以及头被切到下一块。期望消息不得调用被测组件生成。
