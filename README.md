# sheet-dag：增量电子表格计算引擎

TypeScript 实现，仅依赖 Node.js 内置模块（`node:test` / `node:assert`），无第三方运行时依赖。

## 语义规则

- **值域**：整数或错误（`#DIV/0!`、`#CYCLE!`、`#ERROR!`）。空单元格按 `0` 处理。
- **DAG**：单元格引用构成有向无环图（题设前提）。求值时仍会检测环并报
  `#CYCLE!`（来源取环上最小地址），环解除后自动恢复。
- **错误传播**：每个错误携带来源地址；表达式合并多个错误时取**来源地址最小**者。
  地址为行优先全序：`A1 < B1 < A2`（先行后列）。
- **动态条件**：`IF(c, a, b)` 只求值被选中分支——未选中分支既不产生依赖边，
  其错误也不传播。条件本身为错误时直接传播，不选分支。
- **整数除法**：向零截断；除数为 0 产生 `#DIV/0!`，来源为当前单元格。

## 增量引擎（`src/engine.ts`）

- 每个单元格缓存：公式、AST、值、**动态依赖集**（求值时实际读到的单元格）。
- `setFormula` 触发：
  1. 从被改单元格沿**反向依赖边**做失效标记（BFS，只标记可能受影响的闭包）；
  2. 按地址序重算受影响单元格；求值中按需递归，未受影响单元格直接命中缓存；
  3. 每次求值后 diff 新旧依赖集，增量维护反向边（IF 分支切换时依赖随之迁移）。
- 值未变化的单元格也会重算但不向外扩散额外失效（失效闭包在修改时一次确定）。

## 对照验证

- `src/interpreter.ts`：全表解释器，与引擎共享求值核心 `evaluate`，
  但 memo / 依赖记录完全独立，每次从公式集合整体重算。
- `test/differential.test.ts`：确定性模糊测试（mulberry32，6 个种子 × 200 步），
  每步随机改写/清除一个公式后，逐单元格对比增量引擎与全表解释器的
  **值与动态依赖集**。会产生环的编辑不属于 DAG 题设域，跳过（环行为由单元测试覆盖）。

## 运行

```sh
npm test        # tsc 编译 + node --test
npm run build   # 仅编译到 dist/
```

环境要求：Node.js（≥18 即可）与可用的 `tsc`（本仓库不安装任何 npm 依赖；
`src/node-shims.d.ts` 内置了 `node:test` / `node:assert` 的最小类型声明）。

## 已知边界

- 循环图的 `#CYCLE!` 来源与求值顺序相关（增量缓存与全量重算可能给出不同来源），
  因此差分对照限定在 DAG 域内；单元测试固定验证了环检测与恢复行为。
