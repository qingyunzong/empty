# 网页抓取的范围与重定向控制

站点归档服务调用可导入的Go抓取包，输入起始URL、允许主机名集合、正整数请求上限及可替换HTTP传输层。按广度优先顺序抓取，页面链接按文档顺序加入队尾；仅允许HTTP或HTTPS，主机名不区分大小写，去除片段并将主机名转小写后的完整URL用于去重。每次请求前检查允许集合，包括重定向目标；每发出一次HTTP请求计入上限，重定向在当前页面内按顺序跟随；目标若已请求则停止该链，若仅已入队则将队列中的该项标记为已处理并立即跟随，后续出队时跳过。达到上限时不再发请求，返回尚未处理队列及当前未请求的跳转目标。仅从成功HTML响应提取链接，以最终响应URL解析相对地址；非法URL记录拒绝原因并继续。返回访问结果、引用关系及拒绝原因。用本地HTTP服务测试跨域跳转不会请求、重定向循环、相对链接和请求上限。
