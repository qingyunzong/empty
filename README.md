# 重复区域中的记录边界推断

网页抽取服务调用可导入的Go区段划分包，输入按文档序的节点特征串、调用方给出的候选记录区间及每区间非负收益。候选为非空节点索引半开区间，锚点为节点索引；区间可以相接但不能重叠，求总收益最大选择，平局先记录数最少再按所选起点终点列表排序。另给必须覆盖的锚点，每锚点须恰落在一个所选区间，漏覆盖或多覆盖均非法；规模至多200候选和20锚点。输出最优划分及收益，不能把无约束区间调度结果事后过滤。用小规模全子集核验。

## 用法

包路径为模块 `example.org/dataeng/q0117` 下的根包 `dataeng`，入口为
`BestPartition(nodes, candidates, anchors)`：

- `nodes`：按文档序排列的节点特征串，候选与锚点均引用其下标。
- `candidates`：非空半开区间 `[Start, End)` 及非负 `Profit`。
- `anchors`：必须恰好被一个所选区间覆盖的节点下标（不可重复）。

返回 `*Partition`，含文档序 `Intervals`、`Records` 与总 `Profit`；
不存在满足全部锚点覆盖的选择时返回包装 `ErrInfeasible` 的错误。
覆盖约束在动态规划转移内强制，不做无约束调度后的事后过滤。
平局依次按总收益最大、记录数最少、`(Start, End)` 列表字典序最小。

```go
part, err := dataeng.BestPartition(nodes,
    []dataeng.Candidate{{Start: 0, End: 2, Profit: 3}},
    []int{1})
```

测试包含 2000 组随机小规模实例（节点不超过 8、候选不超过 12），
每组与 2^m 全子集穷举结果逐字段比对，另含 200 候选、20 锚点规模测试。
