# 偏序采集值的精确保序投影与对偶证据

多个采集源对同一校准量给出带权观测，元数据只承诺部分节点之间应非递减，任选一个拓扑序做一维合并会额外约束不可比节点。开发供数据校准宿主调用的Go可导入保序投影包。输入至多64个有唯一ID的观测(y_i,w_i)，y_i是任意精度有理数、w_i是严格正有理数；有向边u到v表示x_u<=x_v，图必须无环，允许冗余传递边，重复边去重但保留原边ID列表用于来源映射，未知点或自环拒绝。求唯一最优有理向量x，使全部边约束成立并最小化F=sum_i w_i*(x_i-y_i)^2；不能用浮点近似、epsilon或分母截断后声称精确，也不能先逐条夹紧再把可行结果当最优。空图返回空向量及0，孤立节点保持原值；权重全正使向量唯一，不要求选取某个拓扑排序作为决胜。正式实现须用适用于一般DAG的有限优化算法，例如基于闭集切分的流方法或可证明终止的精确活动集法，不能枚举所有节点划分、所有拓扑序或全部边子集，也不得依赖外部优化器。算法细节可自选，但必须解释终止条件，实际记录流调用或活动集变化次数，不能只做固定次数迭代。除x及精确F外，返回每条去重边的非负有理乘子lambda_e，并满足每点2*w_i*(x_i-y_i)+sum_{i到v}lambda_e-sum_{u到i}lambda_e=0，以及每边lambda_e*(x_u-x_v)=0；非紧边乘子必须0，紧边可以0，不要求乘子唯一。提供一个与优化器分离的证书核验器，仅按输入、x和lambda检查范围、非负、原始可行、驻点及互补条件并重算F，核验器不得再次运行优化或信任缓存的成功标记。不能给每个节点单独声明误差0冒充全局最优证明。宿主可在多个调用间复用编译后的偏序图，更换y和w重新求解；公理边、返回x和乘子不可被下一次调用修改。提供真实校准宿主调用例，在n<=7时用独立集合划分枚举参考：每块取其加权观测均值，保留满足全部原边约束的候选，直接计算目标选最优，以此核对向量而非只比较费用；此指数参考仅用于小测试。覆盖菱形偏序中两中间点不可比且最优值不同、孤立点、相等观测、负有理观测、极不均匀权重、冗余边导致乘子不唯一、图分成多组件、链式池化及一个违反约束需要拆分错误合并池的分叉图。对证书逐项篡改x、乘子符号、某点流量和目标值应被拒绝；较大64节点多层DAG须返回可核验结果，不能借测试规模改用枚举。

## 实现概览

模块 `example.org/dataeng/q0319`：主包 `dataeng` 是编译期偏序图与精确求解器，子包 `cert`
是与优化器完全分离的证书核验器。全程仅使用 `math/big`，无浮点、epsilon 或分母截断。

- `graph.go`：节点/边校验、自环与未知点拒绝、Kahn 无环检查；重复 `(From,To)` 去重并保留
  全部原始边 ID。编译后的 `*Graph` 不可变，可跨多次 `Solve` 复用。
- `flow.go`：精确有理数容量的 Dinic 最大流；每次阻塞增广饱和弧并抬高汇点最短路层数，
  结构性有限终止，不依赖容差。
- `closure.go`：把“最小权下闭集”归约为一次最大流（最大权闭合），用严格负权闭集作为拆分证书。
- `solve.go`：有限块切分。初始为一个整块，反复在块上取加权均值并计算残差
  `a_i = w_i(mean-y_i)`；当且仅当最小权下闭集权值严格为负时拆成两个块。每次拆分块数严格
  增加且上界为 `n`，故至多 `n-1` 次拆分；之后每个块再用一次可行流恢复非负 KKT 乘子。
  `Result.FlowCalls / Splits / Blocks` 记录真实终止过程，而非固定迭代预算。
- `cert/cert.go`：独立核验输入范围、乘子非负、原始可行、逐点驻点、逐边互补并重算精确 `F`；
  不导入也不调用求解器，不读取任何成功标记。

### 宿主调用

```go
g, err := dataeng.Compile(ids, y0, w0, edges) // 偏序公理只编译一次
res, err := g.Solve(yBatch, wBatch)           // 每批更换 y、w 重新精确求解
xv, _ := res.X("sensor-7")
lam, _ := res.LambdaBySourceID("edge-12")
if err := cert.Verify(certificateFrom(res)); err != nil { /* 拒绝该批结果 */ }
```

`n <= 7` 的测试用独立集合划分枚举参考（块内加权均值、块商图无环且均值满足全部原边）逐点
核对向量；`n = 64` 多层 DAG 只走正式流算法并用 `cert` 核验，不使用枚举。
