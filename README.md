# 地址包选项溢出到文件区

地址采集读到结束选项就停，文件区里接着的选项会整段丢失。实现可导入的Go组件，供地址采集调用，不接收网络。前240字节依次是操作、硬件类型、硬件地址长度、跳数、大端uint32事务号、大端uint16秒数、大端uint16标志、4个4字节地址、16字节硬件地址、64字节服务器名和128字节文件名。接下来4字节必须是0x63、0x82、0x53、0x63。之后是选项，直到选项255。选项0是填充，没有长度。其他选项是代码、1字节值长度和值，值长度不含代码和长度字节。选项52的值长度必须为1，值只能是1、2或3。遇到255后，值1再按同样规则解析文件名，值2解析服务器名，值3先解析文件名再解析服务器名。这些区域也必须以255结束。选项区里没有255则失败。同一代码可以重复并保留顺序。原始长度大于宿主maxPacket时在超出的字节出现时拒绝，不按声明分配。Push可停在选项中间；Finish时包未完成则失败。失败停止组件，已交付包保留。测试独立组包，覆盖选项52把选项放进文件名、先文件名后服务器名、文件名里没有255和包被切开。期望包不得调用被测组件生成。
