# sublib

断线重连订阅客户端，语义保证：

- **从最后确认序号重连**：每次 `Dial` 携带 `lastAck + 1`，断线后服务端从该序号重发。
- **回调成功才推进确认**：`Handler` 返回 nil 后才发送 `Ack` 并记入确认账；回调失败直接断连重投。
- **失败可重复投递、结果 ID 稳定**：同一逻辑结果重投时 `ResultID` 不变，回调方可幂等去重；
  已确认的序号若被重复投递，客户端只补 `Ack`，不再触发回调。
- **新代际取消旧连接**：每次重连开启新 generation，先取消旧 generation 的 context 并关闭旧连接。
- **确认账**：`Ledger` 只接受严格连续的序号（拒绝跳号），`Client.LedgerString()` 输出确认账。

运行测试：

```sh
go test ./...
```

测试用受控传输（`fakeServer`/`fakeConn`）精确脚本化断线点，覆盖：
断线后按 `lastAck+1` 重连、断线发生在交付与确认之间不跳号、回调失败重投且
ResultID 稳定、新代际取消旧连接、重复投递幂等、确认账拒绝跳号并可打印。
