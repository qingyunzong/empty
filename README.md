# 缓存响应头里的三段长度

缓存采集若按体长度单独跳过键，附加区会把键的前几个字节算进值。实现可导入的Go组件，供缓存采集调用，不连接缓存。每个响应以24字节头开始：魔数必须是0x81，操作码、键长度大端uint16、附加长度1字节、数据类型1字节、状态大端uint16、体长度大端uint32、不透明大端uint32、CAS大端uint64。体长度等于附加、键和值的字节数之和，大于宿主maxBody时在这4字节可读后拒绝，不按声明分配。附加区在前，键居中，值在最后。键长度或附加长度大于体长度则失败。数据类型必须为0。状态原样返回，不把非0状态当成帧错误。不透明字段和CAS原样返回。操作码只接受0x00、0x01、0x04和0x0C。0x00的键长度必须为0，状态为0时附加长度必须为4，状态非0时附加长度必须为0。0x0C在状态为0时附加长度必须为4，状态非0时附加长度和键长度都必须为0。0x01和0x04的附加长度必须为0。Push可停在体中间；Finish时响应未完成则失败。失败停止组件，已交付响应保留。测试独立组包，覆盖附加区非空、键长度等于体长度、状态非0、魔数0x80和头被切开。期望响应不得调用被测组件生成。
