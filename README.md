# 采集字典码的宽度切换与半项背压

遥测归档接入器收到变宽LZW字典码，输出缓冲恰好用尽时可能只交付一个字典项的前半段。为宿主开发Go可导入的增量解码包，下面规则完整定义本题码流，不要求GIF或TIFF兼容。初始码宽9位，0..255为单字节词，256是CLEAR，257是END，next=258；位流高位先行连续打包，宿主给earlyChange为0或1。首个码必须CLEAR，每个CLEAR清空动态词典并恢复宽9、next=258和空prev；重复CLEAR合法，不产生字节。普通码若code<256取单字节，若258<=code<next取对应词；code==next仅在prev非空且next<4096时合法，词为prev接其首字节，即KwKwK；其他尚未定义码拒绝。拿到普通词entry后，若prev非空且next<4096，建立next号词prev接entry首字节，然后next加1；若width<12且此时next==2^width-earlyChange，则下一个码开始改用width+1。prev置为entry。词典满后保持12位且不再插词，直到显式CLEAR；不能隐式清空。END可在空输出时出现，不插词，终止后当前物理字节未用低位必须全0，后续不得有额外字节，真实Finish前不能报告完整。物理EOF没有END、半个码、非零填充或多余字节均错误；每次错误进入失败终态，已交付输出前缀保持。提供Feed字节与Pull(maxBytes)接口，maxBytes为非负整数；Pull返回实际字节和needInput/needOutput/end之一，maxBytes=0不得消费普通码或生成字典项，但可报告已经确定的终态。可以自行设计明确的状态枚举来区分同时缺输入和容量的情况，必须在接口文档写清。普通码在位数不足时不消耗其部分状态；输出容量不足时保存当前词的待交付后缀，恢复后不能重复插入该码的词典项或提前取下个码，也不能把CLEAR或END当作词的字节。字典只存每动态词的前缀码、末字节、长度及首字节，不给每词保存完整展开字符串；解一个词可用长度至多4096的临时反向栈，已有输出不可累计保留。每条输出片段返回来源码的压缩位区间及在该词内的字节区间，同词多次Pull的来源一致。宿主给uint64总输出上限；处理普通码前按整词长度检查，不允许先输出半词再发现超限，也不能对长度和计数回绕。Feed完成后可标记输入结束，Finish应继续允许Pull排空合法待交付后缀，但只有END、填充、物理尾部均验证并排空时返回end；截断不按有效空流处理。给接入宿主调用例及独立完整词字符串参考解码器，小数据逐码对照词典号、宽度切换点、输出和来源；另构造跨9到10、10到11、11到12位边界的码序列及两种earlyChange，测试紧挨切换前后CLEAR、首个普通码非法KwKwK、合法KwKwK、满词典继续读取、每个字节切块、一个词以1字节Pull多次交付、零容量、上限恰足与差1。测试写码器按参考解码器的下一码宽打包，不能复用生产解码的宽度状态来掩盖同错。
