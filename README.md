# synclib

同步库：把一批字段写入 `Store` 后立即回读核验，规范化只应用**声明的**等价规则。

## 核心语义

- **写后回读**：`Syncer.Sync` 写入后立刻 `Read`，按声明规则比对；
  不一致时返回 `*MismatchError`，其中保留**原始写入回执**（`Receipt`）
  与**逐条具体差异**（`Diff`：字段缺失/多余/不匹配、附件缺失/多余）。
- **声明式规范化**：只有 `Ruleset` 中声明的规则（去首尾空白、大小写折叠、
  折叠连续空白，可全局或按字段）参与等价判断，其余差异一律上报。
- **附件比较**：按内容哈希（SHA-256，含文件名）构成多重集合比较，
  顺序无关，哈希必须一致。
- **读优先重试**：`SyncWithRetry` 每次写入前先读存储，若目标状态已存在
  （例如上次写入实际已生效），直接返回既有回执，不再重复写入。
- **假存储**：`fakestore` 支持注入部分写（`PartialWrite`：指定第 N 次写
  丢弃某些字段/附件并可返回错误）与延迟回读（`ConsistencyWindow`：
  写在窗口期内对读不可见），时钟可注入便于确定性测试。
