# route — 路线 CLI

计算含通行费、单次累计满额返还、互斥优惠券与燃料约束的最优路线。
仅使用 Go 标准库。

## 语义

- **路径约束**：路径不重复节点（简单路径），至多 `maxNodes` 个点（默认 12，上限 31）。
- **排序**：先实付费用小，再行驶时间短（字典序 `(cost, time)`）。
- **通行费**：每条有向边有 `toll`（通行费）、`time`（行驶时间）、`fuel`（耗油）。
- **单次累计满额返还**：累计净通行费达到 `rebate.threshold` 时触发一次
  `rebate.amount` 返还。返还**不作为独立负边**建模，而是作为累计状态
  （`cumNet/trig/red`）随搜索标签携带；仅在抵达 `rebate.stations`
  指定的收费站时兑现（`stations` 为空则触发即兑现）。
- **优惠券**（至多 6 张，互斥）：券 `i` 在其 `requiresEdges` 全部驶过后
  生效，可抵扣**之后**某一条边的通行费（最多抵到 0）；整条路径至多使用一张券。
- **燃料**：`fuel.capacity` 为油箱容量（0 表示不限油），`fuel.start` 为
  初始油量；`fuel.stations` 列出加油站及单价，加油费用计入总费用。
  油量为整数单位，固定路径的加油方案由精确 DP 求得。

## 用法

```sh
go build ./cmd/route
./route solve     [-budget N] problem.json   # 最优路线 + 逐边费用过程
./route verify    [-budget N] problem.json   # 与简单路径枚举对照
./route enumerate problem.json               # 暴力枚举基准
```

`problem.json` 可用 `-` 表示标准输入。示例见 `examples/basic.json`
（通行费+返还）与 `examples/full.json`（返还站+券+燃料）。

## 求解器

- `internal/route.Search`：有限状态最优优先搜索。标签状态为
  （节点， 油量， 已访问点集， 各券进度位掩码， 已用券， 返还触发/兑现，
  累计净通行费），配精确支配规则剪枝与可采纳下界
  （最小通行费距离 − 未兑现返还 − 未用最大券额）。
- **预算**：`-budget N` 限制标签扩展次数。预算耗尽时返回当前**最佳可行解**
  与**下界**（`Exhausted=true`）；预算未完（队列排空）时解为最优且
  `LowerBound == Cost`。
- **对照**：`internal/route.Enumerate` 枚举全部简单路径，用共享精确模拟器
  `Simulate` 评估，作为搜索的基准对照。

## 输出

`solve` 输出逐边状态：边、通行费、券抵扣、净通行费、累计净通行费、
本边兑现的返还、加油量与加油费、行驶前后油量、累计费用、累计时间，
以及总费用、总时间、下界、扩展次数、预算是否耗尽。

## 测试

`go test ./...`：

- 搜索 vs 简单路径枚举随机对照（basic 1000 种子 / full 1000 种子，
  开发期另以 20000 种子强化验证通过）；
- 预算耗尽时最佳可行解与下界夹逼最优值；
- 返还非负边（累计触发、仅一次、仅指定站兑现）、券互斥与生效条件、
  燃料与加油费、费用优先时间其次、简单路径与 12 点上限等语义用例。
