# 稀疏地理栅格的守恒重采样

地理数据接入宿主需要可导入的Go守恒重采样包，源目标都是以严格递增有理x/y边界描述的轴对齐栅格，源格为精确有理值或nodata，值代表单位面积密度。对每个目标格按相交面积积分，结果为有效源格的加权均值；同时返回有效覆盖面积、未覆盖面积、nodata覆盖面积和全部贡献源坐标，三个面积之和须等于目标面积，无有效面积时值为nodata。每个轴至少两个边界，输入值格数必须匹配边界尺寸，否则全次拒绝；贡献按源行再列排序。源格无重叠，不允许按中心点近邻代替；边界无面积不算贡献。用所有端点切分成小格的独立模型核验跨域目标、极细有理边界和全nodata，源目标坐标同一平面。
