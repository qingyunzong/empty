# 科学数组记录交错的切片读取

科学数据接入宿主会把已解析的CDF-1元数据与io.ReaderAt交给Go包，请实现其中的切片读取器。元数据含文件长度、记录数、维度长度、每变量的维度ID、类型、begin和vsize；仅支持byte、char、short、int、float、double，宽度分别为1、1、2、4、4、8，数值大端，byte有符号，char保留原字节。至多一个维度长度为0，代表记录维且只准出现在变量首维，实际长度取记录数。普通变量末维最快连续存储；记录变量按记录交错，每条记录内按begin顺序排列各变量slab，跨记录步长为各记录变量vsize之和；vsize是单个普通变量或单个slab的字节数向上补齐到4，必须与元数据一致。只有一个记录变量且类型为byte、char或short时，实际跨记录步长使用未补齐字节数，vsize仍填写补齐值。切片参数为每维start、count、stride，stride正，count可0，返回末维最快的值和每值物理偏移；浮点以原始位型返回。检查维度引用、长度乘法溢出、变量区域重叠、begin落入其他变量数据区、记录slab布局不一致、切片越界和短读，错误不能交付半个切片。普通变量不能占记录区。不得先全量读入文件再切片；非空切片才校验start到最后坐标，任一count为0时返回空且不访问ReaderAt；元数据仍需完整校验。标量以空维度列表表示且恰有一个值。begin必须非负且4字节对齐，数值范围和中间乘积均以精确整数校验。调用方限制一次最多读取的字节数，返回读取计数用于验收。测试单record变量不补齐、两个record变量交错、标量、空切片、跨记录步长与大偏移，使用独立小数组逐坐标模型核对。
