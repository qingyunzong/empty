# faultplan — 故障测试规划 CLI

为持久点故障注入测试规划用例：每个用例覆盖一个持久点子集（受容量限制），
要求覆盖**每个点的单故障**与**指定的双故障对**，用例数不超过上限（默认 22），
最小化总执行费用。仅使用 Go 标准库。

## 模型

- 持久点 `0..n-1`；需求 = `n` 个单故障 + 指定的双故障对（默认全部 `C(n,2)` 对）。
- 用例 = 非空点子集，大小 `≤ max-case-size`；覆盖子集内所有单点与点对。
- 用例费用 = `setup + per-point × 点数`；总费用最小化；用例数 `≤ max-cases`。

## 用法

```sh
go build -o faultplan .
./faultplan -n 6 -verify
./faultplan -n 5 -pairs 0-1,1-2,2-3,3-4,4-0 -setup 5 -per-point 2 -max-case-size 2 -verify
./faultplan -n 10 -max-case-size 3 -timeout 30   # 大规模：限时，给出当前最优+下界间隙
```

参数：`-n` 点数，`-pairs` 双故障对（`all`/`none`/`0-1,2-3`），`-max-cases`（默认 22），
`-setup` / `-per-point` 费用参数，`-max-case-size` 用例容量，
`-verify` 小规模 DP 全量核对，`-cert` 打印对偶证书权重，`-timeout` 求解时限（秒）。

## 输出

1. **覆盖方案**：用例列表、各自费用、总费用，并复核全部需求确已覆盖。
2. **下界证书**：集合覆盖 LP 松弛的对偶可行解 `y`（满足：对每个候选用例，
   其覆盖需求的权重和 ≤ 用例费用），故 `Σy` 是任意可行方案费用的严格下界；
   程序对全部候选逐一验证约束后输出 `LB` 与间隙。间隙为 0 时即证明最优。
3. **小规模核对**（`-verify`，需求数 ≤ 22）：掩码 DP 枚举所有候选用例的
   0/1 选择，独立求精确最优并与分支定界结果比对。

## 实现

- `model.go`：问题建模、候选枚举、方案校验。
- `solve.go`：贪心初始解 + 分支定界精确求解（按首个未覆盖需求分支，
  覆盖状态记忆化，用例数/费用双下界剪枝，支持超时降级为可行解）。
- `bound.go`：对偶下界证书（均匀权重 + 多顺序坐标上升，整体收缩后严格验证）。
- `dp.go`：覆盖掩码 DP，用于小规模全量核对。
- `faultplan_test.go`：手算最优用例、300 个随机小实例 B&B 对 DP 全量核对、
  对偶证书可行性与下界性质、用例数上限、超时降级。
