XML消息网关需要可嵌入Go服务的验签组件，调用方注入Ed25519公钥，消息只有一个Signature，其Reference为#ID并带SHA256摘要。先检查全树ID唯一、唯一业务Payload正是被引用元素且签名不在Payload内，再规范化并验签，成功后只向处理器传该节点。规范化限定无DTD、无注释、无处理指令的XML子集：元素与属性用展开名，属性按展开名排序，规范流以E加展开名和属性数开始，每项名与值为32位大端字节长加UTF-8内容，T加长度文本，Z结束元素；展开名为命名空间URI和本地名两个长度串，签名覆盖32字节摘要，前缀不参与。测试签名包裹攻击、同ID复制、前缀改名与文本变动，不允许验签一个节点却消费另一个。
