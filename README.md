# 高频采集项的有界误差摘要

遥测计数宿主需要可导入的Go加权频率摘要，最多保存K个非空字节键的正整数计数，K>=1，输入权重为正任意精度整数。插入已有键直接加；空位可放新键；满表遇新键时取权重与当前最小计数的较小者δ，全部计数减δ、零者删除，新键剩余权重继续同规则，累计误差预算加δ。分片合并先把同键保留计数相加，超K时反复全体减最小计数并清零，合并误差为两侧误差再加新δ之和。仅允许相同K的摘要合并，T由已接受输入权重及合并两侧总权重自行维护；针对该真总权重T，不在保留表中的键保留计数视为0；查询任意键返回[保留计数,保留计数+误差]，候选必须包含所有真频次大于T/(K+1)的键。保存总权重并验证合并不改输入，用全量计数证明界及随机合并树测试，不能宣称不同合并树保留表完全一致。
