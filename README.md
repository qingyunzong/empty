# 书目采集记录的目录与异文链接

书目数据接入宿主要从连续MARC21记录中提取字段，并把880异文与对应普通字段关联，不构建借阅或管理系统。实现可导入Go流读取包，只处理题面规定的UTF8子集。每条记录前24字节为leader，0..4为5位ASCII十进制记录总长，12..16为5位十进制数据基址B，字节9必须a、10/11必须2、20..23必须4500；其余leader字节原样保留。目录从24开始，以单个0x1e终止，B恰等于目录终止后一字节；目录每项12字节，依次为3位十进制tag、4位字段长度、5位相对B偏移。总长至少26，B不得小于25且不得超过总长-1；字段长度为正且含末尾0x1e，记录最后一字节必须0x1d，字段范围须无重叠无洞地覆盖[B,总长-1)，但目录顺序不必等于物理字段顺序，输出保持目录顺序和重复tag。tag001..009是control，正文仅为UTF8且不能含0x1e/0x1d/0x1f；010..999为data，首两字节是可打印ASCII指示符，后面是至少一个0x1f、单ASCII字母数字子字段码、UTF8值组成的子字段序列，空值允许，值不能含0x1e/0x1d/0x1f；tag000拒绝，所有文本严格UTF8而不是按字符数算目录长度。data字段最多有一个代码6子字段，880必须有且在第一位置，其他data的6也只可在第一位置；其值只支持TTT-NN，TTT为三位目标tag、NN为两位出现号，普通字段只能指向880，880只能指向010..999中的非880。NN=00表示不要求配对的独立异文，非零时按普通tag与NN建立恰一对普通字段和880，任何孤立、重复或不互指都拒绝整条记录，不能按最近同tag猜配。输出全部字段/子字段原始字节范围和配对的目录下标，不因配对重排字段。宿主限制单条字节数与字段数，声明超限先拒绝；任意切块可读连续记录，只在整条结构、文本和链接通过后交付，真实截断给当前记录起点及局部错误偏移，已交付前缀保留。以独立编码夹具测试物理乱序目录、重复245、两套出现号、00不配对、多字节UTF8长度、目录洞和后续记录截断。
