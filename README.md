# mask — 字节范围脱敏库（仅 Go 标准库）

## 语义

- 敏感字段以原始输入的半开字节区间 `[Start, End)` 指定。
- 重叠或相邻的范围先求并（`MergeRanges`），空范围丢弃。
- 替换策略必须显式选择，未选择返回 `ErrModeUnset`：
  - `ModeSameLength`：同长替换，每字节替换为 `MaskByte`（默认 `*`），长度不变；
  - `ModeDigest`：摘要替换，整段替换为 `[sha256:<hex>]`。
- 非敏感字节原样保留。
- 返回双向位置图 `PositionMap`：`OrigToOut` / `OutToOrig`。
  保留段内线性映射；脱敏段内映射钳制到段边界；越界钳制到末尾。

## 增量块输入

`Streamer`（`NewStreamer`/`Write`/`Close`）支持任意切块喂入：

- 敏感字段全部字节到齐（已判定）之前，既不输出原文片段，也不提前输出
  替换内容（同长与摘要模式一致）；
- 已确定不属于任何范围的字节即时通过；
- `Close` 时校验范围合法性并冲刷剩余输出，之后可取完整 `PositionMap`。
