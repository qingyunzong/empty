# 点分键与数组表

流水线配置接入调用可导入的Go包读取配置，不启动任务。点分键在同名表尚未出现时可以建立隐式父表；父表一旦被定义成非表，后续再写入就失败。数组表只能追加，不能替换已有的表。基本键重复赋值失败。字符串只接受题面写出的转义：引号、反斜杠、换行、回车和制表。用独立表格模型核对隐式父表、重复键和数组表追加，期望不得由被测包生成。

## 包用法

`dataeng` 是一个只负责读取配置的可导入 Go 包，不启动任何流水线任务。

```go
import dataeng "example.org/dataeng13/q0027"

tbl, err := dataeng.Parse(configText)   // 或 dataeng.ParseFile(path)
if err != nil {
    var pe *dataeng.ParseError          // 带行列号的错误
}
name, _ := tbl.Lookup("pipeline", "name")
```

## 语义规则

- 点分键（含引号键）在中间键不存在时建立隐式父表；父表一旦是非表值，后续再向其下写入即报错。
- `[a.b]` 标准表不可重复定义；可承接此前点分键建立的隐式父表。
- `[[a.b]]` 数组表只追加新元素，永不替换已有表；与标量、普通表或非表数组冲突时报错。
- 基本键重复赋值失败，内联表内同理。
- 字符串仅接受 `\"`、`\\`、`\n`、`\r`、`\t` 五种转义，其他转义或裸换行报错。
