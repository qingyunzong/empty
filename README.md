# simulator

确定性的滑动窗口（选择重传风格）设备传输模拟器。

- 按帧号处理累积确认与选择确认，重传仅针对未确认帧
- 确认与超时同刻时先处理确认（事件按 tick、类型、序号排序）
- 重传次数计入每帧重传上限，超限帧记入失败列表
- 环绕序号：窗口严格小于模数一半（`2*window < modulus`），据此消歧
- 窗口可在有未确认帧时调整；缩小不丢在途帧，仅暂停新发送
- 快照/恢复保留各帧原截止时间与重传次数及待处理事件队列，
  逐事件暂停恢复后发送轨迹与不间断运行完全一致

## 测试


重传上限、环绕序号下交付唯一性、枚举丢包轨迹（每帧丢失 0..MaxRetries
次的全部组合）验证交付恰好等于输入、在途时缩窗、快照保留帧状态、
逐事件暂停恢复核验同一发送轨迹。
