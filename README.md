# sheetcalc — 表格单元格增量求值器

基于依赖图的最小失效传播与确定性重算。仅使用 Python 标准库（兼容 3.11+）。

## 运行

```sh
python3 -m sheetcalc            # 从 stdin 读取命令，结果写 stdout
python3 -m unittest discover -s tests -v   # 运行全部测试
```

## 命令

| 命令 | 说明 |
| --- | --- |
| `set <cell> <expr>` | 定义/重定义单元格表达式 |
| `del <cell>` | 删除单元格：等价置为 0 并解除其出边 |
| `get <cell>` | 输出当前值（除零输出 `E_DIV0`） |
| `dump` | 按 cell 名字典序输出所有存活单元格：`A1 = B1+1 => 2 (v1)` |
| `quit` / `exit` | 退出 |

表达式支持整数、`+ - * /`（截断除法）、括号、单元格引用（如 `B12`），
以及一元正负号。空行与 `#` 注释行被忽略。

## 语义

- **无环**：`set` 若形成引用环则整批原子失败，状态不变，退出码 3。
- **最小失效**：修改后仅按拓扑序重算受影响且值可能变化的祖先；
  未受影响节点不重算、版本号不增。
- **幂等**：重复设置结构相同的表达式（AST 相等）不触发任何传播。
- **删除**：`del` 等价于置 0 并解除出边，值变化时照常传播。
- **除零**：结果为固定错误 `E_DIV0`，并沿依赖传播。
- **未定义引用**：按 0 求值，并向 stderr 记录 `warning:`。
- **退出码**：0 正常；2 解析/用法错误；3 依赖环。

## 实现

- `sheetcalc/parser.py` — 词法/递归下降解析、AST 求值（`E_DIV0` 传播）。
- `sheetcalc/engine.py` — `Sheet`：依赖/反向依赖图、环检测（原子失败）、
  拓扑序最小重算（堆保证确定性）、版本号管理。
- `sheetcalc/cli.py` — 命令循环与退出码。

## 测试结果（真实运行）

- 环境：Python 3.14.4（代码仅使用 3.11 标准库特性）
- 命令：`python3 -m unittest discover -s tests -v`
- 结果：**17 个测试全部通过（OK），0 失败**，最近一次运行耗时约 1.0s

覆盖验收点：

- A 链式 `A1=B1+1, B1=C1+1`，改 `C1` 恰好重算 3 格（`eval_count == 3`）。
- B 菱形共享子表达式，`D1` 变更后 `B1/C1/A1` 各只算一次（`eval_count == 4`）。
- C 构造环 `A1=B1, B1=A1` 原子失败，状态不变，CLI 退出码 3。
- D 随机 20 节点、200 步随机 set/del，与全量重算枚举（oracle）逐步对照一致。
