# tokenbucket

持久化令牌桶限流库，仅依赖 Go 标准库。

## 语义

- **显式单调逻辑时间**：调用方传入 int64 逻辑时钟，库不读墙钟。时间倒退或静止不补充令牌（`now <= last` 时不产生任何累积）。
- **整数速率按余数累计**：速率为有理数 `RateNum/RateDen`（令牌/ tick），小数部分以整数余数累计，不丢不多；桶满时超出部分（含余数）被截断。
- **幂等决议**：窗口内的请求 ID 重复时返回原决议，不重复扣费；决议随日志持久化，重启后仍然有效。
- **日志截断保留幂等窗口**：`Truncate` 将日志压缩为一次状态快照 + 当前幂等窗口（最近 `Window` 个 ID），原子替换日志文件。窗口外的旧 ID 会被重新评估。

## 日志格式

```
S <tokens> <rem> <last> <hasTime>                 # Truncate 写入的快照
W <id> <decision>                                 # 快照保留的窗口条目
D <id> <decision> <tokens> <rem> <last> <hasTime> # 每次决议及其后状态
```

## 测试

- `limiter_test.go`：余数累计、时间倒退、幂等重放、重启不重复扣费、截断保留窗口、配置校验。
- `model_test.go`：与 `math/big.Rat` 有理数参考模型做随机化对拍（时间前进/倒退、请求、重启、截断混合序列），逐操作比对决议与精确有理数余额。
