# numalloc — 持久化整数区间编号库

仅使用 Go 标准库。中央分配器向节点持久化分配**互不重叠**的整数区间,
节点在区间内本地发号, 无需逐号协调。

## 设计

- **分配器 (`Allocator`)**: 只追加日志 (`alloc`/`close`/`transfer` 记录,
  JSON Lines), 每条记录先 `fsync` 再更新内存。落盘失败即进入
  fail-stop 状态 (`ErrBroken`), `Reopen` 后从日志恢复, 因此**故障绝不
  重复发号, 但允许空洞**。
- **节点 (`Node`)**: 状态文件原子替换 (tmp + rename + fsync)。发号前
  先落盘游标, 重启后只续用未消费尾部; 游标已落盘但应答丢失的号码成为
  永久空洞, 绝不重发。
- **区间转让 (`Transfer`)**: 先 fencing 关闭旧代 (状态文件标记
  `Closed`, 旧代含重启后永久停发), 在日志中关闭旧代并固定游标, 再以
  新代把尾部 `[cursor, hi]` 授予目标节点。分配器强制校验"旧代已关闭且
  授予区间与关闭记录一致"。
- **幂等重试**: 所有变更操作携带 `reqID`, 已提交的请求重放返回原结果;
  应答丢失 (`ErrAckLost`) 后用相同 `reqID` 重试即可, 不会重复扣减。
- **故障注入 (`Faults`)**: 注入点覆盖分配器落盘失败、节点落盘失败、
  分配/关闭/授予/发号四种应答丢失。
- **全历史核对 (`Audit`)**: 重放全部历史记录, 结合各节点持久化游标,
  校验所有租约的已消费区间两两不重叠。

## 测试

```sh
go test ./...
```

覆盖: 基本分配与重启续尾、转让关闭旧代、各阶段应答丢失重试、
落盘失败崩溃恢复、随机故障混沌测试 (多种子)、并发发号唯一性。
