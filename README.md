图片采集宿主需要C++交错图像重建组件，输入宽高、每像素1或4字节及七个有编号的数据流。各流依次采样起点与步长为(0,0,8,8)、(4,0,8,8)、(0,4,4,8)、(2,0,4,4)、(0,2,2,4)、(1,0,2,2)、(0,1,1,2)。每行带0至4滤波号，滤波0不加预测值，1加左字节a，2加上字节b，3加floor((a+b)/2)，4从a、b、左上c中选最接近a+b−c者，平局依a、b、c，a距离为每像素字节数，缺失邻值取0，上一行限本流，所有计算模256。流可交错分块，行中断保留状态；只将全部像素齐备的目标行交给调用方，错长或非法滤波撤销整图。用独立正向滤波夹具覆盖奇数尺寸、空流、任意切块及滤波4平局。
