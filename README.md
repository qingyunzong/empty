嵌入式图形宿主需要C++三角形光栅组件，顶点给齐次裁剪坐标及纹理坐标，先裁剪到六个标准视锥平面，再做透视除法和透视正确插值。像素中心采样、顶左规则决定共享边归属，深度小者覆盖且相等保留先提交片元。颜色由调用方纹理采样回调返回。用相邻三角形拼矩形、跨近平面及w异号的夹具验证无裂缝或重复覆盖，并对小画布用高精度参考比较深度及纹理位置。

## 组件

接口在 `include/rast/rasterizer.hpp`，实现在 `src/rasterizer.cpp`（C++20）。

每个三角形的处理流程：

1. Sutherland-Hodgman 依次裁剪到六个标准视锥平面 `-w <= x,y,z <= w`
   （近、远、左、右、下、上）。平面交点按线性插值生成，天然支持
   `w` 异号；完全位于相机后方的三角形不产生任何片元。
2. 透视除法得到 NDC，再做视口映射；像素中心在整数坐标处采样。
3. 边函数光栅化配合顶左填充规则，共享边只归属一个相邻三角形，
   因此无裂缝、无重复覆盖。
4. 透视正确插值：`1/w`、`u/w`、`v/w` 与 NDC 深度在屏幕空间为仿射量，
   重心插值后再除以 `1/w` 恢复纹理位置。
5. 深度测试为严格小于：深度更小才覆盖，相等时保留先提交的片元。
6. 片元颜色由调用方的 `TextureSampleFn` 回调返回。

`Framebuffer.coverage` 可选，用于在深度测试前统计每个像素被几何覆盖
的次数；`dbg_u`/`dbg_v` 可选，记录最终胜出片元的纹理坐标。

## 构建与测试

```
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

`tests/test_rasterizer.cpp` 内含独立的 `long double` 高精度参考实现，
夹具覆盖：相邻三角形拼矩形、跨近平面、`w` 异号（含全负 `w` 剔除）、
深度平局保留先提交片元、透视正确 UV，以及小画布随机输入下逐像素
比较覆盖计数、深度和纹理位置。
