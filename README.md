# rollback-dsu

支持**合并（union）、快照（snapshot）、回滚（rollback）**的连通库（并查集），TypeScript 实现。

## 语义

- `union(a, b)`：合并两个元素所在集合；返回是否真正合并。**重复合并（已连通）也占用一个操作序号**，回滚时按序号逐条撤销。
- `snapshot()`：返回当前操作序号，作为回滚锚点。
- `rollback(snap)`：撤销该快照之后的所有合并（含重复合并占用的序号）。
- `find(x)`：返回 x 所在连通分量的**最小成员 ID**。
- `connected(a, b)` / `componentSize(x)`：连通性查询 / 分量大小。

## 设计约束

- **禁止路径压缩**：回滚依赖父指针的完整历史，压缩会破坏可撤销性。仅使用按大小合并，`find` 复杂度 O(log n)。
- 每次 `union` 在历史栈中记录一条可逆记录（重复合并记录空操作占位），`rollback` 弹栈逆序恢复 `parent` / `size` / `min`。

## 测试

```sh
npm test
```

测试包含确定性用例（重复合并占序号、回滚恢复最小成员、find 不改写父指针等）和随机操作核验：参照模型只存合并日志，**每次核验都从日志逐条重建图**（BFS 求分量与最小成员），与库的实现全量比对。
