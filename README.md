# 分页抽取中的跨页记录续接

扫描文档的记录会在页尾断开，采集宿主需要可导入的TypeScript续接包。每页包含有序片段，片段有稳定ID及start、continue或end标记和记录ID；start建立记录，continue/end可在前页start前先到，按页号与页内序组合。每记录ID只能有一个start和end，continue必须在二者之间；页从1连续确认，只在记录start到end之间所有页均确认后交付，交付回调成功才记为已交付，失败保留本次记录；按start位置排序且不越过更早未完成记录。相同片段重投忽略、异内容冲突，页修订只能在未确认前整页替换。模拟乱序页、修订和跨页多个记录，核对一次交付。
