# 数据查询的相关作用域绑定

嵌入式查询宿主需要可导入的Go绑定器，输入已解析查询AST，含FROM表别名或子查询、列引用、WHERE、SELECT命名表达式及ORDER BY，不必解析SQL文本；表达式只含列、整数常量、加法和EXISTS查询，SELECT各项有唯一输出ID，FROM子查询的可见列是其SELECT输出ID；本层关系别名重复拒绝。每层FROM按顺序建立关系，普通FROM子查询看不到包含它的查询层FROM，但可见更外祖先层，LATERAL子查询在包含层只看到其左侧来源，更外祖先层照常可见；内层裸列先查本层，零命中才逐层向外，任一层多命中立即歧义，不能继续外查。限定列按最近声明该别名的层查找，别名存在但列不存在即错误。SELECT别名仅ORDER BY可见且优先于来源裸列，重名别名使用时报歧义。表模式由注入目录提供稳定列ID，SELECT别名引用返回其输出ID和深度0；其他引用输出命中可见列ID与跨越的查询层数，EXISTS可见包含层的完整FROM。测试遮蔽、非法向右引用及同名列，以独立枚举作用域参考核验。
