# 时间包尾部的扩展与鉴别码

时间采集若把最后20字节也当成扩展字段，鉴别码的类型号会落在摘要中间。实现可导入的Go组件，供时间采集调用，不发送请求。包头48字节。第1字节的高2位是闰秒指示，随后3位版本必须为4，低3位模式只能是3或4。其后是层、有符号8位间隔指数、有符号8位精度、大端uint32根延迟、大端uint32根离散、4字节参考标识，以及参考、原始、接收、发送四个时间戳。每个时间戳是大端uint32秒加大端uint32小数。头之后若剩余超过24字节，就继续读扩展：大端uint16类型、大端uint16长度和值。长度包含这4字节，必须是4的倍数且不小于16，不能超过剩余。扩展读完后再次判断剩余。剩余为0则没有鉴别码。剩余为20或24时，前4字节是密钥标识，其余是摘要。其他剩余长度失败。长度大于宿主maxPacket时在扩展长度可读后拒绝，不按声明分配。Push可停在扩展中间；Finish时包未完成则失败。失败停止组件，已交付包保留。测试独立切分，覆盖剩余20字节被当成扩展、扩展长度不是4的倍数、版本不是4和包被切开。期望包不得调用被测组件生成。
