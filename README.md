# leasesim

租约模拟库（仅 Go 标准库）：不同故障域的投票者确认租约，证书必须同时满足
输入的权重门槛与域数门槛；投票者不会同时授予重叠租约；时刻一律使用半开区间
`[Start, End)`。

## 模型

- `Interval`：半开区间 `[Start, End)`，相邻区间（如 `[0,2)` 与 `[2,4)`）不重叠，
  空区间不与任何区间重叠。
- `Voter`：属于一个故障域，携带正权重。
- `History.Add`：记录授予；拒绝未知投票者、空区间、以及同一投票者重叠的授予。
- `Certificate`：若干投票者各出一票，区间为各票区间之交（非空），
  总权重 ≥ `WeightThreshold` 且不同域数 ≥ `DomainThreshold`。
- `Certificate.Conflicts`：两份证书区间重叠且投票者集合不相交才算冲突；
  重叠但共享投票者的证书基于同一授予（投票者不可能另发重叠授予），属于同一租约。
- `History.CheckSafety`：枚举全部合法证书，查找冲突对。
- `Config.QuorumIntersectionGuaranteed`：充分条件
  `2*WeightThreshold > 总权重` 且 `2*DomainThreshold > 总域数`，
  保证任意两个法定集合相交，从而无冲突证书。

## 穷举核对

`enumerate_test.go` 在 3 时刻时间网格上枚举每个投票者的全部合法授予组合
（每人 13 种），覆盖全部小历史：

- 4 投票者 / 3 域 / 等权（权重门槛 3，域门槛 2）：28561 个历史、102939 份证书，无冲突。
- 3 投票者 / 2 域 / 加权（权重门槛 3，域门槛 2）：2197 个历史、6665 份证书，无冲突。
- 门槛过低（权重 2、域 1）时，穷举在 11792 个历史中发现冲突证书，验证检查器非空转。
