# shed — 离线负荷切除优化器

纯 Node.js 22 标准库实现（无第三方依赖）。以有限域 CSP 表示每负荷的切除阶段
（0..K），通过约束传播（馈线累计容量、联锁关系、缺口可达性）加回溯分支定界
求解最优切除方案。

## 模型格式（model.json）

```json
{
  "stages": 3,
  "gap": 120,
  "feeders": [
    {
      "id": "F1",
      "capacity": [0, 90, 180, 400],
      "loads": [
        { "id": "L1", "power": 60, "level": 1, "shed": [0, 20, 40, 60] }
      ]
    }
  ],
  "interlocks": [
    { "type": "together",    "loads": ["L1", "L2"] },
    { "type": "sequence",    "loads": ["L1", "L2"] },
    { "type": "unsheddable", "loads": ["L3"] }
  ]
}
```

- `stages`：阶段数 K，每负荷取阶段 0..K，阶段 0 表示不切除。
- `capacity[s]`：馈线在阶段 s 的累计切除容量上限（`null` 表示不限）。
- `shed`：每阶段切除量，数组按阶段索引，或对象 `{"0": 0, "1": 20, ...}`
  （键必须为整数阶段）。要求非负整数、单调不减、`shed[0] = 0`、不超过 `power`。
- `level`：重要等级，数值越小越优先切除；同等级按负荷编号顺序决定。
- 联锁：`together`（同阶段）、`sequence`（前者不晚于后者切除）、
  `unsheddable`（固定阶段 0）。

## CLI

```
shed model.json --gap 120 --budget 300
```

- `--gap`：功率缺口（覆盖模型内 `gap`）。
- `--budget`：分支节点预算，默认 1000000。

退出码：

| 码 | 含义 |
|----|------|
| 0  | `ok`，找到最优方案（输出 `plan`/`shed`/`cost`） |
| 1  | `infeasible`，输出最小冲突（馈线容量 + 联锁负荷） |
| 2  | 校验/用法错误（负功率、未知负荷、非整数阶段等） |
| 3  | `unknown`，预算耗尽，输出未决负荷 `pending`（绝不误报为不可行） |

## 目标函数

在满足 `切除量 >= gap` 的方案中最小化
`Σ shed_i * M^level_i`（M 大于总可切量，BigInt 精确计算），
即低等级优先；同等级按负荷编号作确定性并列裁决。

## 测试

```
node --test
```

测试内容：3–5 负荷实例与全枚举对照可行性和最优成本；互锁链导致任何阶段
都无法满足缺口时返回最小冲突；小预算复现 `unknown`、增大预算后得到可验证
方案；CLI 各退出码。真实运行输出见 `result.txt`。
