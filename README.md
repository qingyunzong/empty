# robocalib

机器人间相对位姿标定库。约束由**整数平移 + 90° 整数倍旋转**构成，
组合不可交换，库内严格按定义顺序复合。

## 模型

- `Transform{Rot, Dx, Dy}`：把点 `p` 映射为 `R·p + t`，`R` 为逆时针
  `Rot·90°` 旋转。`a.Compose(b)` 表示先作用 `b` 再作用 `a`（即 `a∘b`），
  `Inverse` 为群逆元。
- `Constraint{ID, From, To, T}`：语义为 `pose(To) = T ∘ pose(From)`。

## 行为

- `Add` 插入约束；若与既有约束矛盾，返回 `*Conflict`，内含闭环上的
  约束 ID 序列（`Cycle`，首元素为被拒约束）及沿环复合的变换证书
  （`Composite`，一致时本应为单位元）。被拒绝的约束不改变库状态。
- `Remove(id)` 按 ID 删除约束并重建连通分量。
- 每次成功增删都会提交一个不可变快照，旧版本通过 `Snapshot(v)` 保留可取。
- 每个连通分量以**最小机器人 ID** 为原点；`Pose` 给出相对原点的势变换，
  `Relative(a, b)` 给出 `pose(b) = Relative ∘ pose(a)`。

## 测试

```sh
go test ./...
```

包含变换群性质（结合/逆元/不可交换）、闭环证书核验，以及随机图测试：
随机增删后，将每个保留快照与独立实现的“全路径势变换”参考模型
（从分量最小 ID 出发 BFS 逐边复合）逐一比对。
