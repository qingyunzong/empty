# searchre

一个小型正则搜索库（仅依赖 Go 标准库），支持：

- **字面量**：普通字符；`\\` 转义元字符（如 `\*`、`\(`、`\|`）
- **分组**：`(...)`（捕获组，按左括号编号，从 1 开始）
- **并联**：`a|b|c`（优先级最低）
- **星号和问号**：`x*`、`x?`（可叠置，如 `a*?*`）

## 匹配语义

- **左起最早**：匹配起点尽可能靠左。
- **再最长**：同一起点下取最长匹配。
- **同长度按并联分支顺序**：等长候选按并联分支书写顺序决胜（量词为贪婪）。
- **捕获取最终参与迭代**：捕获组报告其最后一次参与迭代的文本；
  星号的最后一次空迭代也算参与（与 Perl/Python 一致，例如
  `(a?)*` 作用于 `"aa"` 时 `$1` 为 `[2:2]` 的空串）。
  空循环必然终止：重复相同 `(循环头, 捕获)` 状态的空迭代会被截断。

偏移量均为 rune 下标 `[start:end)`；未参与的捕获组偏移为 `-1`。

## API

```go
re, err := searchre.Compile("(ab|a)*")
re.FindSubmatchIndex("aba") // [0 3 2 3]
re.FindSubmatch("aba")      // [aba a]
re.FindIndex("aba")         // [0 3]
re.Find("aba")              // "aba"
```

## CLI

```
go run ./cmd/match PATTERN [STRING ...]
```

无 STRING 时从标准输入逐行读取。每个输入输出整体匹配区间与各捕获组；
退出码：有匹配 0，无匹配 1，出错 2。

```
$ go run ./cmd/match '(a|b)*b' xaabay
"xaabay": match [1:4] "aab"
  $1 [2:3] "a"
```

## 实现与验证

- `syntax.go`：递归下降解析为 AST。
- `compile.go`：编译为 NFA 程序（`Char/Split/Jmp/Save/Loop/Match`）。
- `vm.go`：Pike VM，按 `(程序计数器, 捕获状态)` 去重；`Loop` 指令在
  状态重复时切向循环出口，与回溯守卫同点产生退出线程，保证优先级一致。
- `brute.go`：独立的回溯穷举器（直接遍历 AST，不经过编译），
  按优先级枚举全部匹配后取左起最长。

测试（`go test ./...`）包含语义表用例，并对随机生成的短模式与短串
（两个种子、各 3000 模式 × 4 串）逐一对照 NFA 引擎与回溯穷举器的结果；
穷举在嵌套可空星号下可能指数爆炸，超出步数预算的用例会被跳过并计数。

性能说明：为精确保持捕获优先级，引擎按 `(pc, 捕获)` 去重，病态模式
（如 `(a*)*b` 匹配长串无 `b`）最坏情况可达多项式高阶耗时。
