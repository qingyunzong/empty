# 采集包的部件上下文与小端浮点

指标采集若沿用上一个插件的实例名，新插件的第一条数值会带上别人的实例。实现可导入的Go组件，供指标采集调用，不接收网络。一个分组由部件顺序组成。每个部件以大端uint16类型和大端uint16长度开始，长度包含这4字节，小于4则失败。长度大于宿主maxPart时在这2字节可读后拒绝，不按声明分配。类型0是主机，1是时间，2是插件，3是插件实例，4是类型名，5是类型实例，6是数值，7是间隔。其他类型失败。字符串部件的最后一字节必须是0x00，前面的字节是严格UTF-8且不能含0x00。时间是大端uint64秒，间隔是大端uint64秒，这两种部件的长度必须是12。数值部件先是大端uint16个数，个数必须不小于1，随后每个值1字节种类，再按同样顺序放值。种类0是大端uint64计数，1是小端binary64有限浮点，2是大端int64变化量，3是大端uint64绝对值。数值部件的长度必须等于6加个数的9倍。数值部件交付一条记录，使用当前主机、时间、插件、类型名和可选的实例与间隔。主机、时间、插件或类型名尚未出现则失败。新的插件清空插件实例，新的类型名清空类型实例。间隔可以一直为空。Push可停在部件中间；Finish时部件未完成则失败。失败停止组件，已交付记录保留。测试独立组包，覆盖浮点用了大端、新插件仍带旧实例、数值出现在类型名之前和部件被切开。期望记录不得调用被测组件生成。
