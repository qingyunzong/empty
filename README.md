# 浏览器采集 iframe 快照定位

浏览器采集服务调用TypeScript跨框架定位包。适配器为每个frame返回带代数的不可变元素树，iframe节点可关联子frame ID；一条查询由非空选择器路径列表组成，前几段在当前frame中必须恰匹配一个iframe，末段可返回多个节点，选择器求值由注入的纯函数提供。frame读取和选择器调用可能异步；任何已读取frame代数变化使整次尝试作废，从顶层重新定位，最多尝试调用方给定正整数次数，不能拼接不同版本结果。订阅接口支持从指定代数开始按序重放，读取与监听间的变化不得漏掉；成功前进行适配器原子checkVersions校验。循环frame关系、非iframe中间节点、多匹配、frame不可访问均返回含路径段号的确定错误，取消需解除全部监听且不返回部分节点。用可控适配器测试导航替换、嵌套变化、最终校验失败与取消。
