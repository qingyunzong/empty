# 十六进制浮点采集值的舍入

地震资料接入服务要将历史设备的32位十六进制浮点样本转成IEEE binary32；普通浮点乘法会在边界二次舍入。实现供样本解码管线导入的Go转换包。输入四字节大端字，最高位为符号，中间7位为指数e，低24位为整数尾数m，精确值为(-1)^sign*(m/2^24)*16^(e-64)；m=0时忽略指数但保留符号得到正负零，非零m允许未规范化。输出IEEE binary32原始位型，使用round-to-nearest ties-to-even，一次完成舍入，含次正规数、舍入到最小正规数、最大有限数及溢出无穷；输出是否精确、是否下溢及是否溢出，下溢定义为舍入前绝对值小于最小正规数且转换不精确。还要提供反向转换：给binary32位型，在满足下述规范化要求的全部可表示十六进制字中选择数值最接近者，平局取偶数尾数，再取指数最小者，符号按输入保留；NaN与无穷不能反向转换，返回错误。反向非零输出应规范化为m最高四位非零，但若指数0仍不足则允许非规范尾数；符号零统一指数0尾数0。实现不能通过float64中间值或字符串格式化推断舍入。测试以任意精度有理数对照正反向误差，覆盖每类指数交界、半ULP平局、正负零、多个等值非规范字及两种格式的最大范围差异；说明精确性和上下溢标志如何验算。

## API

- `HexWordToBinary32(word uint32) Result`：转换打包的 32 位字。
- `HexBytesToBinary32(src []byte) (Result, error)`：按四字节大端输入转换。
- `Binary32ToHexWord(bits uint32) (uint32, error)`：反向转换；NaN/无穷返回 `ErrNotFinite`。
- `Binary32ToHexBytes(bits uint32) ([4]byte, error)`：反向输出四字节大端字。
- `Result.Bits` 是 IEEE binary32 原始位型；`Exact`、`Underflow`、`Overflow` 是转换状态。

`DecodeHexWord`、`DecodeHexBytes`、`EncodeHexWord` 是上述函数的短别名。

## 舍入与状态

记 `V = m * 2^(4e-280)`，并令 `b = floor(log2(m))`、`E = b + 4e - 280`。

- `E >= -126` 且 `E <= 127` 时，结果的 24 位有效数为 `m << (23-b)`，指数为 `E`，因此该范围内转换总是精确的。
- `E < -126` 时，先精确计算 `V * 2^149`，再对该二进有理数做一次 ties-to-even 整数舍入；舍入值可落到零、次正规数或最小正规数 `2^-126`。
- `E > 127` 时结果溢出为带符号无穷，且不精确。

状态按以下方式验算：

- `Exact`：结果有限且舍入前后数值相等。零样本（无论指数）精确；目标为正规数时精确；目标为次正规数时，只有被丢弃的位全为零才精确。
- `Underflow`：仅当舍入前 `|V| < 2^-126` 且 `Exact == false`。因此可精确表示的次正规数不置下溢，半 ULP 舍入到零或舍入到最小正规数时置下溢。
- `Overflow`：结果被舍入为无穷。最大有限数 `0x60ffffff -> 0x7f7fffff` 不溢出；`2^128` 及更大值溢出。

反向转换从 binary32 的精确二进有理数出发，在规范的指数/尾数网格上做 ties-to-even 最近选择：
非零且 `e > 0` 时尾数至少为 `0x100000`；同值平局先选偶数尾数，再选更小指数；零统一输出
`sign | 0`，即指数和尾数都为零。由于全部运算使用整数和 `math/big` 测试参考模型，没有使用
`float64` 中间值，也没有通过字符串格式化推断舍入。
