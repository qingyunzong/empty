# 列值波列矩阵的秩与范围分位

列扫描宿主需要可导入的Go波列矩阵索引，输入N个b位无符号整数，1<=b<=32。从最高位起逐层记录当前序列该位位图，再按0在前1在后的稳定分区进入下一层，每层保存零数和位图前缀rank索引。实现按原行取值、rank(value,end)统计原前end行相等数、select(value,k)找第k个相等值的原行，以及rangeKth(l,r,k)求原半开范围内第k小值；k零起始，越出b位域的value在rank返回0、select返回notfound；At或end或范围越界报错，合法值找不到select返回notfound，k为负、k不小于范围长或空范围分位请求报错。查询只能经层位图与rank/select导航，不能保存原列作为查询捷径或展开范围排序。以朴素列参考核验重复值、未出现值、b=32和所有短范围，公开层结构并验证稳定分区与总位数不被伪造。
