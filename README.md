数据总线升级字段模式时需要一个可嵌入Go消费服务的转换组件。模式是有ID的有向无环转换图，边由调用方提供纯转换函数和正整数成本；记录携带源模式，目标模式在屏障处切换。选择总成本最小路径，平局按边ID序列字典序；一个批次任一转换失败则整批拒绝，屏障前已接收批次仍用旧目标。提供可控并发测试，覆盖转换中切换目标、无路径、图更新成环以及旧批次完成后不会污染新版本缓存。

## 用法

组件即包 `q159`，无外部依赖、自身不启动 goroutine，可直接嵌入消费服务。

```go
tr, err := q159.New([]q159.Edge{
    {ID: "e1", From: "v1", To: "v2", Cost: 1, Apply: toV2},
    {ID: "e2", From: "v2", To: "v3", Cost: 1, Apply: toV3},
}, "v3")
if err != nil { /* 图校验失败，例如成环、成本非正、边 ID 重复 */ }

// 整批要么全部转换成功，要么整体拒绝（无路径或任一转换失败）。
out, err := tr.ApplyBatch(ctx, []q159.Record{{Schema: "v1", Payload: rec}})

// 屏障：已在执行的批次继续用旧目标，之后接收的批次路由到新目标。
_ = tr.SetTarget("v4")

// 原子换图：校验失败（含成环）时版本号不变、旧图继续服务。
version, err := tr.ReplaceEdges(newEdges)
```

## 设计要点

- **最小成本路径**：Dijkstra，边成本为正整数；成本相同时按边 ID 序列逐元素字典序决胜。
- **屏障语义**：批次在入口一次性捕获不可变快照与当前目标，转换期间的 `SetTarget` 不影响在途批次。
- **版本化缓存**：每个图版本持有独立快照与路径缓存；旧批次只读写旧快照，无法污染新版本缓存。
- **整批原子性**：先对整批做路径规划，任一记录无路径则零转换拒绝；执行期任一转换失败即丢弃全部输出。
- **并发安全**：`RWMutex` 保护当前快照/目标指针，快照内部缓存独立加锁；测试使用门闩（`gate`）+ `WaitGroup` 实现确定性的可控并发。
