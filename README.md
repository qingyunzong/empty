# 增量等值连接的多重集撤销

流式查询宿主调用可导入的Go连接包维护左右多重集，每条变更为行ID、连接键和有符号整数权重；同侧同ID内容必须相同，批末累计权重不得为负。null键不匹配，其他键按原字节相等；输出每对行ID的连接权重增量，须包含同批两侧变化的交叉项。整批校验失败不改状态；按左右ID字节序输出零以外增量，精确整数不溢出。用每批全量展开连接核对撤销、重复行及同批双侧更新。

## 包 API

`dataeng` 包通过 `NewJoin` 与 `Join.Apply([]Change)` 按批维护左右多重集：

- `Change` 包含 `Side`、`RowID`、可为 NULL 的 `Key`（nil 切片）和 `*big.Int` 有符号权重。
- 同侧同 ID 的键必须一致，批末累计权重不得为负；校验失败时整批拒绝、状态不变。
- NULL 键不匹配任何键（含 NULL），非 NULL 键按原始字节相等匹配。
- 成功时返回非零的 `[]Delta`，按左、右行 ID 字节序排列，同批两侧变化的交叉项包含在内。
- 全部算术基于 `math/big`，任意精度整数不溢出。
