# HTTP3采集头块的插入计数回绕

HTTP3采集宿主已解析QPACK指令，需要可导入Go接收端组件，重点处理跨流乱序造成的动态表等待，不实现字节/Huffman解析。当前表容量初始为0；创建时给非负最大表容量M、非负阻塞流上限及零起始索引的静态表；动态项大小为名字和值字节数加32，绝对索引从0累增，当前容量可调但不超过M，插入或缩容逐出最旧项，项大于当前容量报错。头块含唯一streamId、编码计数E、符号S、非负Delta及字段列表；字段为literal、static索引、relative动态索引或post-base动态索引。收到头块时以当前总插入数I冻结解码：K=floor(M/32)，F=2*K；E=0得R=0，否则要求K>0且E<=F，V=I+K，R=floor(V/F)*F+E-1，若R>V则R<=F时报错，否则减F，最终R=0也报错。Base在S=0时为R+Delta，S=1时为R-Delta-1，负数拒绝；relative索引i映到Base-i-1，post-base映到Base+i。动态字段最大绝对索引加1必须等于R，无动态字段R必须0。R>I则保存本头块等待，不能稍后按新的I重解释E；插入推进后释放已满足R的块，按接收次序处理，引用已逐出项报错而不能取同位置新项。取消阻塞流后不得再交付它，重复streamId拒绝，阻塞上限按当前等待流数计，超限是本连接解码错误；已取消及已交付ID也不能在同组件内复用。每块只有全部字段解析合法才向宿主返回完整有序字段及绝对索引来源，任意解码错误使本连接组件停止，保留错误证据且不再接收操作。所有计数用精确整数避免回绕。测试计数跨F回绕、同E在不同I含义不同、Base正负号、跨流等待与取消、表收缩后旧引用失效及零容量静态块，给独立算术参考和事件重放测试。
