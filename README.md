# 大数组的增量JSON接入

采集服务需要可导入的Go增量JSON解码组件。输入为连续字节块，顶层必须是数组，允许空数组；显式结束输入后数组已结束且其后只能有JSON空白。完整元素解析且原始字节数不超过调用方上限时交给回调；支持嵌套对象与数组、字符串转义及UTF-8，拒绝重复对象键和非法代理对。回调返回暂停表示当前元素已接收，停止消费并返回当前块已消费字节数，恢复时从未消费位置继续，不能重发；回调报错使解码器终止。语法错误返回零起始偏移：非法UTF-8报无法构成合法编码的首字节位置，其他非法字节报该字节位置，输入结束时缺字节报总长度，重复键报第二个键的引号位置。已交付元素保留，未完成元素不交付。用每字节切块测试跨块转义、非法编码、重复键、尾随数据和暂停恢复。
