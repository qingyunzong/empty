# ringlog — 固定页环形文件遥测记录器

变长帧追加写入固定页大小的环形文件，帧可跨页（包括跨绕回点）；读者
对自己停留的页加 pin，写者不得覆盖被 pin 的页，空间不足时显式返回
`ErrBackpressure`（背压），且一个字节都不写。仅使用 Go 标准库。

## 磁盘格式

- 文件 = `numPages` 个定长页。
- 页头 24 字节：`magic(4) | generation(8) | pageIndex(4) | dataLen(4) | headerCRC32(4)`。
  `dataLen` 是该页已提交的帧数据字节数；`headerCRC32` 覆盖前 20 字节，用于识别撕裂页头。
- 帧头 12 字节：`frameMagic(4) | payloadLen(4) | payloadCRC32(4)`，帧数据紧密排列，
  可跨任意多个页，包括从末页跨到第 0 页（绕回点）。
- 代际号（generation）：写者每绕过第 0 页一次加 1。页的绝对序号
  `key = generation*numPages + pageIndex` 给出全序，恢复与读者都靠它区分新旧 lap。

## 写入与提交协议

1. 预检：模拟推进，计算帧需要的所有页；任一所需页被读者 pin → 直接返回
   `ErrBackpressure`，**不产生任何部分写入**（避免背压本身制造撕裂帧）。
2. 先写数据字节，再（重新）提交所触及页的页头。页头提交是帧可见性的
   原子发布点：崩溃时未提交的数据因 `dataLen` 未覆盖而被忽略。
3. 推进到下一页时先提交 `dataLen=0` 的空页头（作废旧 lap 数据），再写数据。

## 恢复（最后完整前缀）

1. 逐页校验页头（magic + CRC + 页索引 + dataLen 范围），撕裂页头 → 该页作废。
2. 取最大 key 的页为写前沿，存活窗口 = `[maxKey-numPages+1, maxKey]`；
   窗口内有效页按 key 升序拼接成逻辑流（旧 lap 的页因 key 落在窗口外被排除）。
3. 顺序扫描帧：长度越界 / 截断 / CRC 不符 → 视为撕裂；借助 `frameMagic`
   逐字节重同步，跳过撕裂区后继续接受完整帧。结果 = 最后完整前缀
   （外加撕裂区之后可校验的完整帧）。
4. 写者从最后一个完整帧的末尾处恢复续写，并截断该页 `dataLen`。

## 跨页与绕回故障点枚举

| # | 故障点 | 检测手段 | 恢复行为 |
|---|--------|----------|----------|
| F1 | 帧头跨页撕裂（12 字节帧头只落盘一部分） | 剩余字节 < 帧头 / magic 不符 | 截断到上一完整帧 |
| F2 | 帧负载跨页，后继页未提交 | 帧 CRC32 不符 | 截断到上一完整帧 |
| F3 | 页头撕裂（崩溃于页头提交中） | 页头 magic/CRC 校验失败 | 页作废；崩溃撕裂总在写前沿，前沿前的前缀完整保留 |
| F4 | 绕回覆盖旧 lap | 代际号 + key 窗口 | 旧 lap 页被排除在存活窗口外 |
| F5 | 帧跨绕回点（页 N-1 → 页 0，代际号不同） | key = gen*N+idx 全序 | 逻辑流按 key 排序，顺序正确 |
| F6 | 绕回后存活窗口起点落在帧中间 | 帧 magic 重同步 | 跳过不完整的头部残片，从下一完整帧开始 |
| F7 | 读者 pin 的页与写者撞页 | pin 计数预检 | 写者返回 `ErrBackpressure`，读者数据不受损 |
| F8 | 数据已写但页头（dataLen）未提交 | dataLen 之外的字节不可见 | 视为不存在，前缀语义保持 |
| F9 | 帧长度字段损坏 | len > MaxFrameSize 或超过流剩余 | 视为撕裂，重同步 / 截断 |
| F10 | 读者被写者甩开（防御性） | 读者位置页的代际号不匹配 | 返回 `ErrLapped`（pin 语义下正常不会触发） |
