# offlineq

离线任务队列库（仅 Go 标准库），提供世代租约与可重放的事件日志。

## 语义

- 时间为调用方传入的逻辑时钟 `now int64`。
- `Claim` 成功时世代号 +1；任务已有存活租约或已 ACK 时拒绝。
- 租约在 `now < Deadline` 时存活；`now == Deadline` 即视为过期。
- `Ack` 仅接受当前世代且租约存活；超时重新领取后旧世代的 ACK 被拒绝。
- `Extend` 仅接受当前世代、租约存活且新截止时刻在未来。
- 每个任务在任意时刻至多一个当前持有者。
- 所有变更以 JSON 行事件追加到日志文件；`Open` 重放日志恢复状态
  （世代号、持有者、延长后的截止时刻均不丢失）。
