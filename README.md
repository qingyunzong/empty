# 主机记录布局中的变长与覆盖字段

遗留主机数据接入宿主会提供已解析的copybook子集AST，请实现Go可导入的布局编译与记录解码包，不要求解析COBOL文本。AST节点有唯一字段路径，未声明OCCURS即一次；显示十进制位数d为正，bytes长度为非负整数，packed的d为正且0<=scale<=d，为group、unsigned显示十进制、signed packed decimal、定长原始bytes四类；group按孩子顺序连续排布，无隐式对齐。显示十进制每位占一字节ASCII数字；packed decimal占ceil((d+1)/2)字节，数字按高位到低位存放，含d位十进制及最低符号半字节，C/F正D负，最高多余半字节必须0，精确值按字段给定scale乘10的负scale次幂，输出规范整数与scale及原字节范围，不经浮点。节点可OCCURS固定正次数，或0至max次数且DEPENDING ON引用之前已解码、位于根层且不重复的unsigned标量；实际记录只占实际次数空间，后续字段起点随之移动。无REDEFINES时group可嵌套，动态计数只准引用根层之前的标量。相邻根层字段可组成REDEFINES组，共享同一起点，空间取所有分支固定长度最大值；分支选择由之前的根层unsigned字段和调用方给定值到分支表决定，未知值拒绝；覆盖组内禁止变长OCCURS，未选择分支不解码但整个最大空间仍须存在。编译时拒绝路径重复、前向控制引用、控制字段位于覆盖分支、计数上限乘法溢出与无意义类型组合。运行时记录必须恰好消费完整长度，计数越界、数字或符号非法不交付部分记录，错误给字段路径及物理偏移；按调用方限制总展开叶数，零次数不读取其字段。交付宿主调用例和测试，独立逐字段构造字节验证动态数组后继偏移、嵌套固定重复、负零规范化、奇偶packed位数、短覆盖分支保留空间及非法未选分支不误拒绝。
