# 采集文档召回的精确块上界剪枝

采集文档的检索宿主要在倒排分块上精确找加权得分最高的文档，请用Go交付可导入的索引构建与查询包。输入不可变文档目录，ID为不同uint64；每词项有按ID严格递增的posting及非负规范有理贡献，同词同文最多一项，目录外ID拒绝。构建时按调用方给定的正blockSize对每个词项分别分块，保存每块最小/最大文档ID、posting数和最大贡献，并将该块完整posting载荷交给注入的只写存储；查询实例只能持目录、块元数据和存储读接口，不能保留所有原posting或提前建每文档的词项向量绕过读取。构建必须实际算出上界，不能相信输入给的最大值。查询给词项到非负有理权重的映射、排除文档集合及非负整数k，分数是各词项权重乘该文贡献之和，缺posting贡献0，未知词项按空表处理；全部未排除目录文档都参与，包括无查询词的0分文档。返回最多k项，按精确分数降序、文档ID升序，k=0为空，查询空或所有权重0时仍按ID返回0分结果。不得使用浮点或把相等分数当可随意决胜。查询须以块最大贡献、当前各词项的ID覆盖范围和已经形成的第k名下界做安全跳过，可采用block-max WAND或其他等价的动态上界方案；不能给所有词项直接相加某一个当前块上界后跨过其他词项更早的块边界。尚未得到k个有效候选时不能凭默认0阈值跳过所有0分文档；上界恰等第k名时，仅当被跳范围内最小可能文档ID也不能胜过第k名ID才可整段剪枝。跳过记录包括ID闭区间、各查询词项在该区间使用的贡献上界、合计分数上界和当时第k名的分数/ID；其范围不得包含未覆盖的块，证明必须能由独立元数据检查器验证，不能只记录“上界小”一句话。存储每次读取返回一个块的完整posting副本，单次查询同块最多读一次，计数可观察；不得先读全部块再补造跳过证据。提供确定的剪枝夹具：文档1的单词贡献100，其余至少8块每项贡献<=1，权重1且k=1，必须返回文档1并跳过至少一个后续块而不读取其载荷；同时构造上界相等但较小ID仍能入选、各词项块边界不齐、过滤掉高分文档、空词项和跨uint32范围ID的反例。以独立全量posting求和排序参考对随机小目录、全部k及多组有理权重核对结果，逐条复核跳过证据，并给宿主实际构建/读取调用例。索引不涉及网页请求、报表或业务排名系统，测试不要求外部搜索服务。
