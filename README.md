# 嵌套交换流的不定长元素边界

采集接入宿主需要可导入的Go标签树包，元素首字节低5位为标签号，限uint64；小于31直接用；31时后续7位分组大端累积，最高位1表示续组，必须最短且值至少31；首字节0x20位表示构造元素，高两位为类别。长度首字节<128为长度，等于128表示不定长，其他值低7位给后续大端长度字节数，限制1到8且必须最短。不定长只准构造元素，用00 00闭合当前层；定长构造须恰好容纳完整子元素，原始元素正文里的00 00不能闭合父层。00 00在非不定长闭合位置非法，流只含一个顶层元素，尾随字节拒绝。返回类别、标签、树及每元素源范围，限制字节/深度，分块输入截断或提前结束整份拒绝。测试高标签跨块、定长内嵌不定长和原始零字节，以独立树编码器往返核验。
