# 虚拟数组采集的跨形状选择映射

科学数据接入宿主提供虚拟数组的映射元数据，要求读取小区域时不展开整个源或整个选择。实现可导入Go虚拟数组读取包，不解析HDF5文件。所有数组维长及索引为任意精度非负整数，秩1至8；每个映射含源数组名、源shape、虚拟selection和源selection，selection每轴为start/stride/count/block，stride、block为正且stride>=block，count可为0，选中坐标为start+i*stride+j，0<=i<count、0<=j<block；非空selection所有坐标须在对应shape内。各selection按坐标字典序排列点，最后一维最快，以相同序号把虚拟点映到源点，源与虚拟秩或形状可不同，但选中点总数必须精确相等。一个虚拟点落入多条映射时列表最后一条优先；优先映射引用的源不可用时输出fill，不能退回较早映射；无映射也输出fill。宿主提供虚拟shape及固定int64 fill值，同名源的shape和C/F顺序必须一致；每次读取的源可用性由宿主不可变快照给定，只对可用源调用读取；源按宿主给定C或F存储顺序平铺成原始int64值，通过按元素线性下标的批量读取回调访问；接口返回精确值数组或读取失败，不能把合法填充值当源缺失。C为最后维最快、F为第一维最快；宿主请求虚拟半开矩形，各轴0<=起点<=终点<=维长，允许空矩形，返回C顺序值及每点来自哪条映射、哪个源坐标，fill也给原因。输出点数超过调用方预算须在分配及源回调前拒绝；映射合法性须在初始化完整检查，包括空selection也检查秩、正stride/block及start<=维长，空选择不要求虚构最后坐标。源相同线性位置只读一次，排序并合并相邻位置为批量区间，读取失败整次不交付半批，源不可用作为有效fill处理而非读取失败。不得逐点展开任何完整selection或按其总点数分配索引；用membership/rank/unrank计算请求点映射，大于2^53及uint64的元数据也须精确。提供接入宿主调用例及小数组全展开参考，核对跨秩zip、block内部顺序、C/F源布局、后映射遮蔽、缺源不回退、重复源读取与超大空间中的小请求。
